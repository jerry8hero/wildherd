## 【置顶评论】

🐢 白化 vs 黄化 vs 果冻，看眼睛一秒分清！

三兄弟最容易混，记一个铁律就够：**看眼睛！**

- 🔴 红眼 + 通体雪白 + 无眼线 = 白化（Albino）
- ⚫ 黑眼/暗红眼 + 金色虹膜 + 无眼线 = 黄化（Hypo）
- 🔴 红眼 + 半透明黄体 = 果冻（Hybino）

⚠️ 关键：白化和黄化都**没有眼线**，只有普通巴西龟才有那道黑色眼线！看到有眼线的"白巴"，基本是温室龟冒充的，别上当。

💰 价格逻辑（稀有度决定天花板）：
1. 果冻最常见，二三十块入门首选
2. 白化次之，大几百到上千，看血统（C / R / G 三条线）
3. 黄化最稀少，基因难稳定，**极品黄化价格天花板最高**

🛒 避坑干货：
1. 没红眼的"白巴"基本都是温室龟冒充
2. 新手从果冻起步最稳，二三十块试水
3. 追求极致品相再冲黄化，量力而行
4. 浅色龟视力弱、怕强光，记得留躲避洞，别暴晒
