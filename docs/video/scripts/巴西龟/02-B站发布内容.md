## 【置顶评论】

🐢 白化 vs 黄化 vs 果冻，看眼睛一秒分清！

三兄弟最容易混，记一个铁律就够：**看眼睛！**

- 🔴 红眼 + 通体雪白 + 无眼线 = 白化（Albino，T-）
- ⚫ 黑眼/暗红眼 + 金色虹膜 + 无眼线 = 黄化（Hypo，T+）
- 🔴 红眼 + 淡蓝虹膜 + 半透明粉体 = 果冻（Hybino，T-/T+ 复合）

⚠️ 关键：白化和黄化都**没有眼线**，只有普通巴西龟才有那道黑色眼线！看到有眼线的"白巴"，基本是温室龟冒充的，别上当。

💰 价格（曾经天价，现在白菜，全跌进百元档）：
1. 果冻最常见，二三十块入门首选
2. 白化次之，普通苗三五十，极品一两百
3. 黄化最稀少，普通苗几十到一百多，极品也就几百块

曾经的几十倍差价现在基本抹平，正是入坑好时机！

🛒 避坑 + 保命干货：
1. 没红眼的"白巴"基本都是温室龟冒充
2. 新手买大不买小，挑 5cm 以上大苗，避开弱苗
3. 1 岁以内建议加温越冬、暂不冬眠，30–32 度恒温更稳妥
4. 新龟到家先静养 3–7 天，水温 23 度以上再喂，防肠胃炎
5. 浅色龟视力弱、怕强光，记得留躲避洞，别暴晒
