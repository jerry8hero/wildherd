# 结构化内容

## 标题
变异巴西龟选购速查｜速记6看

## 学习目标
观众保存这张图后，买变异巴西龟时能逐条对照：眼型辨品系、体色识药浴、品相定价值、体质避温室、来源防噱头、价格对行情。

## 模块（内容逐字保留）

### 模块 1｜看眼睛（子项最多，配 4 个眼型小图标）
- 内容（原文）：白化必红眼，黄化偏黑眼；黑珍珠魔眼，果冻红瞳蓝虹膜
- 视觉元素：四只小眼睛涂鸦（红眼/黑眼/魔眼黑/红瞳蓝圈）
- 文字标签：看眼睛

### 模块 2｜看体色（避雷警示）
- 内容（原文）：药浴龟体色不均、深浅斑驳，一两周到一个月就恢复原形
- 视觉元素：斑驳壳色涂鸦 + 警示叉
- 文字标签：看体色

### 模块 3｜看品相
- 内容（原文）：同品种品相差价大，白化看白度、黄化看金色、果冻看透明度
- 视觉元素：三档色阶小条（白/金/透明）
- 文字标签：看品相

### 模块 4｜看体质（避雷警示）
- 内容（原文）：温室苗壳薄反应慢，腐皮白眼肠炎高发，健康小苗更靠谱
- 视觉元素：壮苗 vs 弱苗对比小涂鸦
- 文字标签：看体质

### 模块 5｜看来源
- 内容（原文）：正规繁殖场有繁殖记录；变异龟全是人工选育，别信"野生"噱头
- 视觉元素：文件/记录本涂鸦 + "野生"打叉
- 文字标签：看来源

### 模块 6｜看价格（行情提醒）
- 内容（原文）：2026行情大跳水，普通苗二三十块；价格明显偏离行情的要警惕
- 视觉元素：价格标签涂鸦 + 数字"20-30"用陶土橙放大
- 文字标签：看价格

### 页脚
- 内容（原文）：新手建议从正规繁殖场购买，有保障！· 有问题评论区问～
- 视觉元素：washi tape 条 + 白化巴西龟苗涂鸦（浅黄体色+红眼）
- 文字标签：评论区互动

## 设计指令
- 竖版 9:16；六宫格 2×3，字号保证手机单屏可读
- 沿用中秋特辑版式（bento-grid + morandi-journal），形成"评论区保存版"系列感
- 龟种涂鸦须符合变异巴西龟特征：白化苗浅黄体色、红眼、无红色耳斑
