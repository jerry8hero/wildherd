速记6看：
1. 看眼睛：白化必红眼，黄化偏黑眼；黑珍珠魔眼，果冻红瞳蓝虹膜
2. 看体色：药浴龟体色不均、深浅斑驳，一两周到一两个月就恢复原形
3. 看品相：同品种品相差价大，白化看白度、黄化看金色、果冻看透明度
4. 看体质：温室苗壳薄反应慢，腐皮白眼肠炎高发，健康小苗更靠谱
5. 看来源：正规繁殖场有繁殖记录；变异龟全是人工选育，别信"野生"噱头
6. 看价格：2026行情大跳水，普通苗二三十块；价格明显偏离行情的要警惕
