# 内容分析

## 基本信息
- 主题：变异巴西龟选购"速记6看"避坑速查
- 来源：B站视频《变异巴西龟怎么选？6个避坑指南，新手必看！》置顶评论
- 用途：评论区配图，观众保存当选购参考卡（线下逛市场/网购时可对照）
- 数据类型：平行清单型——6 个等权重的"看X"模块 + 页脚建议
- 复杂度：中等——每条一行（15~25 字），条目内部有并列子项（如"看眼睛"含 4 个品系的眼型）
- 语气：行家带新手，防坑警示
- 受众：B站准备入手变异巴西龟的新手，手机端查看+保存

## 语言
- 源语言：中文；用户语言：中文 → 图上文字全中文

## 设计指令（来自用户）
- 与中秋特辑评论区信息图同一套版式：bento-grid + morandi-journal，9:16 竖版
- 面向不想读长文字的用户，可保存、可对照

## 结构判断
- 6 个模块完全平行、无次序依赖，天然的 2×3 bento 网格
- 每个模块自带小标题（看眼睛/看体色/看品相/看体质/看来源/看价格），标题格式统一"动词+名词"，适合做徽章式模块头
- 模块 1（看眼睛）子项最多（4 个品系眼型），适合配小图标；模块 2、6 是主要避雷点，可加警示色
- 页脚 = 行动建议 + 互动，弱化为 washi tape 条
- 布局结论：bento-grid，2×3 六宫格 + 顶部标题带 + 底部页脚带
