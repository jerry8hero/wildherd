# 冷到你不信 - 眼镜凯门鳄

戴眼镜但是看不到东西——眼镜凯门鳄，最委屈的鳄鱼，整天被欺负！

你可能会说，眼镜鳄？是不是戴眼镜的？难道样子是眼镜的？如果你这样想，就大错特错了！眼镜凯门鳄的名字不是因为戴眼镜，而是它眼球前有一条横骨，看上去像眼镜架——这个就是"眼镜"的真正由来！

兄弟们你知不知道眼镜凯门鳄有多大只？

成年只有1到2米，最大都不过2.5米——和恒河鳄、尼罗鳄、湾鳄这些大佬相比，它就像个小孩子。但正是因为这样，它在大自然里面受尽欺负——蜥蜴、鹰、长鼻浣熊、猴子都会偷它们的蛋吃！

你知不知道眼镜凯门鳄有多惨？

还没大个的时候会成为鲶鱼、龟类的食物，甚至小猪都会啃小眼镜凯门鳄！就算大个了，还有一大堆天敌——美洲豹、水蚺、黑凯门鳄、奥利诺科鳄——全部都对它们流口水——这个就叫做"小孩难做"！

说到最惨的，就是眼镜凯门鳄在鳄鱼界被称为"战五渣"！

不仅体型小，咬合力都不够大佬打。但是呢，它生存靠不是很大只，而是生得多——数量多就不怕绝种。这个就是大自然很有趣的平衡：不够打就靠狂生！

你知不知道？眼镜凯门鳄的名字有多委屈——

明明是鳄鱼，但因为小只，就被叫"眼镜仔"。你问它服不服？当然不服了！但有什么用，基因决定了它只能长到这么大。

各位兄弟，接下来讲的，就是眼镜凯门鳄最厉害的生存之道。

虽然受欺负，但眼镜凯门鳄有一样东西比其他鳄鱼厉害——它们很会分散风险，不会一次过被人抓完。而且它们繁殖快，就算损失一部分，都可以迅速补数。这个就叫做"不要将所有鸡蛋放在一个篮子里"！

所以下次见到戴"眼镜"的鳄鱼，记得——它可能是最受欺负的那只，但依然坚强地生存在南美洲淡水河里！
