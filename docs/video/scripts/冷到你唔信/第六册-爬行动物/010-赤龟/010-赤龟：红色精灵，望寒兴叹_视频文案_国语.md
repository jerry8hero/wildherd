# 冷到你不信 - 赤龟（赤蠵龟）

兄弟们，红色精灵现身！但是它最厉害的技能竟然是——耐寒？赤龟，带你看看冰海里面的生存专家！

好了，你可能会说，赤龟？是不是因为它红彤彤的？恭喜你，答中一半！这个"赤"确实是指红棕色，但"蠵"字才厉害——在古代汉语里面，"蠵"就是大龟的意思。所以"赤蠵龟"三个字合起来就是：红色大龟。起名字那个人真是懒醒，但又挺贴切。

你知不知道赤蠵龟有多大？成2米多长、500多斤重！是硬壳海龟里面最大的那只。想象一下，在海里游着游着，突然撞到个餐桌那么大的龟——不用问，肯定是赤蠵龟。科学家还发现过接近600斤的超级巨龟，真是龟中巨无霸。

但是啊，说到赤蠵龟，最惨的是它的身世。

大约300万年前，上新世纪的时候，中美洲突然从海里升上来——就像有个神秘力量拿横幅挡住你们一样，它将大西洋和印度洋-太平洋之间的海流彻底截断。赤蠵龟本来游得好好的，突然间路就不见了。

接着下来，地球进入冰川循环，冷水慢慢上升到好望角附近，海水温度大跌。赤蠵龟是要迁徙的嘛，但是这层冻水就像条冰墙，它们只能"望寒兴叹"——想游过去但是真的游不动。

最终，大西洋和太平洋的赤蠵龟被完全隔开，各自发展。就是这样，赤蠵龟一家被逼散，经历几百万年进化，变成两个不同的群体。

所以下次见到赤蠵龟，记得——这只龟不仅大，还要经历过沧海桑田那种全球地理大变动，是历史见证者来的。

顺便提一提，各位，接下来讲的，就是赤蠵龟最厉害的迁徙本能。

虽然被冰水阻隔，但赤蠵龟依然年年跨越大洋进行长距离迁徙。它们可以游成几千公里，从觅食区游到繁殖区，导航能力强到呢。

科学家发现它们主要靠地球磁场来定位，就像内置GPS一样，精准地知道自己在哪里、要去哪里。这种能力是天生的，不需要学，是几百万年里面刻入DNA里面的。
