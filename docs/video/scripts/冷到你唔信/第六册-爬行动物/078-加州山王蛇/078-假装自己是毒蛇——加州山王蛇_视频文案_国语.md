# 冷到你不信 - 加州山王蛇

无毒但装作有——加州山王蛇，有样学样，骗到你以为它很毒！

你可能会说，假装是毒蛇？为什么要假扮？因为怕被人欺负嘛！加州山王蛇生活在美国加利福尼亚州，是蛇类里面比较温顺，而且完全无毒——但是它有个很厉害的"保护色"！

兄弟们你知不知道加州山王蛇有多厉害？

它皮肤由红、白、黑等颜色组成，远远望上去像用好几种颜色的彩线编织成的艺术品！就像你穿了件名牌衫，走出街就说："我很贵，你不要搞我！"

但是！你知不知道有另一种蛇和它一样颜色——但是剧毒？

就是珊瑚蛇！红配黄，杀人狂——这句歌谣你听过吗？珊瑚蛇就是这样。但加州山王蛇就是红配黑——红配黑，不慌忙！所以呢，无毒的加州山王蛇就靠着像毒蛇骗人！

你知不知道加州山王蛇为什么可以生存？

因为它像毒蛇，所以捕食者见到它就怕——以为是剧毒的珊瑚蛇，不敢靠近！这个就叫做"借毒蛇的威名"！

所以下次见到红黑白相间的蛇，记住歌谣："红配黄，杀人狂；红配黑，不慌忙！"——红配黄就赶紧走，红配黑就可以松口气！

各位兄弟，接下来讲的，就是加州山王蛇最有趣的生存之道。

无毒但是像毒蛇，靠骗人生存——这个就叫做"扮猪食老虎"！虽然温顺，但因为会打扮，就生存到今天！
