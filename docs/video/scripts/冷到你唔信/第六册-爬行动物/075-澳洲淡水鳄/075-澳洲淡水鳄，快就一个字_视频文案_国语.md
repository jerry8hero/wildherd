# 冷到你不信 - 澳洲淡水鳄

快——就一个字——澳洲淡水鳄，游泳速度厉害到像只船！

你可能会说，澳洲淡水鳄？是不是很快？你如果这样想，就答对了！但你知不知道，这只东西其实小到呢——一般个体不到2米，只是可以欺负下锥吻古鳄和钝吻古鳄！但重点不是多大，而是一个字——快！

兄弟们你知不知道澳洲淡水鳄有多快？

游起来快、跑起来快、扑起来快——水里面可以捕锯鳐、硬杠巨蜥，还可以窜出水面抓飞着的狐蝠！这个就叫做"全能运动员"，不要看它小，它是速度型选手！

你知不知道澳洲淡水鳄为什么咬不死人？

因为它嘴巴太细长，咬合力不够——就好像用筷子夹东西吃，夹得到但是夹不紧！这个就叫做"工具不趁手"，想咬都咬不下！

但是！你知不知道澳洲淡水鳄其实都有咬人？

虽然小，但是澳洲当地有不少澳洲淡水鳄咬人致伤的记录！所以你不要以为它们是纯良无害——外表骗人，内心都想咬！

各位兄弟，接下来讲的，就是澳洲淡水鳄最有趣的生存之道。

不靠大只，靠速度；不靠咬力，靠灵活。就像你打游戏不靠装备，靠走位——这个就叫做"技术型选手"！

所以下次见到澳洲淡水鳄，记得——这是"快"字当头的"技术型鳄鱼"，不要被它小只骗到你！
