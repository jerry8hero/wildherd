# 冷到你不信 - 角蜥

兄弟们，喷血双眼、满身尖刺——角蜥的防御看到都心寒，但这招只用来对付狗！

好了，你可能会说，这家伙看起来像个菠萝包加了很多刺，它是蜥蜴来的？没错，角蜥就是美洲沙漠的原居民，它周身长满硬刺，就像披了件"铠甲"一样，谁敢靠近来侵犯，分分钟撞到你头破血流！

你知不知道角蜥那些硬刺有多厉害？

这些不是普通的鳞片来的，是爬行动物界里面一种很特别的结构设计。它不仅可以防御，还可以折射阳光，令到自己看上去大只一点——就像你戴了个超夸张的爆炸头，看上去头变大两倍，捕食者见到都不敢靠近一样。

不过呢，说到角蜥最夸张的技能，当然是喷血——动物界最奇葩的防御活动！

当角蜥遇到狗或者狼这些犬科动物追捕的时候，它会将自己头部的血压急速提升，眼角位置就会爆裂，然后——喷出一股鲜血！可以射到1米以外！

猜不到吧，这下不是普通呕血。角蜥食量大吃收获蚁，这种蚂蚁里面有些化学元素会在角蜥身体里面慢慢堆积，令到它的血带有一股很难闻的气味。喷出来呢，就像拧开了个"臭弹"，狗和猫科动物一闻——真的，宁愿饿死都不想再追！

所以呢，角蜥不仅是"铠甲战士"，还是"生化武器专家"！就像你和人打架打到近身，突然撩开衣服说"我有体臭，你怕没"——对手当然是先走再说！

顺便提一提，各位，接下来讲的，就是角蜥最厉害的沙漠求生技。

角蜥不仅防御厉害，它还会自己调节体温——靠晒太阳！

这种叫"辐射调节"的技能，角蜥可以通过调整自己身体的角度，控制吸收多少热量。早上呢，就侧身对着太阳，增大受热面；中午热辣辣，就将自己扁扁地摊在沙上面，减少受热——就像你自己在灵活走位，不同时间站不同位置！

而且角蜥配色很厉害，沙黄色加上深色斑纹，躺在沙面完全隐形。捕食者走过都看不到它——这个就是真正的"隐形术"，不是哈利波特才有啊！
