# 冷到你不信 - 暹罗鳄

人鳄表演明星——暹罗鳄，娱乐大众为己任，但表演背后是泪！

你可能会说，暹罗鳄？人鳄表演？是不是那种将只手伸入鳄鱼嘴里的危险表演？如果你这样想，恭喜你答对！但你知不知道，有多危险？

兄弟们你知不知道暹罗鳄有多大只？

雄性体长可达3到4米，性情凶猛！当它感觉受到威胁，会主动攻击人——所以这种表演就叫"玩命"，翻车惨剧不是没有！

你知不知道暹罗鳄为什么会出现在人鳄表演？

因为它们分布在东南亚，容易拿到。但这些表演者就是拿命拼——将手或头放入能咬断骨头的嘴巴里，不知是勇敢还是等死！

但是！你知不知道暹罗鳄其实有多危险？

当人在暹罗鳄生活的水体旁边活动，它发动攻击的可能性极高！而且咬下去可以咬断手指甚至整只手——这个就叫做"天然剪刀"！

各位兄弟，接下来讲的，就是暹罗鳄最令人心痛的事实。

它本来是东南亚河流的王者，但被人捉去表演——为了人类娱乐，要将自己置于危险之中。这个就叫做"强者被困"！

所以下次见到人鳄表演，记得——这是暹罗鳄，3到4米长，可以咬断你整只手臂，但是被迫为人表演！不要再看这种东西了！
