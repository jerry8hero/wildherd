# 冷到你不信 - 鬃狮蜥

下巴长"胡子"但是真的——鬃狮蜥，沙漠型男，厌春时块胡须会膨胀变深色！

我们今天讲只很有中东气质的蜥蜴——鬃狮蜥！

你第一眼见到它，可能会觉得：哦，这家伙下巴这么多东西，是不是整了假胡子博出位？你如果这样想，就大错特错了！它这坨东西不是假的，是真天生来的！江湖人称"胡子龙"，下巴那坨东西叫"颚须"，不是化妆化出来的！

说到鬃狮蜥的名字，就不得不佩服古人的想象力。它下巴那坨"胡子"其实是颚须，因为看上去像一头甩着鬃毛那样的狮子，于是就叫"鬃狮蜥"。这个命名真是很有趣，你说它像狮子，它就真有个"狮"字在名里面。

但是！鬃狮蜥最厉害的时候就是感觉到危险的时候！它会怎样？会将自己身体胀大，兼且将下巴那坨胡子都胀起来！远远望过去——哇，风水先生都不敢靠近！整头威风凛凛那样雄狮一样，你知不知道多有气势！

而且你知不知道？这个时候它的胡子会变色的！变黑色的！就像发出最后通牒：千万不要靠近，我不是开玩笑的！这个就是它们的"送你离开"警告模式，黑须一震，千里之外。

接下来讲的，可能很多人都不知道——鬃狮蜥不是只有雄性有胡子的！雌性都有的！只不过雄性就比较喜欢"显摆"，整天整大个下巴充大它。就像你见到个男孩整天炫耀他那撇很漂亮的胡子，你就知道这只是雄性鬃狮蜥来的。

各位兄弟，接下来讲的，就是鬃狮蜥最威风的场面。

当它觉得受威胁的时候，除了胀大身体、变黑胡子，它们还会张开嘴巴，露出橙黄色那样口腔！这是什么操作？就是典型地"虚张声势"——我很凶的，你不要过来！但其实呢？它可能只是样子凶，实际攻击性就像你见到鬼那样，其实是弹开三丈远都行的。

下次你见到鬃狮蜥，记得看清楚它那坨"胡子"——这个就是它们的身份象征，威风信号灯来的！
