# 冷到你不信 - 东部拟眼镜蛇

穿着丝袜就以为好斯文——东部拟眼镜蛇，其实挺毒！

你可能会说，精美丝袜？蛇？难道真的穿着丝袜？你猜错了！是1846年动物学家收集标本的时候，被它们身体表面网纹般的图案震撼到，感叹："这真像精美的丝袜！"——所以叫"精美丝袜"！

兄弟们你知不知道东部拟眼镜蛇有多常见？

澳大利亚东部、中部和新几内亚南部——干燥桉树林、荒地、热带草原林地、干旱灌木丛，甚至农田和偶尔洪水泛滥的地方——全部都有！有时在郊区、农场、建筑物后面、大石头下面、甚至垃圾堆里——都见到它！

你知不知道东部拟眼镜蛇有多毒？

澳大利亚第二毒的蛇——仅次于内陆太攀蛇！而且是伤人最多的毒蛇！但是呢，它们不会主动伏击人，受到惊扰才变得危险——这个叫做"人不犯我我不犯人"！

但是！你知不知道为什么叫"拟眼镜蛇"？

因为它们受到威胁时会将身体flatten，类似眼镜蛇的防御姿态——但其实不是真正的眼镜蛇，所以叫"拟"眼镜蛇！

各位兄弟，接下来讲的，就是东部拟眼镜蛇最令人惊讶的事实。

可以生活在垃圾堆里，但依然保持着"精美丝袜"的外观——这个就叫做"出得厅堂，入得垃圾房"！

所以下次见到网纹状的蛇，记得——这是澳大利亚第二毒但是"不主动犯人"的东部拟眼镜蛇！
