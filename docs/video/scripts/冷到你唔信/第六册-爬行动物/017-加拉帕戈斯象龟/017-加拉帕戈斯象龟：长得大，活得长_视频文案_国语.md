# 冷到你不信 - 加拉帕戈斯象龟

兄弟们，世界上最大型的龟，可以活过100年，达尔文的研究明星——加拉帕戈斯象龟，体型大过饭桌！

好了，你可能会说，象龟？是不是慢慢爬那种？我家那只龟也叫象龟啊。如果你这样想，就错了。加拉帕戈斯象龟可不是你想象中那种普通宠物龟，它是地球上现在现存体型最大的陆龟——注意是"现在"啊，一亿年前有更大的，但现在就是它称霸！

你知不知道加拉帕戈斯象龟有多巨型？成年身长可以到1.5米，不是开玩笑，真是到腰那么高！体重方面，平均175千克——这个是什么概念？就是差不多三部摩托车那么重，或者等于三个多四个普通成年男人加起来！如果你朋友说他180斤，不要理他，加拉帕戈斯象龟是175公斤，不一样的！

不过呢，说到体型大，科学家有个很有趣的预测。有科幻节目说，一亿年后地球可能会演化出一种巨龟，重得过现代大象20倍！20倍啊，大象已经是这么巨型，再乘20——这个就真是海陆空三栖最大生物了。但这个不关我们事，一亿年后我们早就不知去了哪里享受。

其实呢，你知不知道？加拉帕戈斯象龟是极度长寿的代表，野生平均寿命超过100岁！

100岁不是开玩笑，普通人奋斗一生都未必积累到的岁月，它们轻轻松松就抱住。但是这又有什么出奇呢？它们是冷血动物，新陈代谢慢到呢，吃一餐可以顶很久——像你们老人家说的，"慢慢吃，慢慢走"，结果就是慢慢活。

但真正厉害的是，2006年6月23号，澳大利亚动物园有一只叫"哈丽"的加拉帕戈斯象龟走了——走了是什么意思？就是去世了。它活了多少岁？170多岁！170岁是什么概念？就是说它出生那时候是清朝道光年间，定律还没变，电视电脑全部没发明，它已经在地球上慢慢爬。它当时是世界上发现的最长寿动物——注意是"当时"，因为后来又有新纪录，但你知不知道，170多岁已经厉害到离谱。

顺便提一提，说到体型大，就不能不讲象龟为什么这么大。

科学家发现，加拉帕戈斯群岛上面的象龟之所以长这么大，主要是为了储存水分和能量。岛屿资源有限，要慢慢"吃大一点"才可以度过艰难时期。但是现代研究发现，其实它们的新陈代谢很慢，理论上不需要这么大体积都可以活得久——这个就像你说减肥，但是就是瘦不下来。

这个就是大自然很有趣的东西：体型大不一定是为了生存，而是历史里面的偶然。造物主就是这么说：不如试下放大来！

各位，接下来讲的，就是加拉帕戈斯象龟最传奇的故事。

当年达尔文探访加拉帕戈斯群岛，注意到不同岛屿上面的象龟壳形有点不同——有点拱形，有点马鞍形。后来这个观察就成为他提出进化论的关键证据之一。所以呢，每只加拉帕戈斯象龟壳上面，其实刻着一段进化史的痕迹——这个才是真正的"活化石"！
