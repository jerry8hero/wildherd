# 冷到你不信 - 新疆沙虎

沙漠里面最安静的杀手——新疆沙虎，到你听到沙声都已经走迟了！

这期我们不讲龟，讲条"蜥"——新疆沙虎！听名字你以为是老虎吗？不是，但一样凶狠！

兄弟们你知不知道，新疆沙虎虽然只是一条蜥蜴，但维吾尔族人就不叫它"沙虎"，而是叫它"库莱伦"——翻译过来是"有手的蛇"！一条蜥蜴，为什么叫做"有手的蛇"呢？等我就告诉你，因为它样子真是像蛇多点，但四肢又挺短的，爬起来像只手在那里舞——就这样叫"有手的蛇"。这个命名，真是够贴切又够奇葩。

说到新疆沙虎，第一样东西就是——猜不到这么大只！它身长70到80厘米，在戈壁里面已经是巨物级别。但这个外表就骗得了人——看上去像条肥肥的蜥蜴，小小粒好可爱那样。你信它就死，这家伙脾气厉害过它的体型！

你知不知道新疆沙虎对声音有多敏感？在沙漠里面，它们对每一粒声音都当是生存警报！一有动静——火速走人！但如果你继续吵下去，慢慢接近它呢？这个时候它就不走了，在原地等你靠近，然后——狠狠咬你一口！这招叫什么？就像武侠片里面，你追我，我跑；但你追多两步，我就回身反杀！这个就是新疆沙虎的生存之道：你走我走，你来我就焗你！

说到新疆沙虎最厉害的东西，当然是它们的地下宫殿。

它们的洞穴很复杂，有些甚至有5条岔道！你以为它们是随便找个洞就钻进去？不是的，是正经的五房一厅！科学家推测，这么复杂的洞穴结构除了防御捕食者，还可以调节温度——热天时深处凉浸浸，冬天时又可以找到暖点的角落。这个就是建筑工程学应用到极致，你以为只有人类会起楼吗？爬行动物一样行！

你知不知道新疆沙虎分布有多广？从吐鲁番盆地——那里热到可以煮蛋——到海拔1700多米的高山，它们都可以活得好好地。吐鲁番夏天成40度，高山冬天得几度，这种温差，换着是我都顶不住，但新疆沙虎就当作是免费的冷气暖气——热天钻洞底，冻天找向阳位，这个就是真正的随遇而安。

说到新疆沙虎为什么可以生存在这种这么复杂的环境，就不能不提它的示警方式。

这家伙遇到威胁，不会第一时间就跑路，而是发出低微的声音警告你——这种声音像微微的嘶嘶声，就好像在你耳边说"你别过来啊"。如果你收声慢点，它就真的当你答应了，冲过来咬你一口！这种"先礼后兵"的策略，真是教精你——和人一样，不要欺负我，要你知道我不是你好惹。

各位兄弟，接下来讲的，就是新疆沙虎最有趣的地方。

这家伙外表像蛇像蜥蜴，小小只但脾气厉害；住在沙漠但最厉害的是地下工程——五岔隧道就是基本操作；听到声音就走，但慢慢接近就反杀；分布从火焰山到高山都行。这种"样样都不行但样样都行"的生存能力，就是新疆沙虎称霸戈壁的真正原因。
