# 冷到你不信 - 科莫多巨蜥

兄弟们，3米长、70公斤、一口毒液——科莫多巨蜥，不仅大，毒素才厉害！

好了，你可能会说，蜥蜴我见得多了，不就是壁虎那样？你如果这样想，就随你了。科莫多巨蜥可不是你想象中那种小孩子蜥蜴，它是世界上最大的蜥蜴，最大可以长到3米，重70公斤——就像一只狗那么大！一口咬下去，不仅是痛，它分泌的毒液会让你伤口血流不止，器官衰竭，慢慢等死。这个就是真正意义上的"毒蜥"！

你知道不知道科莫多巨蜥分泌的不是普通毒液？厉不厉害？厉害到呢！

科学家研究了好多年，之前大家都以为它是靠嘴里面的细菌搞死猎物，但是后来发现，不好意思，这个只是误解——它下颚有两个毒腺，真是会分泌抗凝血和降血压的毒素！被它咬一口，伤口血流不止，血压暴跌，一阵子就晕倒了，然后慢慢被吃。所以说，不要以为被咬到可以撑住，毒液慢慢发作就是等收工。

其实呢，你知不知道？科莫多巨蜥会吃同类的！夸张不夸张？

大只的科莫多巨蜥会吃小只的，有时候妈妈都会吃自己的宝宝！科学家观察到，在野外，大只有大概10%的食物来源是同类幼体。所以科莫多巨蜥宝宝想生存，出生之后要立刻学会躲起来——地上太危险，干脆爬上树顶避一避。小只的爬上树，吃年幼的鸟类和昆虫补充营养，等长大一点才下来。这个就是真正意义上的"大只就是爷"——小孩子永远都要低调行事。

不过呢，说到科莫多巨蜥最厉害的能力，当然是追踪猎物——隐蔽王者就是这么厉害！

它不仅跑得快，时速可以到20公里，还可以闻到几公里外的血腥味！舌头就像雷达一样，舔一舔空气，就知道哪里有东西吃。有科学家做过实验，将猪肉吊在树上，距离几公里，不够两个小时就被它找到。这个就是真正意义上的"用舌头看世界"——你只是停一停，它已经知道你在哪里。

试下想象一下，你在印尼科莫多群岛的草原上面慢慢走，突然间感觉到地面微微震动——是它来了。科莫多巨蜥潜伏在草丛里面，等你走近一点，然后突然出击，一下子咬住你大腿！你想走？不要白费力气，它追到你怀疑人生。

顺便提一提，你知不知道？科莫多巨蜥是一脚踏多船的！

繁殖季节，公蜥会为了争交配权大打出手——用自己强大的尾巴扫向对手，必要时连毒牙都用上。打赢了就抱得美人归，打输了就要等多一年。所以呢，公蜥之间的斗争绝对是激烈级别：不讲武德，只讲实力。赢了的可以同时管理几只母蜥，输了的只可以自己一个喝西北风。

各位，接下来讲的，就是科莫多巨蜥最离谱的进食方式。

科莫多巨蜥吃东西完全不用你想象中有款有型。一只70公斤的大只，一次过可以吃成20公斤肉——就像你一次过吃成40盒麦当劳外卖！吃完之后就找个地方慢慢消化，可以几个礼拜不用再吃。消化的时候它们会分泌一种特殊胃液，将骨头都溶解掉——就是这么夸张。所以呢，如果见到一只科莫多巨蜥静静地趴在那里，千万不要靠近，它可能只是饱到吐。

这个就是大自然最霸道的猎食者：不仅大，不仅有毒，还要懂得隐蔽等你中招——就是这样，你就是它的下一餐。
