# 冷到你不信 - 大鳞鳞虎

危险来了——丢鳞片！大鳞鳞虎，脱身技术一流，留下敌人在那里吃自己的鳞！

我们从头讲起。今天聊聊，兄弟们，讲只超级离谱的壁虎——大鳞鳞虎！

你可能会说，壁虎我见得多了，甩条尾就算厉害了吗？如果你这样想，就错了。大鳞鳞虎不仅甩尾，它竟然连鳞片都可以整块甩走！是的，你没有听错，它遇到危险的时候会将自己的鳞片——剥！下！来！然后裸奔逃走。这个才是真正的"我自闭了"，全身东西甩完，才走得掉。

更加离谱的是，它们不是住在普通地方，而是住在马达加斯加北部安卡拉纳国家公园的喀斯特石灰岩山里！这种地方什么环境？整座山都是石头，溶洞又多，普通人走进去都分分钟迷路。大鳞鳞虎就是在这种地方长大，修炼出一身特殊技能。

你知不知道大鳞鳞虎什么时候被人发现？

1867年，科学家正式发现了这个"鳞虎"家族——就是会因为自虐逃命而闻名的一族。但大鳞鳞虎就在家族里面最猛料，因为它们的鳞片是！最！大！的！就好像你们家有个亲戚整天教东西，但这个是教得最厉害的——是啦，它就是这样。

说到脱落鳞片，这个就厉害了——

科学东西来的，兄弟们你们不要错过！大鳞鳞虎的皮肤底有一层叫"肌纤维母细胞"的东西，这些细胞一收缩，鳞片就会从下面那层细胞分离。科学家帮这个位置改了个很贴切的名字——"撕裂区"。就像你剥贴纸那样，一撕就走——只不过大鳞鳞虎撕的是自己的鳞片，撕完还要裸跑！

但剥离鳞片不会痛吗？你问得好！它们就像有免疫系统那样，痛的感觉其实没这么厉害。可能就像你脱手皮那样，虽然有点痒，但不至于痛到走不动。

你知不知道？大鳞鳞虎不仅鳞片大，体型都挺巨型！

它们可以长到成30厘米那么长，是马达加斯加最大型的壁虎之一。住在喀斯特石山区，食物当然少不了——昆虫、小的脊椎动物，它都吃。但这个不是最厉害，最厉害是它们可以在很干旱的环境生存，还要晚上才出来活动。这个才是真正的夜行者：白天躲起来，晚上才出来搞事。

各位兄弟，接下来讲的，就是大鳞鳞虎最夸张的生存绝技。

大鳞鳞虎遇到天敌的时候，会立即进入"剥皮模式"——将自己外围的鳞片用力收缩，然后"啵"一声整块甩走！天敌：？？？难道我咬着整块？大鳞鳞虎就趁着你想着的时候，裸身逃走。

甩走的鳞片之后会再生，不过就要等好几个礼拜。所以你见到它们的时候如果发现它们穿着件"不合身"的衣服，不用问，先生它就是最近才甩完东西。

这个就是大自然最夸张的逃生术——宁可裸跑，都不要变成晚餐。
