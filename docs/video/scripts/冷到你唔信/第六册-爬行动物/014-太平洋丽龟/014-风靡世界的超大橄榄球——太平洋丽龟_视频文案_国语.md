# 冷到你不信 - 太平洋丽龟

兄弟们，橄榄球那么大的龟你见过没？太平洋丽龟——集体产卵名场面，成千上万只同时爬上岸！

好了，你可能会说，丽龟？听名字挺有趣。它又叫橄榄龟，你知不知道为什么？因为它只背甲像个橄榄球一样，心形那样，灰黑色，滑滑的——不说还以为谁不知道在哪里捡到个橄榄球。

更厉害的是，太平洋丽龟曾经是世界上数量最多的海龟！1968年，单是墨西哥海岸一年就被商业捕捞了100多万只！100万只啊，看到这个数字我都打冷颤——这个不是龟，是"海鲜的士"了！

但是啊，事情就在这里反转。

因为当年科学家太高估它们的数量，以为资源充足，结果过度捕捞一路狂飙。等大家反应过来，太平洋丽龟已经跌了三成有多——就像你以为虾有很多，结果眨下眼就不见了三成，还行不行？

其实呢，你知不知道？太平洋丽龟其实分布很广的——太平洋、印度洋、大西洋、非洲西海岸、南美洲部分沿海，全部都见到它们的踪影。一只龟游完整个地球，这个才是真正的"世界公民"！

顺便提一提，说到太平洋丽龟最厉害的，就是它们喜欢群聚——经常几千只一起上岸产卵，场面厉害过大片！但正是因为这样，当过度捕捞出现，它们特别容易中招。

这个就是典型的"你以为很多，但一跌就跌三成"的故事。

各位，接下来讲的，就是太平洋丽龟最不可说的悲情命运。

曾经它是海洋里面最多的海龟，1968年单年捕获量超过100万只。但是好景不常，因为数量被过度高估，商业捕捞一发不可收拾。到今天，全球总数比高峰期下跌超过30%——现在还是受保护的濒危物种。

所以下次见到太平洋丽龟，记得——这不是普通的龟，而是曾经的"海龟一哥"，现在只能低调生存。
