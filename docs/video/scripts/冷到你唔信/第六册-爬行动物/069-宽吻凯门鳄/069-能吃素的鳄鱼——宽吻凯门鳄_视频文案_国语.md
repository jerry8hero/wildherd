# 冷到你不信 - 宽吻凯门鳄

厉害就吃水草——宽吻凯门鳄，鳄鱼界的素食者，不关你事！

你可能会说，鳄鱼？不是都是肉食性的吗？但你知不知道，宽吻凯门鳄竟然会吃素！就是这么离谱，鳄鱼界的"异类"就是这只！

兄弟们你知不知道宽吻凯门鳄长得有多有趣？

顾名思义，它的嘴宽宽的——特别适合撕扯沼泽中茂密的植物。你以为它只是吃肉？由不得你不信，它竟然会吞植物！有科学家拍到它们吃一种叫"羽裂蔓绿绒"的果实——这个就叫做"鳄鱼吃斋"！

你知不知道？这个多厉害——宽吻凯门鳄可能是唯一会吃素的鳄鱼！

它们不仅会吃植物，科学家认为它们的行为还可以帮助植物传播种子。就是说，它不仅是猎人，还是"园丁"！这个就叫做"跨界合作"，大自然的创意真是超出你想象！

说到最奇葩，就是宽吻凯门鳄的"宽吻"有什么用——

宽嘴不仅可以撕植物，还可以很方便地叼住东西。而且因为这样，它们可以在水面大开嘴巴，晒下太阳——这个就叫做"享受世界"！

各位兄弟，接下来讲的，就是宽吻凯门鳄最有趣的生活习惯。

它们生活在南美洲东部、中部淡水沼泽和红树林，喜欢慢慢游、慢慢享受。有时吃下鱼虾，有时吃下植物，杂食得很——这个就叫做"佛系鳄鱼"，样样都不拒绝！

所以下次见到宽嘴的鳄鱼，记得——这个可能是会吃素的"佛教徒"，而且是南美洲沼泽地的"环保大使"！
