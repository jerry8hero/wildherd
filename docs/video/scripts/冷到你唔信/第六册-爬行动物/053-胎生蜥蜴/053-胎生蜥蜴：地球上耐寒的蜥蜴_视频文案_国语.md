# 冷到你不信 - 胎生蜥蜴

天寒地冻不用怕，胎生蜥蜴——北极圈最喜欢的蜥蜴，不用卵生直接生仔！

你可能会说，蜥蜴哦，常见啦，家后花园都见过啦。你如果这样想就错了。这家伙英文名叫"Common Lizard"，直译就是"普通蜥蜴"——但它一点都不普通！它竟然是地球上最耐寒的蜥蜴，在北极圈里面都有它的足迹！普通？厉害普通！

兄弟们你知不知道胎生蜥蜴可以去到多北？北极圈！零下几十度大雪纷飞那种地方！普通蜥蜴早就僵了冬眠，它竟然还可以动来动去找东西吃。这种抗寒能力，就像你冬天不穿棉衣还可以在街头走一样——它就是爬行动物里面的冰雪女王！

更厉害的是，胎生蜥蜴是直接生蜥蜴宝宝的！不落蛋的！

不要以为所有爬行动物都是下蛋再孵化的，胎生蜥蜴就是例外。它不落蛋，直接产下蜥蜴宝宝，就像绝大部分哺乳动物那样！你知不知道多离谱？爬行动物里面这样操作的不多，它就是那个最特别的存在。就像全班人都写纸质作业，突然有人交个USB——这种是逆向思维！

你知不知道？胎生蜥蜴分布范围很广，整个欧亚大陆都有它们的踪影！

从西欧到东亚，从北极圈到中部欧洲，到处都见到它。它就是爬行动物里面的"全球化物种"，无论哪个国家和地区都可以生存。这种适应能力，就像你身边那个什么地方美食都可以吃得下的朋友——哪里都行！

说到胎生蜥蜴最厉害的东西，当然是它的生存能力。

它可以在很寒冷的环境里面生存，冬天会进入冬眠，但它的抗冻能力厉害到呢，科学家发现它身体里面有特殊的"抗冻蛋白"，可以防止细胞结冰。就像你家的汽车antifreeze那样，零度以下都不会冻坏！这种技能树，大概就是它在北极圈附近都可以生存的真正原因。

你知不知道？胎生蜥蜴虽然分布广，但它们的生活习惯很低调。

它喜欢躲在草丛、石头缝、枯叶堆里面，不会大大方方晒太阳。它是典型的"社恐"选手，你想去野外看见它，不是这么容易。但它们的生命力就厉害在这里——低调那样生存，不张扬，不需要特别保护，不知多写意。

各位兄弟，接下来讲的，就是胎生蜥蜴最厉害的生存哲学。

它不靠厉害的攻击能力，不靠夸张的外表，就靠一样东西——适应。无论北极圈还是欧亚大陆，无论冰雪还是草地，它都可以找到生存的方法。这种"打不死"的精神，大概就是"Common Lizard"可以分布这么广的真正原因。

所以下次你见到一只小小只、颜色普通的蜥蜴，可能就是这位"北极圈原住民"！不要小看它啊！
