# 冷到你不信 - 吉拉毒蜥

兄弟们，毒蜥被咬可以顶6个月？吉拉毒蜥——毒素厉害到自己身体都顶不住，懒得理继续吃！

好了，你可能会说，蜥蜴哦，不就是变色龙那样？最多咬你一口肿一阵？朋友，你这样想就大件事了。吉拉毒蜥是北美洲唯一有毒的蜥蜴，它的毒厉害到可以搞到你进ICU！而且这种毒蜥在美国西部有个很恐怖的称号——"吉拉怪物"。传说它身体会散发出剧毒气息，一滴毒液就够你躺下。哇，多吓人啊！

但是啊，**知识点一：由不得你不信——吉拉毒蜥是恐龙同期生！**

你知不知道吉拉毒蜥有多老资格？它们在1亿几亿年前白垩纪就存在，是和恐龙一起走过地球的！当恐龙都已经变成化石，它还在那里慢悠悠地散步。这种生物见证了整个地球历史变迁，真真正正是活化石。就像你家有个老老年纪的祖先，看着你爷爷奶奶爸爸妈妈和你一起大，小时候就在那里，多厉害？

其实呢，**知识点二：毒液厉害到可以毒死人，但是抓猎物不用！**

吉拉毒蜥的毒液真是厉害，一滴就够你归西。但是它们猎食的时候竟然不用毒液的！它们猎东西靠的是强壮的下巴和扭力，咬住猎物就不放，扭来扭去将对方扭死。这个就好像你打火锅的时候夹着那样捞——不靠毒，靠蛮力！

但是如果你惹它呢？情况就不同了。一旦感觉到危险，它们就会用毒来保护自己。被吉拉毒蜥咬是什么感觉？亲历者说——"像热熔岩在血管里面流动"，痛到呢，厉害过生孩子！所以呢，遇见它最好就不要搞它，不然你就知道死了。

顺便提一提，**知识点三：吃东西很有趣——一次吃够三个月！**

吉拉毒蜥吃东西很有趣，它们主要吃鸟类蛋、细小型哺乳动物和其他蜥蜴。它们可以将超大份量的东西塞进肚子里面，然后一次过消化完。因为新陈代谢很慢，所以吃一餐可以顶一年！这个就像你一次过看完一整季剧——然后三个月不用再看。但这种"极端省力"生活方式，反而令到它们可以在沙漠这么恶劣的环境生存下去。

不过呢，**知识点四："吉拉怪物"其实挺静态**

美国西部流传很多关于"吉拉怪物"的恐怖传说，说它身体散发毒气，走过的地方植物都死了。但是呢，其实都是夸大的。吉拉毒蜥性格相当静态，大部分时间都在地下洞穴或者岩石缝隙里面休息。它们不会主动攻击人，除非你真的踩到它或者搞它。这个就像你家那只肥宅——平时就在沙发看电视，你不搞它它都不会理你。

**知识点五：稀有到列入附录——其实是受保护动物**

吉拉毒蜥虽然这么厉害，但它们其实是受保护物种。因为它们繁殖周期很长，每次才生2到13只蛋，而且孵化期很久，所以种群数量恢复得很慢。加上栖息地丧失，野生吉拉毒蜥就越来越少。所以呢，它们虽然是"怪物"，但现在反而要靠我们来保护。多有趣啊，强如"吉拉怪物"都要我们帮忙。

各位，接下来讲的，就是吉拉毒蜥最不可说的秘密武器。

说到最厉害的东西，就是它们的毒液其实是用来防守不是进攻。它们的毒腺在下颚，咬东西的时候毒液会通过牙沟慢慢渗入伤口。这个就像你用着防守装备，但是永远都不会主动出击——除非真的忍你不住。

科学家发现吉拉毒蜥的毒液里面有很多独特的成分，其中一种叫做"exenatide"的物质，后来被用来开发了一种叫做"Byetta"的药物，专门用来治疗糖尿病。所以呢，"吉拉怪物"虽然很疼，但它的毒液反而帮了很多病人。这个就是大自然的东西——危险的东西有时候也可以变成为人类服务的东西。
