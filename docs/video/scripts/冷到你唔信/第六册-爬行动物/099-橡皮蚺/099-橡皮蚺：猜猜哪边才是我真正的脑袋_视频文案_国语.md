# 冷到你不信 - 橡皮蚺

两边都像头——橡皮蚺，猜猜哪边是头？猜不到你试下！

你可能会说，蚺？不是都是大只东西吗？这家伙就不是——橡皮蚺可以说是蚺类中的"袖珍蚺"，一般长度不超过1米！而且样子两头都一样——圆钝形！

兄弟们你知不知道橡皮蚺有多有趣？

虽然缺乏一般蚺类可怕的上颚齿，但是有"铁头"——坚固的前额叶头骨！可以硬着头挖地洞，闯入鼠类洞里找东西吃！这个就叫做"用头行先"！

你知不知道橡皮蚺最搞笑的地方？

你分不清哪个头是真正的头！脑袋和尾都是圆钝形，特别容易骗敌人！有时还会将尾抬起来模仿移动的脑袋——这个就叫做"装头头"！

但是！你知不知道怎样分辨真头？

棕红色的小圆眼——这头就是真正的脑袋！看不到眼？就是尾！这个就叫做"找出真相"！

你知不知道橡皮蚺外号？

叫"铁头"——因为真是可以用头挖洞！但这个"铁头"不是讲笑，而是真的有东西——头骨硬到可以穿梭土壤！

各位兄弟，接下来讲的，就是橡皮蚺最令人疑惑的"哪个头"问题。

头尾都一样圆钝，连眼都细到看不清——但只要记住：棕红色小圆眼就是头！这个就叫做"记住这个就行"！

所以下次见到分不清头尾的蛇，记得——这是有"铁头"、喜欢用头挖洞、而且会伪装尾做头的橡皮蚺！
