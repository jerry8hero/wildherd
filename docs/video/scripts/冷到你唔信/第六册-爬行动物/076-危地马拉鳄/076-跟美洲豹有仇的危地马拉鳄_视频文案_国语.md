# 冷到你不信 - 危地马拉鳄

同美洲豹有仇——危地马拉鳄，见一个打一个，豹豹艰难！

你可能会说，危地马拉鳄？同美洲豹有仇？它们有什么过节？如果你这样问，就大错特错了——这个过节就大了！俗话说"一山不容二虎"，它们就是"一河不容二霸"！

兄弟们你知不知道危地马拉鳄和美洲豹打过几场？

有些——有人目击它们争中美貘尸体，危地马拉鳄率先发难，想将尸体拖入河里，但美洲豹就站在那里什么都做不到——这次是美洲豹输！

但是！你知不知道有场更厉害的？

有观察显示，危地马拉鳄成功杀死了一头美洲豹！就是说，鳄鱼可以杀豹——这个就叫做"冷血杀手"！

但是！你知不知道还有场更加惊险的？

有科学家就估计，离危地马拉鳄巢穴不到一百米，有一具危地马拉鳄尸体！而附近有美洲豹拖拽猎物的痕迹，一直延伸到那只死了的鳄鱼下面！这次是美洲豹反击——美洲豹复仇成功！

各位兄弟，接下来讲的，就是危地马拉鳄和美洲豹的"恩怨情仇"。

它们是中美洲地区两大霸主，时不时就要打一场。鳄鱼赢过，美洲豹也赢过——这个就叫做"大佬交锋，各有输赢"！

所以下次见到危地马拉鳄，记得——这是同美洲豹互相残杀过不知几次的"河中之霸"！
