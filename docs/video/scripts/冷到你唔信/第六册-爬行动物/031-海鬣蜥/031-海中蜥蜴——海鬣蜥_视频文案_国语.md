# 冷到你不信 - 海鬣蜥

蜥蜴下水游泳你信吗？海鬣蜥——唯一会游泳的蜥蜴，在大海吃海藻很爽！

今天聊聊，兄弟们，讲只厉害到你不信的爬行动物——海鬣蜥！

你没有听错，是蜥蜴，但是会游泳的蜥蜴！一只在大海里边游边吃生猛海藻的蜥蜴！不是骗你，是真的存在，它就是——海鬣蜥！

你可能会说，爬行动物不是只会在陆地爬的吗？什么时候轮到它们下海捞东西吃？由不得你不信，海鬣蜥就是爬行动物界的异类，是造物主吃饱饭太无聊整出来的奇葩作品。

海鬣蜥主要栖息在加拉帕戈斯群岛——就是赤道上面那个神奇群岛，整天都会有些稀奇古怪的生物在这里出现。这里就是海鬣蜥的主场。

兄弟们你知不知道海鬣蜥有多厉害？

作为爬行动物，它竟然可以在海水里边游泳找吃的！不要以为很简单——海水很冻的！海鬣蜥是冷血动物，体温会跟随环境变，落到海里边冻到震了。但这个不是问题——因为它们有自己的生存智慧。

---

说到海鬣蜥最厉害的能力，当然是——未下水，先热身！

你知不知道，海鬣蜥下海之前，会先找块岩石趴起来，利用太阳的能量将身子晒暖——这个就像充电那样，晒够了才下水。就像你去冻水池游泳之前，要先在岸边做热身操那样，不过它是靠晒太阳来热身，是纯天然的太阳能发热。

这个就厉害了：身为爬行动物，用太阳的热量来做活动能量，晒到暖暖暖再下水找吃的——就像你去buffet之前先在家吃饱那样，先warm up再冲！

你知不知道海鬣蜥为什么不会被海水冲走？

海鬣蜥对爪像钩子那样，密密麻麻地抓紧海底岩石！这个就厉害了——一爪下去，想被冲走都很难。它们就像攀岩高手那样，在海底的岩石上面稳稳地找吃的，任凭海浪怎么冲都不怕。

而且它们游泳的姿势很有型——S形那样摆动尾巴，就像条鱼一样，流畅到呢！

你知不知道海鬣蜥吃什么？

成年雄性海鬣蜥主要吃海藻和海底岩石上面的植物——是素食者来的！不过小的时候不同，它们会吃昆虫和海中小动物，慢慢大了才转素。

但重点不在这里——重点是：海水很冻，而爬行动物需要热量来消化食物。它们就发明了一个很厉害的操作：吃饱之后迅速游上岸晒太阳，继续充电！就像你吃完饭不立即坐下，而是去做运动帮助消化——不过它是靠晒太阳来消化，是真正的太阳能消化系统。

说到海鬣蜥最特别的东西，当然是——它们是唯一会游泳的鬣蜥！

整个蜥蜴家族里面，只有它一个可以在大海里边自由地游。这个就厉害到呢——几千万年前，它们的祖先决定下海找东西吃，结果竟然适应了海的生活，演化成了现在这个样子。

科学家发现，海鬣蜥的祖先可能在南美洲大陆生活，后来漂流到加拉帕戈斯群岛，发现陆地上没什么竞争对手，食物又丰富——然后就慢慢适应了海边和海洋的生活。所以这个就是典型的"找到蓝海就转型"例子。

各位兄弟，接下来讲的，就是海鬣蜥最不讲武德的生存技能。

海鬣蜥有个很厉害的技能——它可以在水下边停车！

你没有听错，真是停车——就这样悬浮在海中间，一点都不游，靠的就是它的密度低、骨骼轻、还有肺部空气多。所以它可以静静地在这里休息，等太阳继续帮它热身。

这个就像你打游戏的时候暂停一样，暂停一阵再继续——不过海鬣蜥是真·暂停，等身子暖多点再继续找吃的。

而且海鬣蜥懂得喷盐！不是打喷嚏，而是通过鼻盐腺将多余的盐分喷出来——喷出来很咸的！是真正的海水淡化器来的！
