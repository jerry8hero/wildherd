# 冷到你不信 - 犰狳环尾蜥

有只蜥蜴转圈圈像轮胎——犰狳环尾蜥，遇到危险卷成一个刀片连环！

你可能会说，犰狳我们听说过，就是那个会卷身的刺猬那样，但你知不知道，爬行动物里面也有个"犰狳"？没错，就是我今天要讲的——犰狳环尾蜥！这个名字已经很有料到啦，它既像犰狳那样穿着副"铠甲"，又有环尾蜥的身份，是非洲南部沙漠的原住民。

兄弟们你知不知道？犰狳环尾蜥的名字就说明了它这套防御系统有多厉害！

"犰狳"这两个字，其实就是讲它身上那副"铠甲"像美洲犰狳那样，无坚不摧。美洲犰狳出名到怎样？连子弹都打不穿的哺乳动物，它多硬啊！犰狳环尾蜥就有样学样，整出一副硬壳来保护自己。但是，它比犰狳还厉害——这副铠甲不止硬，兼且带刺！突出鳞骨的鳞甲硬刺，全身都是尖锐的东西，看见都痛。你以为它只是靠块硬壳防身？由不得你这样想，这个是全方位立体式防御刺猬Plus Max！

不过呢，万事都有例外——它个肚就比较柔软。

你知不知道，犰狳环尾蜥只有个肚是软的？全身都是刺，但个肚完全相反，白净光滑，柔软得像我们的笑脸那样。这个就是它的最大弱点！所以呢，遇到敌人或者受到惊吓，它就会使出终极奥义——咬住自己条尾，变成一个车轮的形状！这下就厉害了：刺全部向外突，硬壳包住个肚，捕食者望着这个"刺猬车轮"，哪里下嘴？不知咬哪里好！就好像你见到一个全身是刺的海胆刺身，不知从哪里入口——是那样的感觉。

说到这招"咬尾车轮防身术"，就不得不提它的身体结构。

犰狳环尾蜥咬住尾之后，整条身会卷成一个完美的圆环，靠着鳞甲之间的关节锁死，这样就完成了一个"金刚不死身"。这一招什么时候用得着呢？当它受到惊吓，或者敌人扑过来，它就会立即启动防御模式——一口咬住尾，卷成刺球，舍不舍得下都不关你事。如果敌人还是这么聪明想进攻？好，刺到你喊！这个就是真正的"全身带刺，不要靠近"。

各位兄弟，接下来讲的，就是犰狳环尾蜥最厉害的沙漠生存之道。

虽然全身都是刺，但这个非洲南部沙漠居民，其实是怕东西来的——它最喜欢吃蟋蟀、昆虫和小的蜥蜴，是个挺温和的猎食者。昼伏夜出，白天就躲在岩石缝隙里面享受冷气，太阳落山才出来找东西吃。就像我们的宅男宅女哦，天天就是吹空调叫外卖，周末才出来放风——完全是动物界的"社恐代表"。

但是，不要以为它只是被动防御骗你！当它真的要认真打架，犰狳环尾蜥可以靠着鳞片肌肉快速移动，在岩石上面走起来很快！它的最高时速可以说是"沙漠竞速选手"级别——虽然不是说什么多厉害，但对于一只主要靠防御的蜥蜴来说，这个速度已经厉害过好多对手。
