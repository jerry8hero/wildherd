# 冷到你不信 - 花龟

兄弟们，商朝人就已经养的龟，花龟——3000年前的宠物，身份证书比好多国家都老！

好了，你可能会说，花龟？是不是就是花纹好看的龟？你如果这样想，就太简单了。花龟不仅花纹漂亮，它还是3000多年前的商朝人用来写甲骨文的"御用龟种"！什么石破天惊？等你慢慢听下去。

你知不知道？商朝人占卜最喜欢用花龟！

在3000多年前的商朝，王室整天都要搞占卜，问天问地问收成。占卜的方式就是在龟甲上面刻字，然后烧看裂纹断吉凶。考古学家研究完发现，商朝人最喜欢用的龟甲有两种——草龟，和花龟！但是问题来了：花龟现在主要分布在华南地区，但是河南安阳这些中原地方，刚好就是商朝首都遗址，在这里发现了大量花龟甲！就是说，3000多年前，花龟的分布范围比现在宽很多——大概气候变暖或者其他原因，花龟就慢慢退守到南方去。这个叫做：沧海桑田，龟都会走位。

但是啊，你知不知道？花龟也是"南越王"的爱！

不仅商朝人喜欢花龟，秦汉时期的南越王都一样！在广州发掘的南越王墓里面，考古学家发现了不少花龟甲碎片——你就知道花龟多厉害了。古代宫廷不是你说想养就养，要有身份才行。花龟可以说是龟里面的"贵族"，见证着整段中国历史添！

其实呢，说到花龟最有趣的东西，当然是它们的花纹——天然的水墨画就是这样！

花龟的样子就像大自然随手画的艺术品，壳上面有不规则的黄色和黑色条纹，好像山水画一样添！所以好多爬友都喜欢养花龟，不仅因为它性格温顺，还因为它真的很有看头——就像养着一幅会游动的水墨画。

顺便提一提，你知不知道？花龟是淡水龟里面比较常见的一种，但是脾气好到不得了！

不少龟仔咬人咬到飞起，花龟就相对温和很多，不会无缘无故就向你示威。就像龟里面的"文青"，性格安静，喜欢慢慢游水的——但是你不要以为它好随便，它游起水来灵活到你不信，水面转身、水底漫步，样样都行！

各位，接下来讲的，就是花龟最厉害的生存技能。

花龟虽然性格温柔，但是它懂得适应不同的环境！华南地区的池塘、沼泽、河流它都可以生存，冬天冷的时候它会钻入泥里冬眠，等春天暖了才出来。就像一个懂得见机行事的"淡水精灵"，天冷就睡，天热就活动——活得多机灵！
