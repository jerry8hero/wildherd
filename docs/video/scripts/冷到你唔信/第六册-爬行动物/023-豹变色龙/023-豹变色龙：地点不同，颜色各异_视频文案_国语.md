# 冷到你不信 - 豹变色龙

兄弟们，在非洲住在山上，落到山谷，颜色竟然会变？豹变色龙——看地方换衣服，撞色大师！

好了，你可能会说，变色龙我见得多了，不就是绿色那样？你如果这样想，就错了。豹变色龙可不是你想象中那种普通绿色变色龙，它的身可以变到五颜六色，而且不同地方出身，颜色完全不同——是地理因素决定的！这个就是今天要讲的重点：地点不同，颜色各异！

你知不知道？豹变色龙是马达加斯加的特有种！

不要看它叫"豹"，就以为它身上有豹纹——完全不是那么回事！它之所以叫"豹变色龙"，是因为它是变色龙里面体型比较大只，而且颜色鲜艳，有点像豹皮一样。但是呢，它真身是完全没豹纹的——就是颜色漂亮而已！

但是啊，说到颜色，就是豹变色龙最厉害的地方。

不同地区的豹变色龙，颜色完全不同！就像你在不同省份读大学，不用四年就自动换了套校服——基因不改，但外观就变完！

贝岛、安基菲和安班扎这三个地方的豹变色龙，全部都是耀眼的蓝色为主！蓝色的！想象一下，一只全身蓝色的蜥蜴，在树上面慢慢地动——多梦幻！不过这种蓝不是普通蓝，而是有种金属感的蓝，像你们手机壳表面的渐变蓝——就是这么厉害！

但是，如果你去到安比卢贝、安齐拉纳纳、桑巴瓦这些地方，蓝色就完全消失了！这里的豹变色龙全部变成红色、绿色或者橙色。就像你由广州、上海、北京三个地方买同一款车，但一落地就自动变成不同颜色——由不得你不信！

而马鲁安采特拉和塔马塔夫呢，红色就是主色调！这两个地方出的豹变色龙，红到就像着火一样——但是放心，不会真的烧着你，只是颜色鲜艳得过分！

其实呢，你知不知道？科学家为什么要研究这种地理颜色差异？

因为这种现象叫"地理变异"——同一个物种，不同地方会有不同外表。豹变色龙就是研究这种东西的完美对象，毕竟颜色差别实在太明显！就像你看地图，不同省份不同天气预报——但豹变色龙不用看天气预报，它自己就是天气预报！

顺便提一提，说到生存环境，豹变色龙就厉害了。

它喜欢住在干燥的森林或者草原地区，但是呢，它们完全不抗拒人类！在道路附近、房屋旁边、甚至种植园里，都可以见到它们的踪影。就像你在城中村发现一只野生豹纹——不用惊讶，它已经习惯了和人挤在一起住！

这种适应能力，多厉害？就像你city walk那样——它都可以在人类的地盘找到自己的生存空间。

各位，接下来讲的，就是豹变色龙最神奇的地方——颜色不仅用来隐身，还用来沟通！

豹变色龙的颜色变化，其实大部分时候不是为了隐身，而是用来表达情绪！当它们害怕的时候，会变暗；当兴奋的时候，会变亮；当想威胁对方的时候，会变到最鲜艳！就是蜥蜴界的"情绪指示灯"——但这只指示灯不帮你找路，只帮你表达内心世界！

所以下次见到豹变色龙变色，不要只是想着"哇，隐形！"——它可能只是想告诉你：我现在心情不好！
