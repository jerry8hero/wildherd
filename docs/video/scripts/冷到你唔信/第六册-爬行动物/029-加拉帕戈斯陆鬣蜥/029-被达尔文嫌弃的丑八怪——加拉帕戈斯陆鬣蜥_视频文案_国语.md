# 冷到你不信 - 加拉帕戈斯陆鬣蜥

兄弟们，达尔文嫌弃到写下说"好丑"，但它其实挺可爱——加拉帕戈斯陆鬣蜥，丑出自信！

好了，你可能会说，陆鬣蜥？又是鬣蜥？我见得多了！慢着，这家伙当年被达尔文嫌弃到贴——它是这样形容的："上半身橘黄色，下半身红褐色，长得又蠢又难看！" 我就问：达尔文叔叔，你多厉害观察到这家伙这么丑？

不过话说回来，我反而觉得这家伙挺可爱——像只橙色加红色加起来的大型变色龙，又像条穿错颜色的大蜥蜴。但这种独特配色，不知是什么潮流风格呢？

你知不知道加拉帕戈斯陆鬣蜥的生活多舒服？

白天就趴在火山岩上面享受世界——就这样摊开四肢，让太阳公公帮它们取暖。这种生活态度，我只有两个字：羡慕！如果我们人类也可以天天趴在石头上晒太阳，不知多爽。

但是啊一到晚上，就不同说法了——它们会乖乖地钻回自己的洞穴里面，盖好被子盖到严严实实，这样才可以维持体温。你知不知道，爬行动物没有自己的体温调节系统，它们是靠环境来控制体温的！就像你冬天焗在被窝里面，不想出来——但它们是白天焗太阳，晚上焗被窝，认真会享受。

其实呢，说到最厉害的，就是它们会合作——动物界的互利共生，就是这样！

加拉帕戈斯岛上有一些有趣的小鸟，这些小鸟专门跳上陆鬣蜥身上，帮它啄走那些虱子和寄生虫——陆鬣蜥当然不动，等着小鸟帮它免费grooming。

这个时候陆鬣蜥当然——"你吃你的，不要搞我"。小鸟就这样吃寄生虫吃到饱，双方都满意，合作共赢！你说多和谐？

这种关系就像你去餐厅吃饭，有人为你剥虾，有人帮你剔牙——你就坐在那里什么都不用做，舒服！

顺便提一提，你知不知道？这种跨物种合作在自然界其实挺常见，但每次见到都会觉得造物主真是什么东西都想得出！

各位，接下来讲的，就是加拉帕戈斯陆鬣蜥最有趣的外貌特征。

达尔文嫌它丑？我就不觉得。它们上半身橙黄色，下半身红褐色——这种撞色搭配，如果是人类穿衣服，肯定被说不会穿。但放在动物界，就变成独一无二的标志。

而且你知不知道，这家伙虽然样子丑丑，但是有几百万年前就住在加拉帕戈斯群岛上面——是岛上的原住民来的！比达尔文来的时候早到几百万年。所以说，论资排辈，它才是大佬！
