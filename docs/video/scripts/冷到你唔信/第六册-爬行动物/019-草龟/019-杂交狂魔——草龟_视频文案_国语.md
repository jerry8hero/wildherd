# 冷到你不信 - 草龟

兄弟们，龟中杂交狂魔！草龟什么都配，不同品种生出来的样子完全猜不到——基因彩票就是这样！

好了，你可能会说，草龟？养龟的谁不认识啊，宠物市场经常看到的不就是它？你如果这样想，就太低估它了。草龟是龟界的"杂交狂魔"，它竟然可以和十几种龟杂交，而且生出来的后代还可以继续繁殖！这个就不是普通龟做得到的事。

但是啊，说到草龟，第一个要讲的当然是它们的"混血基因"。

草龟学名叫做"黄缘闭壳龟"，是我们国家本土原住民，分布广到哪里都见得到它。就是因为这样，它成为了龟界的"万人迷"——为什么？因为它可以说是龟类杂交的"万能接口"！

它不仅可以和其他草龟繁殖，还可以和花龟、黑颈龟、喉龟等等十几种龟杂交，生出一大堆稀奇古怪的"混血宝宝"。有些遗传了草龟的外表，有些就像另一只龟，最夸张的是有几胎混血龟仔再和其他龟杂交，生出更加复杂的品种——这个就叫做"杂交迭代"，龟界版的混血王子！

由不得你不信，草龟就是龟界的"社交达人"，谁来都可以搞定。

其实呢，但是，草龟最厉害的不止是杂交，还有一样东西——变色！

不是开玩笑，草龟真是会变色的。不同地区、不同环境养的草龟，颜色可以差很远：有些是金黄色，有些是深棕色，有些竟然可以变成黑色！

这种现象生物学家叫做"拟色"，就是为了适应环境。养在浅色环境的草龟，颜色会慢慢变淡；养在深色环境的，就慢慢变深。就像你换了件衣服那么醒目！

所以如果你见到一只黄色草龟，不要以为它是基因突变，它可能就是因为住的环境不同，这个才是真正的"养龟如养色"。

顺便提一提，说到草龟，就一定要提它们的"壳仔"——硬壳，但是又可以闭合。

草龟属于闭壳龟属，意思就是背甲和腹甲之间有韧带连接，让它可以完全闭合！遇到危险？收！捕食者想咬？闭！完全密封就像个保险箱一样。

但是，闭壳不代表无敌——它们最怕的不是天敌，而是人类。

为什么？因为草龟的壳太漂亮了！金黄色的壳身，配埋黑色边线，看上去就像一件艺术品。偏偏我们国家有些地方觉得草龟是"滋补珍品"，说它的壳可以入药，结果搞得野生草龟数量越来越少。

现在草龟已经被列入国家二级保护动物，不是你想养就养，想买卖就买卖的了。

各位，接下来讲的，就是草龟最厉害的生存技能。

草龟是龟界里面最"百搭"的选手——不仅可以水里游，还可以陆地行走，是我们国家分布最广的龟种之一。从东北到华南，从山区到平原，什么环境都可以生存。

它们是杂食性的：鱼、虾、昆虫、水草、果实，什么都吃。有一餐吃一餐，不挑食就不怕饿——这个就是务实主义。

但最厉害的是，草龟很少生病。是的，你没有听错，野生草龟很少会出现龟类常见的腐皮、肺炎这些问题。它们的免疫系统厉害到你不信，可能就是因为杂交得多，基因库够强大——混血基因不仅繁殖厉害，还兼顾免疫力！

这个就是草龟：杂交狂魔、色都会变、夏眠就享受、壳硬到像保险箱，但最厉害的是——什么都不怕，生存力爆灯。
