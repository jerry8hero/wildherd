# 冷到你不信 - 响尾蛇

条尾有部鼓——响尾蛇，沙沙声就是它的Music，不要跟着唱！

你可能会说，响尾蛇？尾巴会响的？你猜对了！它尾末端有"响环"，受到威胁时会振动发出声音——就像在那里说："不要靠近，再靠近我就咬你！"

兄弟们你知不知道响环怎么形成？

响尾蛇每蜕皮一次，尾上就会留下一个空心的"尾节"！一年到头蜕好几次皮，所以尾上的空心尾节越积越多，串成"响环"——这个就叫做"时间沉淀"！

你知不知道响尾蛇怎样捕猎？

吃兔子这些小动物，用毒液制服猎物。如果猎物被咬了但跑掉，响尾蛇会静静跟踪，等猎物毒发才再回去慢慢享用——这个叫做"跟踪战术"！

但是！你知不知道响尾蛇家族毒性怎样？

这只红菱斑响尾蛇的毒性在响尾蛇家族里面算比较弱——但被咬一口依然危险！所以无论如何都不要伸手去摸！

各位兄弟，接下来讲的，就是响尾蛇最有趣的"警报器"。

尾上响环，威胁时振动——这个就是天然警报器！而且不仅可以警告敌人，还可以警告同伴："有危险，快走！"——这个就叫做"一键求救"！

所以下次见到尾会响的蛇，记得——这是有"警报器"的响尾蛇，不要随便伸手！
