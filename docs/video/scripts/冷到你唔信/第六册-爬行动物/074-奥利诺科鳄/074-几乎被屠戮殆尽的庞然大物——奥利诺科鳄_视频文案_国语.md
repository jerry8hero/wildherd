# 冷到你不信 - 奥利诺科鳄

打到快绝种——奥利诺科鳄，人类疯狂屠杀，现在只剩少量！

你可能会说，奥利诺科鳄？有多大只啊？这只可以说是南美洲的"鳄鱼之王"！成年雄性可以长到6米，雌性平均体长超过3米——这个就叫做"鳄鱼巨无霸"！

兄弟们你知不知道奥利诺科鳄有多厉害？

被认为可以和黑鳄并列的"美洲鳄鱼之王"！而且寿命很长，可以达到80岁——80岁啊，够一个人由出生到退休再找工作两次！

但是！你知不知道奥利诺科鳄有多惨？

20世纪60年代，分布在委内瑞拉、哥伦比亚等地的奥利诺科鳄几乎被屠戮殆尽！为什么？因为它们的皮太好卖——皮包、皮带、皮鞋，全部都想要！为了漂亮，人类可以有多绝？看看奥利诺科鳄就知道！

你知不知道？奥利诺科鳄从"鳄鱼之王"变成"濒危物种"——

就是因为一张皮！人类想要漂亮，它就要用命换——这个就叫做"美丽的代价"。80年代开始保护，但是已经太迟——数量已经恢复不到了！

说到最惨，就是奥利诺科鳄的皮——

一张皮可以做多少个皮包？几十个？几百个？为了人类的时尚，不知有多少奥利诺科鳄失去了宝贵的生命——这个就叫做"时尚受害者"！

各位兄弟，接下来讲的，就是奥利诺科鳄最令人心痛的事实。

从6米巨兽到几乎灭绝，只因为人类想要它的皮！80年寿命，但是不够80年，人类就将它杀到差点绝种——这个就叫做"人类多厉害"！

所以下次见到皮制品，记得——这个可能曾经是一只80岁的"鳄鱼之王"！
