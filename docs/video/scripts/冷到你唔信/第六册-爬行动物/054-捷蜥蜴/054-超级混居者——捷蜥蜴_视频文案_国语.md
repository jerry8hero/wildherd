# 冷到你不信 - 捷蜥蜴

东欧到西亚，城市到乡村——捷蜥蜴，谁说蜥蜴就一定恶样？

你可能会说，蜥蜴我见得多了，不就是到处爬那些？你如果这样想就错了。捷蜥蜴可不是你想象中那种普通蜥蜴，它竟然可以在草原、森林、果园、灌木丛、谷地什么都找得到吃！最离谱是，海拔2000米以上的高山都有它们的足迹——这个不就是真正的"浪子"了，周游列国，哪里都是家。

兄弟们你知不知道捷蜥蜴多厉害？它是爬行动物界的"交际花"！

科学家在新疆发现，捷蜥蜴可以和好多其他动物"混居"。和敏麻蜥和谐共处，什么事？两个不同物种竟然可以一起生活，不用打不用闹，就像两个老友记围埋一起聊天。

更厉害的是，捷蜥蜴竟然可以和某些蛙类亲密接触——蜥蜴和青蛙？这个组合本身就够奇葩了，但它们竟然可以埋在一起吃东西，不知道还以为它们是亲戚。

但最离谱的还在后面——捷蜥蜴竟然敢和含有剧毒的中介蝮待在一起！中介蝮是什么？毒蛇来的，一口可以取你命。但捷蜥蜴就偏偏可以在这种毒蛇身边走来走去，还要什么事都没有。这个就像你在老虎笼里面散步，还要帮老虎刷牙——不知你厉害在哪里。

说到为什么捷蜥蜴这么厉害，可以和不同物种相处，科学家就觉得，可能是因为它性格比较随和，不会怎样主动攻击人。而且它们的生存能力厉害，适应力强，在哪个环境都可以找到方法生存——就像一个语言天才，英文行，普通话行，粤语都行，在哪个国家都沟通无障碍。

兄弟们你知不知道？捷蜥蜴在交配季节，就会变成"打仔"！

每年到了繁殖季节，雄性捷蜥蜴就会为了争女孩子大打出手。它们会互相追逐、撕咬、压制，就像两个年轻人在篮球场上面那样。但有多刺激？就是这些打斗可以很快搞定——有些只是几秒钟，一下就分出胜负；但有些就厉害了，可以打超过15分钟，就像一场持久战那样。

想象一下，两个男孩为了女孩子在那里打架，打到一半突然停低大家休息一阵，然后继续打——这个就是捷蜥蜴的爱情故事，充满着戏剧性。

各位兄弟，接下来讲的，就是捷蜥蜴最厉害的生存之道。

它的足迹遍布各地，从草原到高山，从森林到果园，什么环境都可以生存。而且它们可以和不同物种和平共处，这种能力就叫做"超级适应者"——无论环境怎么变，它都可以找到方法活下去。

这个就教懂我们一样东西：在这个世界上面，谁可以适应，谁就是赢家。
