# 冷到你不信 - 海岛竹叶青

蓝蛇——但不青——海岛竹叶青，蓝色的竹叶青，稀有品种！

你可能会说，蓝蛇？世界上真有蓝色蛇？你没有看错！就是海岛竹叶青！不过其实蓝色只是少数，大部分都是绿色——但是蓝色那部分特别惊艳！

兄弟们你知不知道蓝色海岛竹叶青有多厉害？

蓝色分布最高可达海拔1200米！平时喜欢待在树上，到了交配季节或者下完大雨才下树——这个就叫做"树居者"！

兄弟们你知不知道有个很有趣的问题？

蓝色海岛竹叶青是不是临时变了色的绿色竹叶青？就像变色龙那样？澳大利亚博物馆专家解释：蓝色海岛竹叶青不变色，它们本来就是蓝色的，一生都是蓝色！这个就叫做"天生蓝"！

但是！兄弟们你知不知道有另一种蛇会怀孕时变蓝？

生活在澳大利亚北部的"绿树蟒"会在怀孕的时候临时变成蓝色——但是海岛竹叶青就不同，它是一辈子都是蓝色！

各位兄弟，接下来讲的，就是海岛竹叶青最有趣的蓝色。

蓝色海岛竹叶青，天生就是蓝色，不会变色——这个就叫做"基因决定"。而且它们只生活在东南亚那些海岛上，是"地方限定"物种！

所以下次见到蓝色蛇，记得——这是天生蓝、不会变色、一辈子都蓝的海岛竹叶青！
