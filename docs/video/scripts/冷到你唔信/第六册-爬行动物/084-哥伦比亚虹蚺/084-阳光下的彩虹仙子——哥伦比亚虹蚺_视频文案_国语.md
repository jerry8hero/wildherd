# 冷到你不信 - 哥伦比亚虹蚺

七色彩虹现身——哥伦比亚虹蚺，光照不同角度，色彩说变就变！

你可能会说，哥伦比亚虹蚺？明明是棕色的，为什么叫"虹"？你这样问就对了！其实如果你在明媚的阳光下观察它，就会发现它们的鳞片会反射出迷人的彩虹光泽——这个就是"虹"的由来！

兄弟们你知不知道哥伦比亚虹蚺有多厉害？

游泳高手——在水里面游得飞快！但它还懂爬树！遇到敌人？上树！水陆两栖，样样皆能——这个就叫做"全能运动员"！

但是！你知不知道哥伦比亚虹蚺有个秘密？

它们晚间才出没，而且在晚上会变色！黑漆漆的夜幕下，它们身体侧面和肚会变成皎洁的银白色——这个就叫做"夜间变身"！

你知不知道哥伦比亚虹蚺年轻和老时生活不同？

年轻的时候多在树上生活，年龄大了就多在陆地——就好像你小时候喜欢攀爬上床，大了就喜欢睡地板！这个就叫做"成长变化"！

各位兄弟，接下来讲的，就是哥伦比亚虹蚺最有趣的"彩虹光泽"。

棕色底色加彩虹光泽，就像穿着彩虹衫在阳光下逛街——多厉害！而且懂游泳又懂爬树，夜晚还懂变身——这个就叫做"多才多艺"！

所以下次见到哥伦比亚虹蚺，记得——这是可以变色的"彩虹仙子"，懂游泳懂爬树，夜晚还懂变身！
