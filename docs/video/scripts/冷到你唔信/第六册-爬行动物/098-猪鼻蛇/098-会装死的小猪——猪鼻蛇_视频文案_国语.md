# 冷到你不信 - 猪鼻蛇

害怕就装死——猪鼻蛇，奥斯卡欠它一座小金人！

你可能会说，猪鼻蛇？鼻子像猪鼻？你猜对了！它的鼻子向上翘，就像装了个猪鼻——而且不是摆设，有科学家认为这种鼻子能帮它在沙土里高效地挖掘！

兄弟们你知不知道猪鼻蛇有多搞笑？

遇到危险时会先吓你——将脖子膨胀变扁平，发出嘶嘶声警告你！但如果这招不work，它就会装死——翻身仰卧，张大嘴，伸出舌头，从泄殖腔喷出难闻气味！如果你还没走，怎么办？
重新再来一遍——再仰卧！这个就叫做"坚持就是胜利"！

你知不知道猪鼻蛇有多不喜欢咬人？

平时特别不喜欢"动口"，但必要时都会假装攻击一下——但是绝大多数时候都是说不喜欢咬！这个叫做"和平主义者"！

你知不知道猪鼻蛇有个有趣的名字？

叫"小猪"——不仅鼻子像猪，还要喜欢挖土——就像小猪喜欢拱泥一样！所以叫猪鼻蛇就是"小猪蛇"！

各位兄弟，接下来讲的，就是猪鼻蛇最有趣的装死技能。

装死就是的，而且是"坚持不懈"——摆弄到正常姿态？再翻过去！直到你走为止！这个就叫做"终极坚持"！

所以下次见到翘鼻蛇，记得——这是会装死、喜欢挖土、而且可能比猪更可爱的"小猪蛇"！
