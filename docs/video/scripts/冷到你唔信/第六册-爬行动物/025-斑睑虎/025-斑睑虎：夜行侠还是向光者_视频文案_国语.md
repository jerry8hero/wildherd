# 冷到你不信 - 斑睑虎

兄弟们，夜行侠还是向光者？斑睑虎——屋檐常见这只东西，但是它晚晚向灯冲，到底为什么？

好了，你可能会说，壁虎我见得多了，不就是小小只、爬下墙吗？你如果这样想，就错了。斑睑虎可不是你想象中那种普通壁虎，它穿着件超级时尚的"豹纹衫"，全身黑色斑点，花纹比真·豹纹还漂亮！这个就是时尚界的新潮流——野生动物时尚达人。

其实呢，你知不知道？斑睑虎有样东西比其他壁虎厉害——就是它们的脚掌！

普通壁虎脚掌有吸盘，可以爬墙爬天花板。但斑睑虎不同，它们的脚趾底部有细小结节状鳞片，这些鳞片可以粘住昆虫的脚，从而帮忙捕捉猎物！这个就是"睑"字的由来——眼睑旁边有鳞片，厉害吧？

不过最厉害的是，斑睑虎不仅是"夜行者"，还可能是"向光者"！

有科学家在2016年之前从来没在尼泊尔发现过斑睑虎——是完全零记录！但后来研究发现，斑睑虎主要在晚间出没，这就解释了为什么之前发现不到它。你以为它是隐形的，其实是因为它是夜行动物，你睡着了才见不到它出来活动。

但是啊，说到夜行，就不能不提紫外线这样东西——

在圈养环境下，斑睑虎可以利用紫外线合成维生素D3！就像你吃鱼肝油补维，斑睑虎自己有东西补！饲养人员整天用紫外线灯照射斑睑虎，帮它们保持健康。这个就是爬行动物界的"日光浴养生法"——自己的东西自己补，不用靠外面。

顺便提一提，但是，你以为斑睑虎只是喜欢黑暗吗？由不得你不信——

有研究说，有人声称在白天日光强烈的沙漠里面，都见过斑睑虎晒太阳！白天出没和夜行之间反复横跳，时黑时白——这个到底是"向光者"还是"夜行者"？生物学家都说，这个可能同体温调节和维生素D合成有关。所以斑睑虎是双面人——夜黑就出动，日光就晒下东西，完美平衡。

其实呢，你知不知道？斑睑虎的皮肤有黑色斑点，这些斑点不仅好看那么简单——

这些斑纹可以帮斑睑虎在沙漠环境里面进行伪装，融入岩石和沙地的背景。一看就是大自然的"迷彩大师"，随时随地玩消失！

各位，接下来讲的，就是斑睑虎最厉害的生存技能。

斑睑虎的尾巴有自割再生能力——遇到天敌攻击，可以断尾求生！断开的尾巴会继续动，吸引捕食者注意，而斑睑虎就趁机跑路。接着下来，尾巴又会慢慢再生回来——这个就是爬行动物界的"壮士断腕"，然后回来又是一条好汉！

所以下次见到有斑纹的壁虎，千万不要惹它——它可能是时尚达人兼夜行侠，厉害过你很多！
