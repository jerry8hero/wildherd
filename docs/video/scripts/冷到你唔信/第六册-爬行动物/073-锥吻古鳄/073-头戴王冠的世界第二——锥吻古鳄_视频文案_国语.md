# 冷到你不信 - 锥吻古鳄

头戴王冠但是世界第二——锥吻古鳄，有气质但排名输，心气高！

你可能会说，锥吻古鳄？和钝吻古鳄有什么不同？就一个字不同，但你知不知道，这个就决定了它们的命运！锥吻古鳄成年体长1.4米到2.3米，比钝吻古鳄大一点点——但依然是世界第二小！

兄弟们你知不知道锥吻古鳄和钝吻古鳄怎么分？

"锥"对"钝"——锥吻古鳄个头好修长，给人一种锋芒毕露的感觉；钝吻古鳄脑袋比较短，下巴好平，整体看上去很"敦厚"。就像一个是精干的年轻人，一个是肥宅大叔——样子丑但是有实力！

兄弟们你知不知道锥吻古鳄有个很有趣的外号——"加冕鳄鱼"？

因为它们刚出生的时候，脑袋上会有一个金色的斑块，看上去像王冠！所以叫"加冕鳄鱼"——这个就是爬行动物里面最威风的名！但是呢，等它大个了，你会发现——王冠消失了，只剩个秃头！

说到最厉害，就是锥吻古鳄因为皮肤硬厚，不受人类"欢迎"——

正因为这样，它们幸免于人类的大肆捕杀！其他鳄鱼因为皮漂亮被捉，锥吻古鳄表示："我皮不好看，你们不要捉我！"——这个就叫做"丑样救了命"！

各位兄弟，接下来讲的，就是锥吻古鳄最奇葩的"王冠"。

出生就有王冠，大个就消失——这个就叫做"童年巅峰"，然后就是"下坡路"。但不要紧，丑样有丑命，它依然生存到今天！

所以下次见到锥吻的古鳄，记得——这是有王冠但是已经甩掉的前王子，而且靠丑样生存到今天！
