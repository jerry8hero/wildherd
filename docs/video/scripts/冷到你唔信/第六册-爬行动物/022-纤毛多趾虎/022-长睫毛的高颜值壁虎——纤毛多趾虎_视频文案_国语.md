# 冷到你不信 - 纤毛多趾虎

兄弟们，有只壁虎长睫毛，颜值高到被称为"壁虎界女神"——纤毛多趾虎，漂亮到不像真东西！

好了，你可能会说，壁虎？家里大厅那只？不就是灰色那样爬在那里？朋友，你知不知道世上有一只壁虎，漂亮到像睫毛精转世？

纤毛多趾虎，它最厉害的就是眼睛周围那两排"睫毛"——不是真睫毛来的！是它们眼睛周围的皮肤变形，变成一束束毛状突起，厉害了，从头一直延伸到尾巴下面，形成两排很明显的"睫毛"。

这种设计不仅好看，还非常实用——但代价就是少了一层防护罩。

其实呢，你知不知道？普通壁虎有眼睑，可以眨眼，可以眨眼！但纤毛多趾虎就不同了，它们眼睑退化了，眼睛永远都眨不了——它眼睛上面覆盖着一层透明薄膜，作用就是保持湿润。这层膜就是它们的"隐形眼镜"，包你眼睛不会干。

但是！如果眼睛里面有灰尘或者污垢怎么办？简单——伸舌头舔走它！

是的，它们会用舌头舔干净自己的眼睛，这个大概就是世界上最诡异的"隐形眼镜清洁方式"。

顺便提一提，说到纤毛多趾虎最惨的东西，就是尾巴。

你知不知道？它们的尾巴断了之后，不会再长新的！不像其他壁虎，断尾可以再生——纤毛多趾虎尾巴一断，就永远是短尾猫状态。

这个就是漂亮的代价：拥有了盛世美颜，就失去再生能力，造物主真是挺公道的。

各位，接下来讲的，就是纤毛多趾虎最有趣的日常。

除了眼睛很有"睫毛"之外，它们还趾爪很厉害——趾爪上面有超细的刚毛，可以在墙壁甚至玻璃上面走得稳稳稳。就像你穿着磁悬浮波鞋在外墙上面走，多夸张！

但最搞笑的是，它们遇到危险的时候，不会像普通壁虎那样断尾跑路——它们会选择"原地躺倒"装死，务求你不注意到它。这种"摆烂式防御"，真是又可怜又好笑。

下次见到有"长睫毛"的壁虎，千万不要认错——它就是集美貌与尴尬于一身的纤毛多趾虎！
