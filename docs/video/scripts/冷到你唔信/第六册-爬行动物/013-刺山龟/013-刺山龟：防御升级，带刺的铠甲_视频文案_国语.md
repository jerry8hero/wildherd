# 冷到你不信 - 刺山龟

兄弟们，普通龟壳已经不够用？刺山龟穿上带刺铠甲，敌人一靠近就知道怕——防御升级完成！

好了，你可能会说，龟我见得多了，不就是慢吞吞走路那些？你如果这样想，就大错特错了。刺山龟不仅不慢，它还自带武器！它只龟外围有一圈刺，厉害到呢——不信你咬我呀？蛇见到都要转头走！

你知不知道刺山龟住在哪里？东南亚那边，才有！

它们喜欢那些海拔900米以下的森林河流，环境美到晕——树又多水又清，是龟版的世外桃源。不过这种地方越来越少，为了吃和住，刺山龟多低调就多低调。

你知不知道刺山龟长得有多好看？

它外壳是棕色为主，但边缘有一圈刺状尖棘，远远望去——像一轮红日！所以它又叫"太阳龟"。这个名字多厉害，它是龟里面少有可以跟太阳扯上关系的品种。

但是啊，说到这些尖棘，就是刺山龟的防身利器！

尖棘密密麻麻地围住只龟，看到都觉得痛。蛇想咬下去？当然啦，口腔内壁一碰到就痛到弹开！这个大概就是大自然的设计：给你一对利牙，我就有三层护甲！

不过这款防御装备不是一开始就那么厉害——

刺山龟小小只的时候，尖棘很厉害，分分钟刺到你手流血。但是大个了之后，尖棘会慢慢变钝，甚至消失！就像小孩子大个了就不用戴头盔——但是变老了，防御力就下降了。

其实呢，说到生存状况，刺山龟今天不是很好景。

人类不断砍伐森林，破坏了它们的天然家园。无树又无水，刺山龟想找地方舒服都难。现在生存环境越收越窄，数目越来越少——是时候要想下这些带刺朋友了。

顺便提一提，各位，接下来讲的，就是刺山龟最不想面对的现实。

不管你防御多厉害，不管你多会找地方住，一旦家园被人拆掉，你就什么都没有。刺山龟的尖棘可以挡蛇，但挡不住电锯和推土机。这个就是最残酷的生存法则：找到好地方不够，还要看旁边是不是人类。
