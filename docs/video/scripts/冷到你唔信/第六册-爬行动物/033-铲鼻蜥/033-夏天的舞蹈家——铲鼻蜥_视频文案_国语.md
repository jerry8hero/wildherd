# 冷到你不信 - 铲鼻蜥

夏天跳舞不为求偶，铲鼻蜥——为了整好巢穴，舞蹈家转型包工头！

你可能会说，沙漠这么热，谁有空在那里跳舞？但铲鼻蜥就不同，它真是会跳，而且跳得挺用力——不过这个不是表演，而是它的续命大法。

你知不知道铲鼻蜥为什么叫"铲鼻"？就是因为鼻子像把小铲——不过这把"铲"不是用来整东西吃，而是用来挖沙的。它一爪就可以整身插入沙里面，立即消失不见，就像你玩变色龙那样隐身术。

但今天重点不是鼻子，而是它们的舞姿。

你知不知道？铲鼻蜥热的时候会跳"恰恰"！

沙漠的沙，中午可以烫到五六十度——想象一下你赤脚走在沙滩上，烫到你喊救命。铲鼻蜥就聪明，它们不会呆呆地忍受，而是使出独门绝技——抬脚舞！

具体是这样的：它先抬起左前脚加右后脚，离地大概两厘米——hold住大约十秒——然后再换右前脚加左后脚。交替地抬，就像跳着某种奇怪的恰恰舞。

你可能会问：抬脚有什么用？重点来了——就是为了不让脚被烫熟！

铲鼻蜥靠着条尾保持平衡，一次过抬起两只脚，可以让脚暂时离开滚烫的沙面，得到短暂降温。就像你在猛太阳下面，当然想抬下脚离地降下温啦——虽然你不能真是做到。

这种舞步不是什么时候都跳，只是夏天或者天气真是热到顶不住的时候才会出绝招。这个就叫做——热我们都会，降温有方法。

说到铲鼻蜥的沙漠生活，就不能不提它们的速度——虽然样子看上去像呆呆的，但它们可以每小时移动30公里！就是为了追捕猎物或者逃避捕食者。毕竟沙漠里面，慢一秒都可能热到归西。

你知不知道？铲鼻蜥不仅会跳舞，还懂"水上漂"！

骗你不信？这个"水上漂"不是轻功，而是靠着飞快的速度和特殊的脚掌结构，它们可以短暂地在沙面上面滑行——就像你用脚尖点水面那样，不知多像神仙！

想象一下沙漠里面，一只铲鼻蜥高速移动，脚抬上抬落，就像跳着舞——这个就是沙漠里面最漂亮的舞蹈家了！

各位兄弟，接下来讲的，就是铲鼻蜥最厉害的生存技能。

它不仅会降温跳舞，还有一个超级能力——变色！不同时间、不同温度，身颜色会变。热的时候会比较浅色，冷的时候就深色一点。就像你穿黑色衫在沙漠走，热了！但它们可以自己变色做凉浸浸色——这个才叫做真的！

铲鼻蜥：谁说我丑？我只是未热身而已。
