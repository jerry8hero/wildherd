# 冷到你不信 - 拟毒蜥

耳尾像欠缺，但不要欺负——拟毒蜥，无耳蜥蜴但有毒，危险！

你可能会说，蜥蜴我见得多了，不就是四脚蛇吗？你如果这样想就错了。拟毒蜥可不是你想象中那种普通蜥蜴，它竟然像足神话里面走出来的龙！棕色身形、长长的脖子、短小的四肢、锋利的爪子，背脊上还有6列像龙骨那样分布的鳞片——这个不就是"龙的传人"了！

但是，等我问大家一个问题：它叫"拟毒蜥"，是因为有毒吗？由不得你不信——它们其实无毒的！这个"拟"字就是在这里扮嘢，扮有毒骗人而已。就像你见到个骗人的广告，"拟毒蜥"就是蜥蜴界最骗得那个。

兄弟们你知不知道？拟毒蜥其中一个很厉害的地方，就是它对耳——或者应该说，它没耳！

拟毒蜥学名叫做"无耳巨蜥"，因为它真是没耳孔这些可见的耳朵外部构件。但不要以为它聋了，它依然可以听到声音的！这个就像你戴着对降噪耳塞，虽然看上去无声，但内心依然在那里BGM不停。所以如果你在婆罗洲见到拟毒蜥，千万不要故意走过去大声喊它，它是听到的！

说到样子，拟毒蜥那对眼就是最佳证明。

它对眼真是挺随便——细而且半透明状，看上去就像一对未充满电的充电宝。但这对"拉胯"的眼，不仅可以看东西，还可以帮它们发出刺耳的叫声！拟毒蜥的名字叫"拟毒"，其中一个技能就是发出像"龙吟"那样的声音。它们可以像青蛙那样振动喉咙，或者像蛇那样轻弹条舌，发出刺耳叫声——这个就是属于它们的"龙吟"！

你知不知道？拟毒蜥是水塘爱好者，科学家观察过19只拟毒蜥晚间生活，发现一半泊在水里，另一半就守在近水的陆地。就像有人喜欢睡床上，有人喜欢睡沙发——拟毒蜥就是"水陆两栖"的代表，看心情选地方享受世界。

说到拟毒蜥最厉害的地方，当然是它样子——像龙走过来！

6列纵向分布的龙骨状鳞片，从头一直延伸到尾部，配合长颈、短脚、锋爪，看上去就像缩小版的dragon。就是因为这样，它在爬行动物界，绝对是"最像龙的存在"排行榜第一位。如果你在婆罗洲无意中发现一只拟毒蜥，恭喜你，你已经见到"现实版龙"啦！

各位兄弟，接下来讲的，就是拟毒蜥最神奇的生存环境。

它们住在东南亚婆罗洲——这个地方就像个天然游泳池，整天都湿淋淋。拟毒蜥喜欢有水的地方，除了饮饱吃饱，它们还会潜在水底降温或者躲避捕食者。所以如果你想找拟毒蜥，记得带定泳裤——因为它随时在水里等你！

这个就是大自然最奇妙的设计：一只像龙但又没耳、眼像充电宝、懂发出龙吟但又不是真龙的神奇生物。下次有人问你蜥蜴可以多神奇，你就可以讲拟毒蜥故事给它听！
