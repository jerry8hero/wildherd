# 冷到你不信 - 蓝灰扁尾海蛇

偏要吃鳗鱼——蓝灰扁尾海蛇，海蛇里面的挑食专家！

你可能会说，蓝灰扁尾海蛇？海蛇？应该整天待在海里吧？你猜对了！但你知不知道，这只蛇是半水生的——成年后一半时间在海洋，一半时间在陆地！就是这样！

兄弟们你知不知道蓝灰扁尾海蛇有多厉害？

毒液有很强的神经毒素，专门用来捕杀最对东西——海鳗！但新几内亚附近海域的裸胸鳝已经对这种毒液有抵抗力——注射一定剂量都毫发无损！这个就叫做"道高一尺，魔高一丈"！

你知不知道蓝灰扁尾海蛇陆地移动有多慢？

在陆地移动速度只有水里的五分之一——所以人类遇到它们的机会很多！就是因为它们喜欢上岸！

你知不知道蓝灰扁尾海蛇为什么叫"扁尾"？

因为它们的尾巴扁平——可以当桨用，游起来好方便！但正因为这样，在陆地就像踩着两只桨那样——走不动！

各位兄弟，接下来讲的，就是蓝灰扁尾海蛇最有趣的"鳗鱼杀手"身份。

毒液专门为了杀海鳝！但海鳝已经找到办法抵抗——这个就是进化的"军备竞赛"！

所以下次见到扁尾巴的海蛇，记得——这是可以毒杀海鳝但是陆地走不动的"海陆两栖蛇"！
