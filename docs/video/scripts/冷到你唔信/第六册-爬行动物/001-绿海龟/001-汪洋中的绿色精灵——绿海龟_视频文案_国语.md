# 冷到你不信 - 绿海龟

兄弟们，今天开一个新系列——**冷到你不信**！

这个系列是做什么的呢？就是帮你们拆解爬行动物里面那些鲜为人知的冷门知识。什么神奇的习性、逆天的技能、搞鬼的名字，保证令你大开眼界，感叹造物主的脑洞真是大！

好了，废话先不多说，先从海龟讲起。今天我们来聊聊一种超神奇的海龟——绿海龟！

你可能会说："海龟我见得多了，不就是绿色的吗？"哎呀，一看你就知道是没有做过功课。绿海龟可不是你以为那种只是绿色的普通龟龟，它是可以下潜到一两百米深的深海潜水员！重点是，它用肺呼吸的，每隔一段时间就要浮上来喘口气，这个体力消耗，哇，比我们打工人干活还累！

但是啊，这个并不是最离谱的。

绿海龟一辈子几乎只吃素！餐餐都是海草和大型海藻，吃得那叫一个清淡。结果呢？吃素吃得多，身体里面的绿色素越积越多，皮肤和脂肪都变成淡淡的绿色，所以才叫绿海龟。这个大概是我见过最另类的"自己定义自己"了，吃着吃着就把自己变成"绿色食品"。

兄弟们，你知道不知道绿海龟可以潜多深呢？成年男子那么高？不够它们三分之一！一两百米！这是什么概念？普通潜水发烧友可以下去三四十米就厉害到可以指定动作了，人家的舒适区直接是我们极限的两三倍。

不过呢，绿海龟虽然这么厉害，它毕竟是爬行动物，用肺呼吸的，所以每隔一段时间就要上水面喘口气。就好比你打游戏打到刚刚兴奋，突然被强制下线，绿海龟内心肯定是在爆喊："我就想静静地做个深海王者，为什么要这样逼我！"

哦，顺便提一提，大家知道吗？绿海龟是国家一级保护野生动物来的，能够在我国拿到一级保护，没有两下功夫是不行的。

好了，讲完潜水，我们再讲讲吃。如果说什么动物是吃素吃到变身，绿海龟绝对是教科书级别。它们餐餐都是海草和大型海藻，严格素食主义者。长期吃这些绿色植物，叶绿素越积越多，慢慢皮肤和脂肪都泛着淡淡的绿色。所以它名字里面的"绿"不是随便起的，是真是吃伙食吃出来的！

但是，不要以为它是好哄的素食主义者啊，在海里面，绿海龟灵活得你估都估不到，游起水来快过很多鱼！还有的是——60到80岁的寿命，比我爷爷养的那只龟都长寿！这个大概就是传说中的养生之道了，清淡饮食，心情开朗，想不长寿都难。

兄弟们，你知道不知道另一件有趣的事？绿海龟小时候和长大之后，完全是两回事！刚刚出生的幼年绿海龟，背甲是黑色的，黑漆漆的好像煤炭堆一样。你如果不知道，以为是什么变异生物。等它慢慢长大了，背甲才慢慢变成标志性的绿色，正所谓"女大十八变"——虽然绿海龟不分公母。所以下次见到黑色的小海龟，千万不要认错，它不是什么怪异品种，是正宗的绿海龟的童年黑历史！

如果说绿海龟最令人震惊的能力，绝对是它的导航系统，这个简直是动物界的GPS！而且是升级版那种！每年繁殖季节到了，绿海龟就会开展一场说走就走的旅行，从茫茫大海里面精准定位，千里迢迢游回自己出生的那片沙滩产卵。这是什么概念？就好比你从北京出差到广州，下了飞机不用导航，直接蒙上眼睛都可以找到自己楼下的奶茶店，精确到门牌号那种！

科学家到现在都没有完全研究透绿海龟是怎么做到这一点的。有人说靠地球磁场，有人说靠海水化学成分，但无论怎么说，这种能力都是蛮不讲道理的。想想，你在海里面游了二三十年，突然有一天，凭着某个神秘信号，你向着某个方向游，历尽千辛万苦，终于找到你出生的沙滩，你挖了个洞下完蛋，又再游走了。真是浪漫到爆啊！

兄弟们，接下来这个故事，绝对是绿海龟最刺激的生存篇章。刚破壳的小海龟，想要从洞里面爬出来，要花3到7天！一个蛋壳里面的小生命，要用好几天才能打通地下逃生通道。好不容易爬出来了，真正的挑战才开始——沙滩上面全部都是等着开饭的捕食者！海鸟、螃蟹、各种肉食动物，全部虎视眈眈盯着这群刚出生的小鬼头。小海龟想要活命，只有一条路，就是拼命往海里冲！

这个时候它们会循着海浪的声音来定向，一听到浪花声就赶紧冲！一有浪就拼命往外海游，而且这群小鬼头可以连续游足24个小时不停歇！对它们来说，游得越远就越安全，只有去到外海，那些捕食者才追不上。这个大概就是大自然最残酷的生存法则了——出生即赛道，一辈子都在游。
