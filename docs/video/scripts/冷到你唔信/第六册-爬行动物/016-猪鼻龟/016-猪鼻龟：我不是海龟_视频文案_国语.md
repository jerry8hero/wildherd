# 冷到你不信 - 猪鼻龟

兄弟们，叫猪鼻但是不是猪，不是海龟但是住水里——猪鼻龟，名字搞到你猜它是谁！

好了，你可能会说，猪鼻龟？听名字就知道是在海里游的吧？猪鼻——不就像猪鼻子那样在水里喷泡泡——如果你这样想，恭喜你，你中了全世界最多人犯的错！猪鼻龟它不是海龟，而是不折不扣的淡水龟来的！就像你听人叫"海马"，就以为马仔会游泳——骗你的！

你知道不知道猪鼻龟有多厉害？它是地球上唯一完全生活在淡水里面的淡水龟——注意，是唯一！其他龟类要么海水龟，要么半淡水，但是猪鼻龟就只喜欢淡水！这个就是它们的核心竞争力：一门专。

但是啊，它和海龟又真的很像——因为它们四肢都演化成鳍状，就像两对小的桨一样。这个就是猪鼻龟最奇葩的地方：明明是淡水龟，四肢偏偏像海龟。就像你明明是广东人，但是学了北方人说话——是又不是，不是又是，骗你的！

其实呢，你知不知道猪鼻龟长得有多有趣？鼻子隆起来，像个猪鼻——所以就叫猪鼻龟。但是它们不仅长得有趣，还有个很有趣的习惯：它们可以像鱼一样，用肺呼吸，但是又可以长时间潜入水底！科学家发现，它们可以在水底待到几十分钟不用上来换气——这个技能多重要？就像你打游戏打到紧张关头，突然不用去厕所那么爽！

顺便提一提，你知不知道猪鼻龟有多稀有？它们活动范围很窄的——只生活在澳大利亚北部和新几内亚部分地方的淡水环境。换句话讲，你想去看野生猪鼻龟，只能去这个地球上很小的几个地方。这个叫做"地方限定"——好像那些潮牌一样，不是你去那个地区就买不到！

各位，接下来讲的，就是猪鼻龟最有趣的生存方式。

虽然四肢像鱼鳍一样，但是它们在陆地上就很笨拙——爬啊爬的，这个鳍脚完全帮不上忙。就像你穿着拖鞋去跑步——理论上行，但实际上呢？你懂的。

不过它们在水里面就很厉害——鳍脚推进力很足，游起来很顺畅。但是上岸呢？就算是繁殖这么重要的事，它也只是短暂地爬上岸。科学家就发现，它们大部分时间都在水下，很少去太远的地方——就像个死宅女，明明有快递要去拿，但是就是不想下床！

这个就是猪鼻龟的生存之道：陆地？不了，我选择大海——哦，不对，是淡水！
