# 冷到你不信 - 东部珊瑚蛇

红挨黄请你帮——东部珊瑚蛇，歌谣教你分，但不要试！

你可能会说，东部珊瑚蛇？珊瑚？是不是很漂亮？你猜对了！但好看过分——因为它是剧毒蛇！和前面讲过的无毒加州山王蛇很像，但前者有毒！

兄弟们你知不知道怎么分辨？

当地人编了首歌谣："红配黑，不慌忙；红配黄，杀人狂！"你就记住：红环跟黄环挨在一起就是毒蛇，红环跟黑环挨在一起就是无毒！

你知不知道东部珊瑚蛇有多毒？

就一句——红配黄，杀人狂！黄色就代表剧毒，所以见到红配黄就赶紧跑！

但是！你知不知道这首歌谣有多准确？

这首歌谣适用于北美珊瑚蛇——可以说是"保命歌谣"！所以去野外之前记得背诵！

你知不知道东部珊瑚蛇生活在哪里？

美国东南部——所以你去那边行山就要小心了！歌谣不仅要背，还要懂得用！

各位兄弟，接下来讲的，就是东部珊瑚蛇最有趣的"保命歌谣"。

红配黑，不慌忙；红配黄，杀人狂！这首歌谣可以说救过你一命——下次见到红黄相间的蛇，记得赶紧跑！

所以下次见到珊瑚蛇，记得——红配黄就死，不要考虑，跑！
