# 冷到你不信 - 缅甸蟒

美国搞到生态灾难——缅甸蟒，恐怖入侵者，厉害到会开电视！

你可能会说，缅甸蟒？不就是东南亚那边很常见的大蟒蛇？你猜对了！但你知不知道，这家伙入侵美国佛罗里达州之后，搞到当地鸡飞狗走！

兄弟们你知不知道缅甸蟒有多大只？

成年缅甸蟒长约5米，有些甚至可以达到6米长！满嘴都是锋利的牙齿，肌肉厉害到可以紧紧缠住猎物勒死——然后整条吞落肚！这个就叫做"终极猎食者"！

你知不知道缅甸蟒入侵美国之后搞到多糟糕？

佛罗里达州的兔子、浣熊、狐狸等动物数量大大减少，连郊狼、美洲狮这些"狠角色"都受到威胁！而且缅甸蟒还会和美国短吻鳄打起来——有时是短吻鳄吃缅甸蟒，有时是缅甸蟒反杀短吻鳄！

但是！你知不知道我们中国对缅甸蟒有不同看法？

对美国人来说，缅甸蟒是入侵物种；但对我们中国来说，缅甸蟒是本土原生物种，被列为国家二级保护动物——吃不到，摸不得！

各位兄弟，接下来讲的，就是缅甸蟒最厉害之处。

6米长，可以勒死短吻鳄——但这种威力只可以在野外看到。如果入侵其他地方，就会变成生态灾难——这个就叫做"强者做错地方"！

所以下次见到缅甸蟒，记得——这是可以勒死短吻鳄的"6米巨蛇"，但对我们来说是受保护的本土物种！
