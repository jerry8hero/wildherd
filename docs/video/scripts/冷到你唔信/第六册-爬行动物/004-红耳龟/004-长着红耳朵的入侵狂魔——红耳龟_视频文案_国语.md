# 冷到你不信 - 红耳龟

兄弟们，红耳龟？巴西龟？傻傻分不清楚？但是红耳龟已经入侵全球，危害程度超出你想象！

好了，你可能会说，红耳龟？哦，就是那种宠物店经常看到的巴西龟啊！你如果这样想就错了。这家伙，虽然名叫"巴西龟"，但不是来自巴西，而是来自美国和墨西哥！而且它有个劲爆的名字——被列入《全球100种最具威胁的外来物种》，多吓人！

你知道不知道红耳龟这个名字是怎么来的？这个就搞笑——它的耳朵附近位置，有红色的条纹！就像挂着对红耳环一样，是它的标志性特征。但你以为它只是靠脸骗人？错错了！它们适应能力强到呢，本土龟根本不够打！

说到红耳龟有多能顶，就是一个"厉害"字可以形容。

它们是半水栖龟类，什么环境都行——池塘、湖泊、河流、甚至沼泽地，统统都是它们的主场。适应能力强到呢，新环境？小意思啦！正因为这么能打，我们中国的本土龟在生存竞争里面，完全输蚀。你说惨不惨。

但是啊，更惨的是，它繁殖快到呢！一只红耳龟一年可以生几窝蛋，每窝十来只，而且它们带菌，可以传播沙门氏菌等多种病。本土龟一感染，整个族群都麻烦了。你说是不是厉害？

不过呢，你知道吗？红耳龟在好多地方是犯法的！

澳大利亚、欧洲部分国家，贩卖红耳龟是犯法的！日本更加在2015年宣布禁止进口！为什么？因为它们实在太厉害了——适应能力强、繁殖快、带菌，是外来物种里面的"战斗机"。一旦进入新环境，本土物种就很难立足。

所以下次见到红耳龟，记住——它不是普通的宠物龟，是个很厉害的入侵者！

顺便提一提，说到红耳龟最厉害之处，当然是它的"全球扩张"——宠物市场的超级明星！

话说当年美国宠物市场兴起红耳龟热，商人见到有钱赚，就将大量红耳龟当作货品，卖到全世界各个国家。结果呢？红耳龟凭着超强的适应力，在好多地方扎稳阵脚，慢慢取代本土龟种。

这个就是"宠物贸易"的代价——你以为买只龟好小事，但是一旦它跑掉或者被放生，它就可以摧毁整个生态系统。你说多惨。

想象一下，你在宠物店买了只红耳龟，觉得有趣就养大了，后来觉得麻烦就放生。不知道就放生一只"生态炸弹"！它会抢本土龟的食物和地方，传播病症，繁殖又多——这个就是好心做坏事。

各位，接下来讲的，就是红耳龟最厉害的入侵能力。

红耳龟之所以成为入侵物种，就是因为它有三个必杀技：第一，适应能力强，什么环境都行；第二，繁殖快，一年几窝蛋；第三，带菌，传播病给本土物种。

有研究显示，在引入红耳龟的地方，本土龟类数量普遍下跌三成以上，有些地方甚至跌到只剩个位数。这个就是"外来物种入侵"的威力——看不到，但很惨。

所以我们绝对不可以掉以轻心！如果见到红耳龟，千万不要放生，应该找当地动物园或者野生动物救护机构帮忙。

这个就是大自然最残酷的生存法则：太厉害也是罪，做得太好都出问题。
