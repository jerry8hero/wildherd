# 冷到你不信 - 红腹伊澳蛇

红肚兜黑披风——红腹伊澳蛇，究竟是英雄还是反派？

你可能会说，红肚兜黑披风？多威风啊！这只蛇上半身是有光泽的黑色，下半身是暗暗的红色——就像里面穿着红肚兜，外面披着黑披风！这个就是澳大利亚东部最常见的蛇类之一！

兄弟们你知不知道红腹伊澳蛇有多毒？

虽然都是毒蛇，但是在"毒王横行"的澳大利亚，它们的毒性简直不值一提！不过呢，不要招惹——毒液可以令人丧失嗅觉！你就闻不到它们的味道了！

你知不知道红腹伊澳蛇有多臭？

它们身上有强烈气味！有些科学家就靠闻这种味道才找到它们——这个就叫做"体味攻击"！

你知不知道红腹伊澳蛇有多喜欢水？

喜欢待在哺乳动物挖的洞里、草丛里、水里！而且漂在水面的时候很搞笑——笔直地漂浮，一动不动，就像一根棍子——这个就叫做"闲死人"！

各位兄弟，接下来讲的，就是红腹伊澳蛇最有趣的"红肚兜黑披风"造型。

黑色加红色，就像一个穿着中华传统服装的武士——但这个武士有多毒就真的看情况！澳大利亚毒性最厉害的地区，它反而是最温柔的一种——这个就叫做"环境塑造蛇"！

所以下次见到黑上身红下身的蛇，记得——这是"红肚兜黑披风"的红腹伊澳蛇，闻下去可能有点臭！
