# 冷到你不信 - 丛林地毯蟒

花纹像艺术地毯——丛林地毯蟒，漂亮到想晕，但是可以长到5米！

你可能会说，地毯蟒？是不是因为样子像地毯？你猜对了！丛林地毯蟒的鳞片是黑天鹅绒毛一样的黑色，点缀着鲜艳的黄色——就像一件超级精美的地毯！所以叫"地毯蟒"就是因为像地毯那样！

兄弟们你知不知道丛林地毯蟒有多华丽？

黑天鹅绒加上鲜艳黄色，看上去像最华丽的艺术品！但这种华丽不是只是好看的——黑黄搭配可以帮它们在斑驳的阳光下更好地伪装自己，不容易被发现！这个就叫做"外表内功兼备"！

你知不知道丛林地毯蟒有多小只？

通常体长不超过2米，而且很瘦——这种身形在大自然里面很容易被当成猎物！但正因为这样，它们从小就有很强的防御意识，一旦感觉到威胁就会攻击——这个叫做"小孩子都会撩"！

你知不知道丛林地毯蟒多省？

"饭量"不大，有时一年只进食10次——一顿管饱，不用天天找吃的！这个就叫做"省家本色"！

各位兄弟，接下来讲的，就是丛林地毯蟒最有趣的生存之道。

华丽外表帮隐身，深色帮吸热，小只身形但攻守兼备——这个就叫做"小而精"！

所以下次见到黑黄相间的蟒蛇，记得——这是华丽的"地毯蟒"，可以隐身、可以吸热、还可以一年只吃10次！
