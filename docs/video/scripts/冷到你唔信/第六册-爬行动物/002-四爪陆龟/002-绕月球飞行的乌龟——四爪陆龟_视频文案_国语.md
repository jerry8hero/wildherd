# 冷到你不信 - 四爪陆龟

兄弟们，有只龟可以连续睡9个月，还要上过太空！四爪陆龟——龟中睡神兼航天员，这个组合你没见过！

好了，你可能会说，陆龟我见得多了，不就是四只爪的吗？你如果这样想就错了。四爪陆龟可不是你想象中那种普通陆龟，它竟然可以整天赖在那里睡觉——一年到头有9个月都在呼呼大睡！是啊，你没有听错，9个月！相当于整只熊一样，整天都在冬眠状态——但它不是熊啊，是龟啊，这个多离谱。

但是啊，更离谱的是，它连睡觉都特别会——它们会在泥土里挖个洞，然后把头塞进去，就像烤箱里面的鸡腿一样，一睡就半年。你以为它不喜欢动？不是的，它是主动选择的，不想理你这摊事。

其实呢，你知不知道四爪陆龟有多厉害？它是苏联太空史上的英雄！

1968年，苏联发射了"探测器5号"，这次任务带了什么东西上太空？就是两只四爪陆龟！它们成为了人类航天史上第一批飞往月球的地球生物——比人类首次登月还要早一年多！

这两只龟仔就好像说："人类没有去过月球？我们先去了！"然后它们就成功环绕月球飞了一圈再回地球。不知道你们知不知道，它们当时还创下了多个纪录：第一批飞往月球的地球生物、第一批成功环绕月球再安全回来的地球生物、还是第一批在太空里吃东西的爬行动物——科学家专门为它们准备了特制太空餐。

不过呢，顺便提一提，你知不知道？四爪陆龟分辨公母有多搞笑！

说起四爪陆龟，就不能不提它们的"辨别大法"。你想知道你家那只龟是公是母？让我教教你：

第一看尾巴——如果尾巴又短又肥，那就是母的；如果尾巴较长，那就是公的。

第二看爪子——如果爪子很短，那就是母的；如果爪子很长，那就是公的。

第三就是看尾巴尖的"口"——这个是重点！如果口像星星，不用问那么多，是母的；如果口是一条缝，那就是公的。

所以呢，四爪陆龟的性别真的很难分，连口都做成不同款式，真是服了它。

各位，接下来讲的，就是四爪陆龟最有趣的地方，当然是——喜欢赖在那里不动！

你知不知道？四爪陆龟是动物界的"睡公主"！

每年天气冷的时候，它就会开始找个泥洞把自己塞进去，然后进入长达几个月的冬眠状态。就像你冬天赖床赖到不想起床，它直接就跳过你们人类整天说的"起床困难症"，因为它根本就不起床——一睡就几个月，醒来都已经春暖花开。

但你不要以为它懒，它是识时务者为俊杰——天气太冷，外面找不到东西吃，不睡觉难道还饿死吗？不如养精蓄锐，等天气暖再出来活动。这个就是生存智慧。
