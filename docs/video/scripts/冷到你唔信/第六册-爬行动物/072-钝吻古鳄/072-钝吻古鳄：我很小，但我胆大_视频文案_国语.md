# 冷到你不信 - 钝吻古鳄

小过一个人的手臂——钝吻古鳄，娇小玲珑但是胆子大，危险！

你可能会说，钝吻古鳄？名字挺有趣！它多大只呀？如果你这样问，就错了——这家伙成年只有1.2到1.6米，最大都只有1.7米左右，是世界上最小的鳄鱼之一！体重只有6到7千克——就相当于湾鳄体重的百分之一！

兄弟们你知不知道钝吻古鳄有多厉害？

虽然小，但它被评为"世界上最轻的鳄鱼"——百分之一的体重，够厉害！但最厉害的不是这个，而是它虽然小，但是很惊东西——背侧、腹侧都有厚厚的鳞甲，如同古代士兵的铠甲！

你知不知道？钝吻古鳄虽然小，但是很能打！

有铠甲护身，就算面对体型大的捕食者都不用怕！它不像其他小孩子见到大只就跑，它会留下来顶硬上！这个就叫做"小孩子有胆色"！

你知不知道钝吻古鳄和其他鼍类有什么不同？

它更能够忍受低温！干旱的时候，不是去挨着睡觉，而是主动出击找水——这个就叫做"找吃态度认真"！不坐以待毙，主动出击，这个就是生存之道！

各位兄弟，接下来讲的，就是钝吻古鳄最有趣的生存哲学。

小？就小啦！但是穿定铠甲，主动出击，不怕大只佬——这个就叫做"浓缩即是精华"！

所以下次见到小小只的钝吻古鳄，记得——这是世界最轻鳄鱼，但是穿着铠甲主动出击的"小钢炮"！
