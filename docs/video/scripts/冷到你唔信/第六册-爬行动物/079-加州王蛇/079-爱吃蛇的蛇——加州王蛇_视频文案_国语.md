# 冷到你不信 - 加州王蛇

蛇类是我的饭后甜点——加州王蛇，不要谢其他蛇，只要我！

你可能会说，爱吃蛇？难道自己是蛇就吃其他蛇？你猜对了！加州王蛇虽然无毒，但几乎什么都吃——啮齿动物、鸟类、两栖动物、其他蛇类……甚至响尾蛇这些毒蛇，都在它菜单上面！

兄弟们你知不知道加州王蛇为什么敢吃毒蛇？

因为它对响尾蛇的毒液有天然免疫力！就算被咬都不怕——这个就叫做"百毒不侵"！所以它敢叫自己"王"，因为它是毒蛇的克星！

你知不知道加州王蛇怎样捕猎？

缠住猎物，然后收缩身体绞杀！这个压力多厉害？比人的血压还高！所以基本没猎物可以跑掉——这个就叫做"死亡拥抱"！

但是！你知不知道养加州王蛇的人有多头疼？

因为它太能吃了，不仅吃其他蛇类，连自己同伴都吃！所以养它们一定要单独关——否则第二日你就发现另一条蛇不见了！

各位兄弟，接下来讲的，就是加州王蛇最厉害之处。

无毒但可以绞杀毒蛇，什么都吃但就是叫"王"——这个就叫做"实力派"，不靠毒靠武力！

所以下次见到加州王蛇，记得——这是可以绞杀响尾蛇的"蛇王"，而且是"百毒不侵"的毒蛇克星！
