# 冷到你不信 - 平额叶尾壁虎

兄弟们，有只壁虎像片叶子，条尾就更加像——平额叶尾壁虎，大自然的复制粘贴实例！

好了，我们从头讲起。今天聊聊，讲只超级诡异的壁虎——平额叶尾壁虎！

你可能会说，壁虎哦，常见啊，爬窗贴墙那些嘛。你如果这样想，就浪费你了。平额叶尾壁虎可不是你想象中那种普通壁虎，它条尾上面竟然长了片叶子——真是叶子，一片扁扁阔阔像枯叶的东西。你以为造物主在开树叶的玩笑，结果是它真是将树叶整在条尾上！

这种壁虎是马达加斯加独有的品种，不去马达加斯加，你在外面找都找不到。多矜贵？就像你在外面见不到的限定版，这个就是动物界的限定版！

但是啊，你知不知道平额叶尾壁虎为什么条尾会像叶子？

它们整天背着片枯叶在条尾上，其实是为了隐身！平时呢，这只东西喜欢躲在树上，一看就像片枯叶一样，敌人走过都猜你不到。这个就是真正的"带艺投师"，一看就知道是伪装界的老行家。

更厉害的是，它们的叶子尾令到它们在树和树之间跳来跳去很方便！

你知不知道？片扁平的尾像降落伞一样，可以帮它控制方向和平衡。在树枝上跳来跳去，这片尾就是它的秘密武器。就像你用开导航，突然间发现你手机有个隐藏的飞行模式——这片尾就是它们的外挂！

其实呢，说到生存技能，就不能不提它们的绝招——断尾逃生！

这个就厉害了，遇到威胁的时候，它会先将条尾甩给你，然后趁你一阵都还没回过神，这位老哥已经跑路了。条尾不会立刻死，会继续弹跳分散你注意力——就像你打游戏被人追，丢个道具出去引开人家，这招多明智！

所以呢，你见到的"落叶"不一定真落叶，可能是一只正在撤退的平额叶尾壁虎！

这个大概就是最厉害的生存哲学：我走先，你慢慢消化片枯叶啦。

顺便提一提，说到住的地方，平额叶尾壁虎就是典型的宅男。

它们几乎天天都贴在树上，好少落地面。落到地面的时候，通常都是逼于无奈——大概就是"万不得已先下树"那样。就像你在家宅了一年，突然有件急事要先出去处理——它们落到地面就是这种心态。

它们在树上面就如鱼得水，片叶子尾帮它们完美融入树皮和树枝里，敌人想找都找不到。

各位，接下来讲的，就是平额叶尾壁虎最有趣的身体构造。

片像叶子的尾不仅是伪装，还是它的多功能工具——可以用来存储脂肪，可以用来平衡跳跃，还可以用来迷惑敌人。一尾多用，耐用过市面上任何手机！

这个就是进化的神奇之处：大自然竟然想得出将一片普通的尾，整成一把这么有趣的瑞士军刀。
