# 冷到你不信 - 五趾双足蚓蜥

蚯蚓还是蜥蜴？五趾双足蚓蜥——两者混合体，科学家都难分辨！

我们今天讲只超级奇葩的物种——五趾双足蚓蜥！

你脑海中可能立即浮现：是蜥蜴吧？有些像变色龙那种？如果你这样想，就大错特错了！这家伙身体像蚯蚓那样又长又粉嫩，但走着走着突然有两只小脚伸出来，每只脚上面还有5只萌萌的小脚趾——是5只！见到它你真是会想：究竟是蚯蚓穿了一对拖鞋出来，还是蜥蜴去了韩国整了个缩骨手术？

兄弟们你知不知道？这家伙不是蜥蜴，也不是蚯蚓，而是蚓蜥家族的成员——爬行动物来的！

对，你没有听错，爬行动物。但这个家族就厉害了，既不是蜥蜴科，又不是蛇科，自己一个科就叫做蚓蜥目。它们的祖先大约在7000万年前就已经出现，经历过恐龙大灭绝都生存到今天——这个才是真正的老前辈。

说到它们最有趣的地方，当然是那对生仔的小脚。每只后脚有5只脚趾，只只分明，看上去就像迷你版的人类宝宝小手——但只有两只，还要很小只。科学家都觉得这对小脚几漂亮，几有趣，但实际用途就……呃，其实走路都是靠蠕动为主，小脚只是辅助了。

你知不知道？五趾双足蚓蜥是怎样走路的？

这家伙在地下蠕动起来就像蚯蚓那样，一伸一缩那样推进。但是！它偶尔会伸出那对小脚来撑下地面，就像你睡地下时想撑起身那样——但这对东西就真是几亿年历史的"撑地神功"。因为后腿已经完全退化了，所以它们基本上是靠身体蠕动来移动，小脚只是偶尔用来转向或者爬过障碍物。这个就是为什么它叫"双足"——两对脚剩下一对，但用来撑东西不是走路。

各位兄弟，接下来讲的，就是五趾双足蚓蜥最有趣的生存技能。

全身粉嫩粉嫩，看上去就像一条活生生的腊肠——但不要以为它只看不能打哦。在地下，它可以靠身体一节节蠕动来穿过泥土，这种技能就叫做"蠕动推进"。它们的鳞片很光滑，黏土见到都自动让路——多爽呢，就像你在健身房做完facial，滑一滑那样！

但最猜不到的是，它们的食谱里面竟然有蚯蚓！是蚯蚓啊！和自己样子一模一样的蚯蚓！这个就像你突然发现有人喜欢吃素，但它自己就是素菜——究竟是什么心态呢？科学家都觉得离之大谱，但自然界就是这么残酷：基因不同，就算样子丑都要照吃。

你知不知道？五趾双足蚓蜥既是蚯蚓的天敌，又是蜥蜴的猎食者——就是这样都行！

它们的英文名叫"two-legged worm lizard"，直译就是"两条腿的虫样蜥蜴"。但你实际见到它的时候，你一定会问：两条腿？是啊，是有两只小脚，但你真是会忍不住问：只有两只是不是整走了？这个就是大自然讲笑了：留两只就是为了让你觉得它可爱，其实它根本是靠整条身蠕过去——这个就是生物界的"骗人东西"。

所以下次见到粉红色、像蚯蚓又像蜥蜴的东西，千万不要说是蚯蚓——它是有脚的爬行动物，虽然只有两只，虽然几乎不使用，但真是有的！
