# 冷到你不信 - 莫桑比克喷毒眼镜蛇

训练有素的狙击手——莫桑比克喷毒眼镜蛇，喷距厉害过气枪！

你可能会说，喷毒？不是用咬的，而是用喷的？你猜对了！这只蛇不仅会咬，还要会喷——喷到2到3米远，而且说喷哪里就喷哪里，"枪法"很精准！

兄弟们你知不知道莫桑比克喷毒眼镜蛇为什么叫"狙击手"？

准备攻击时会先调整姿势，将三分之二的身体仰起身，然后张开嘴——"噗"一声，毒液就喷出去！精准到可以喷到你的眼睛！这个就叫做"狙击手"！

你知不知道喷毒原理？

收缩毒囊附近的肌肉，用挤压的力量将毒液压出来——毒液流进空心毒牙——然后从毒牙射出来！这个就叫做"液压原理"！

你知不知道喷毒的时候发生什么？

毒液离开毒牙的时候，肺里会冲出一股气流，将毒液变成很小的毒液滴——然后射向敌人！这个就叫做"气流加速"！

各位兄弟，接下来讲的，就是莫桑比克喷毒眼镜蛇最厉害之处。

2到3米精准射击，"枪法"厉害过很多真狙击手！而且是"训练有素"——不是天生的，而是进化出来的技能！

所以下次见到这只蛇，记得——这是可以精准喷毒到你眼睛的"狙击手"，不要碰它！
