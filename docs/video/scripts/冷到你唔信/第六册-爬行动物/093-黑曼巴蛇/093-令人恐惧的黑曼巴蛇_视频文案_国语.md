# 冷到你不信 - 黑曼巴蛇

兄弟们，跑得快、毒得厉害——黑曼巴蛇，非洲死神，跑不过就死！

好了，你可能会说，黑曼巴蛇？黑色？曼巴？多吓人！如果你问一个生活在撒哈拉沙漠以南地区的人，他的噩梦是什么，可能答案就是黑曼巴蛇！这个就证明它有多吓人！

你知道不知道黑曼巴蛇有多长？

身长可达4米以上——是世界第二长毒蛇！仅次于眼镜王蛇！而且攻击时张开嘴，露出黑漆漆的口腔——令人不寒而栗！

不过呢，你知道不知道黑曼巴蛇有多快？

可以以每小时16千米的速度追击敌人！相当于自行车快速骑行的速度——你跑都跑不掉！

其实呢，你知道不知道黑曼巴蛇毒性发作有多快？

毒液可以在10分钟以内毒性发作！1957年至1979年，南非有2500多例毒蛇咬人事件，其中70多例是黑曼巴蛇造成——21例死亡！这个就是"致命效率"！

但是！你知道不知道黑曼巴蛇不会主动攻击人？

虽然厉害，但性格其实很谨慎——一般不会主动攻击人。所以只要不要挑衅它，就不会出事！

顺便提一提，各位，接下来讲的，就是黑曼巴蛇最令人恐惧之处。

4米长、16千米时速、10分钟致命——但依然不会主动攻击人！这个就是"武力高强但是低调"！

所以下次见到黑嘴的蛇，记得——这是世界第二长毒蛇，可以追到你跑掉，但依然守规矩不主动攻击！
