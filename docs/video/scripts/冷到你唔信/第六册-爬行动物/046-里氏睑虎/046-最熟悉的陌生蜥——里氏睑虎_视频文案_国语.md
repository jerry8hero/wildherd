# 冷到你不信 - 里氏睑虎

你家见到的那只壁虎，就是它——里氏睑虎，最面熟的陌生蜥！

你可能会说，睑虎？睑虎是什么？吃得吗？不用问，肯定有好多人连名字都没听过。但我讲一样东西，你可能立即"哦"一声——它们一家都是夜行动物对眼超大像金刚狼，而且会爬墙！是的，睑虎是壁虎的亲戚来的，不过样子再帅一点。

里氏睑虎，又叫"利希登费尔兹睑虎"，这个名字搭不搭先？搭到呢——这个名字是来自越南河内一个工程师，叫卡尔雷斯·利希登费尔兹。这位猛人不知是什么时候抓了几只睑虎，寄去了法国国家自然历史博物馆。1897年，科学家正式帮它们命名——里氏睑虎就此诞生！睑虎家族第一位成员，是祖宗来的！

兄弟们你知不知道？里氏睑虎和海南睑虎像到入木三分！

两者身体底色都是黑色或灰色，身上都有4条黄色横纹——第一眼望过去，基本分不清。你以为是一只？不是的，虽然像，但有些微妙分别：里氏睑虎颈上第一条横纹，靠近耳孔和嘴角的时候，颜色会慢慢变淡直至消失；但海南睑虎呢？条横纹就像拿着支荧光笔那样，穿过耳孔直达嘴角，颜色从头到尾都这么饱满！

你就这样记：里氏睑虎条横纹"甩色"，海南睑虎条横纹"不甩色"——够简单了吧？

说到里氏睑虎最厉害的身份，当然是睑虎家族的老祖宗！

1897年被正式命名，成为睑虎科第一位正式成员。简单来说，就是"睑虎这个家族，由我开山"。你说多厉害？但这个厉害身份是要付出代价的——因为它是最早被研究的睑虎，所以科学家整天拿它来和其他睑虎比较，结果发现海南睑虎、广西睑虎等各种睑虎都是"后来者"，全部像足里氏睑虎但又各有不同。就像家族里面那个大哥，个个弟弟都像你但又不是你——压力多大你知不知道？

各位兄弟，接下来讲的，就是里氏睑虎最奇葩的求生技能。

睑虎类的英文名叫"eyelid gecko"——就是有眼睑的守宫！普通壁虎只可以靠层膜眨眼，但睑虎就有眼皮，可以像我们一样眨眼！这个设定多luxury？养过守宫的都知道，这是多厉害的特征。

更厉害的是，睑虎和其他守宫一样，受到威胁时会自动断尾走人——然后条尾会原地跳跳扎扎，吸引捕食者注意，它就趁机跑路。这个就是经典的"分身术"了：牺牲一条尾，换回条命，抵！

想象一下，你在家突然有条蜥蜴冲出来甩掉条尾跳走——不用怕，不是它在做什么表演，是它的保命绝招来的。
