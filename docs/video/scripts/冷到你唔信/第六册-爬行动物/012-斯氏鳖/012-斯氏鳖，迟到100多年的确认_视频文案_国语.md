# 冷到你不信 - 斯氏鳖

兄弟们，迟到100年才被确认身份，斯氏鳖——动物界的迟到王，科学家都忍不住笑！

好了，我今天讲只厉害到你不信的鳖——斯氏鳖！

你可能会问，斯氏鳖？没听过啊？不要紧，我们慢慢聊。

这个家伙，多厉害？身长成米多，重量成70到100千克——就是鳖界里面的"巨无霸"！你以为鳖都是小小只蹲在那里吗？这只就是鳖里面的"大只佬"，不说还以为是小个富士山。

但是这个家伙厉害不止这么简单。

你知不知道，斯氏鳖在中国南部、越南北部的淡水河里住了多久？成几代人了！但是——1873年西方学者已经为它科学命名，但是一直以来都被误认为是鼋或者中华鳖。就是因为你没认清我，我就不存在？这个就是生物学界的"隐形鳖"。

更离谱的是，等到21世纪才确认它是有效物种——就是迟到了成100年！100年啊！它在那里住了成年，人类就当它不存在。这种待遇，多惨。

不过呢，说到斯氏鳖最惨的故事，就是这样——

本来80年代国家出名单保护野生动物，它应该上榜的！但是一直被误认为是鼋或者中华鳖，不好意思，你不属于你，你只属于"其他鳖类"。所以呢，就是这100年间，斯氏鳖就是在那里静静地做它的"隐形生物"。

但是！2021年终于平反！斯氏鳖正式列入中国《国家重点保护野生动物名录》，而且是一级保护！就是国家级的最高级别了！但是呢——

顺便提一提，各位，接下来讲的，就是斯氏鳖最催泪的事实。

目前已知活在世上的斯氏鳖，可能只有两只，而且——两只都是雄性。一只在苏州动物园，另一只可能在越南河内。两只都是公公来的！

你想一下，100几年前，它们的祖先在河里游着游着，现在只剩两只公公，而且不同地方，想见见面都还没得。

这个就是最残酷的现实：确认得太迟，忘记得太久，现在想保护，都已经太迟。

不过，科学家还没放弃希望。如果找到越南那只，或者有其他野生种群未被发现，那就还有转机的。所以苏州动物园那只公公，就是目前最重要的"独苗"。
