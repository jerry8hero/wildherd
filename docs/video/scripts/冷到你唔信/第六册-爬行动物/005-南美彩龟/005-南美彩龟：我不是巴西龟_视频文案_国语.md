# 冷到你不信 - 南美彩龟

兄弟们，经常被误认为巴西龟，南美彩龟表示：我不是替代品！我有自己的独特魅力！

好了，你可能会问，南美彩龟？不熟啊！但我讲个名字你一定知道——"巴西龟"！花鸟市场几块钱一只，入门级水龟，几乎每个爬友都养过。但你知不知道，你养的那只"巴西龟"，可能连巴西国旗都没见过。

这个就是今天要讲的冷知识——"巴西龟"这个名字，根本就是张冠李戴！

其实呢，你知道不知道？"巴西龟"其实不是来自巴西，而是来自南美洲！

为什么会搞成这样？事缘在几十年前，台湾最早引入这种龟的时候，因为它来自南美洲，就叫做"巴西龟"。后来大陆也从台湾引进，因为运费等问题，改用北美洲的红耳龟——但是名字已经叫开了，"巴西龟"这个名字就这样继续用下去。

所以呢，你买的那只"巴西龟"，可能是坐长途飞机从美国飞过来的，但是被叫了几十年"巴西龟"，它自己都一头雾水。

不过呢，说到分辨南美彩龟和红耳龟，就是看耳朵！红耳龟如其名，耳朵附近有两条红色条纹；南美彩龟呢？耳朵附近干干净净，什么红色条纹都没有！就像你看人，红色围巾就当然是红耳龟，没围巾就是南美彩龟——多简单。

但是，顺便提一提，现在很多杂交种，真的要专业眼光才分得清。所以如果你在宠物店买龟，不要只靠名字，要自己看清楚先。

你知道吗？南美彩龟虽然长得像红耳龟，但性格就好安静很多。

红耳龟什么名？"扫地僧"——走位风骚，攻击性强，经常追着人手转。南美彩龟呢？就比较淡定，不会主动攻击，就算你走近它，它都是一副"你玩你的，我游我的"样子。

但是，不要以为它好随便！南美彩龟其实很喜欢晒太阳的——每天都会在石头上晒一阵，等体温升高，帮助消化。所以养它记得搭个高出水面的晒台，让它可以做个安静的日光浴。

各位，接下来讲的，就是南美彩龟最冤的地方——名不副实。

它明明不是来自巴西，但是被叫了几十年"巴西龟"。它明明安静好养，但是因为名字骗了好多人，以为它是红耳龟，结果养完才发现完全是两个品种。

这个就是造物主的奇葩逻辑：搞错了你的产地，但是改不了你的户口。
