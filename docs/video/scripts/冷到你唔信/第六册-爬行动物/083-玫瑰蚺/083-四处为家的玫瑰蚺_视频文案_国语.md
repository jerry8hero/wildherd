# 冷到你不信 - 玫瑰蚺

世界这么大我想去静静——玫瑰蚺，去哪里？找个角落蜷起来！

你可能会说，玫瑰蚺？是不是因为长得像玫瑰花？你猜中一半！玫瑰蚺确实好看，但"玫瑰"这个名字可能是因为它的颜色像玫瑰——但不要以为它是娇滴滴的东西，它其实很能吃苦！

兄弟们你知不知道玫瑰蚺有多遍？

从美国加利福尼亚州圣迭戈的沿海山脉，向北到莫哈维沙漠，向东到索诺兰沙漠——全部都见到它们！干旱灌木丛、沙质平原、岩石斜坡、灌木丛覆盖的山麓——什么环境都行！这个就叫做"打仔到处为家"！

你知不知道玫瑰蚺有多小只？

出生的时候只有20到30厘米，大个了都不超过90厘米——就不过你家那支拐杖长！但小不代表好欺负，它依然是出色的猎手！

你知不知道玫瑰蚺长得有多有趣？

鳞片滑溜溜，尾巴形状像工人叔叔用的锥子——尖尖的！但样子好看不代表是废物，它依然是捕猎高手！

各位兄弟，接下来讲的，就是玫瑰蚺最有趣的生存能力。

四处为家，什么环境都行；小只，但可以在沙漠和岩石区生存——这个就叫做"打不死的小强"！

所以下次见到滑溜溜的小蛇，记得——这是"四处为家"的玫瑰蚺，好看但是很能打！
