# 冷到你不信 - 非洲树蛇

纤细但有剧毒——非洲树蛇，漂亮样子骗你，其实很毒！

你可能会说，非洲树蛇？树蛇？应该都是无毒的吧？错！非洲树蛇虽然属游蛇类，一般无毒，但它是少数能用毒的游蛇——就是骗你！

兄弟们你知不知道非洲树蛇有多阴毒？

被咬伤之后毒性发作很慢，"受害者"开始以为自己没事——谁知后来就开始恶心、发烧，过了一天就说拜拜！1957年，美国爬行动物学家卡尔·施密特就是被一条幼年非洲树蛇咬，结果低估了毒性，几个小时后出现症状，过了一天就死了！

你知不知道非洲树蛇有多能吃？

可以将嘴张到170度——就是上下颚快呈一条直线！然后一口吞掉猎物——这个就叫做"超级大嘴"！

你知不知道非洲树蛇生活习惯？

属游蛇类，生活在非洲撒哈拉沙漠以南——喜欢爬树，喜欢埋伏，等猎物过路然后一击即中！这个叫做"伏击型选手"！

各位兄弟，接下来讲的，就是非洲树蛇最令人惊讶的事实。

明明是游蛇类，本来应该无毒，但是就进化出毒液——这个就叫做"转型成功"！而且毒性发作慢，但是依然可以致命——这个就叫做"笑里藏刀"！

所以下次见到非洲树蛇，记得——这是可以张嘴170度、毒性发作慢但是依然致命的"伪装者"！
