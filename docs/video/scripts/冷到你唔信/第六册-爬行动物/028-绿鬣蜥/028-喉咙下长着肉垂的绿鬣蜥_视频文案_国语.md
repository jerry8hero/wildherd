# 冷到你不信 - 绿鬣蜥

兄弟们，喉咙下面甩着块肉，看上去像有痰——绿鬣蜥，但这块东西不是病，而是社交神器！

好了，你可能会说，鬣蜥？听起来像个发型名？你猜下"鬣"是什么意思？就是动物头上或脖子上的毛——绿鬣蜥就是头上梳着一排竖起来的毛，帅到呢！

不要以为它只是样子厉害，其实它一排特殊鳞片从头延伸到背脊再延伸到尾巴，又细又长看上去像立起来的毛。就是因为这身这么有型的打扮，它才叫"鬣"蜥——一身竖发，走出来就像个摇滚巨星一样。

其实呢，你知不知道？这个看上去这么厉害的家伙，其实脾气出奇地好！

绿鬣蜥是完全的素食主义者，餐餐都吃植物的叶子、花和水果，不像其他蜥蜴那样什么都吃。在爬行动物里面，它就是这么清新脱俗——不打不抢，只是吃草。这个大概就是爬行动物界的佛系代表了。

但是啊，说到绿鬣蜥最有趣的东西，当然是它喉咙下面那个肉嘟嘟的结构——

你以为它只是用来发声或者求婚？你又中计了！这个肉垂叫做"喉扇"，遇到天敌的时候会展开变成一面大帆，配合全身竖起来的鳞片，看上去大只了很多！敌人第一时间会想：这家伙是不是开大了？

如果对方还是不怕，继续攻过来呢？绿鬣蜥就出大招了——用条像鞭子一样的尾巴抽过去！一下一下抽到你眼都花，再加上可以连续抽好几下——就像古装片里面主角发恶那样！你敢再动就请你吃鞭！

所以呢，虽然绿鬣蜥脾气好，但是不要惹它啊——它不发火不代表你好惹！

顺便提一提，你知不知道？绿鬣蜥是素食爬行动物里面体型最大的品种之一！

纪录说最厉害可以长到两米那么长，体重成二十几磅！两米长的蜥蜴慢慢向你走过来——这个画面多有压迫感。但是呢，它偏偏就是个素食者，不吃肉的！这个大概就是"外表凶狠，内心温柔"的最佳示范了。

想象一下，它慢慢嚼着一片生菜，你看着它觉得它好可爱，但突然它转头望你，这一下就挺有画面感。

讲完，说到绿鬣蜥最厉害的防御技能，当然是——先吓后打！

首先展开喉扇令自己看上去大只一点，如果对方还是不收手，条尾就出鞘！这种"先礼后兵"的策略，多有武士道精神。而且它条尾很长，打下去真的挺痛，有研究显示绿鬣蜥的尾击可以打出很大声音——啪一声，敌人就知道死了。

所以下次见到绿鬣蜥，记得不要骚扰它——你骚扰它，它就请你吃鞭！

各位，接下来讲的，就是绿鬣蜥最有趣的生存智慧。

绿鬣蜥虽然外表厉害，但它们其实很少主动攻击人。遇到危险呢，它们宁愿跑都不动！因为它们知道，真正的强者不需要年年在这里打打杀杀——保存实力，留待真正需要的时候才用，这个就是绿鬣蜥的生存之道。

它们跑起来都挺快的，遇到危险会用后腿跑，短距离冲刺厉害过好多人想象！如果真的跑不掉，才会用到喉扇警戒，再不行才会动用条尾反击。这套"跑—吓—打"的三级策略，真是设计得很完美。

这个就是大自然的奇妙之处：不一定要打得赢，先要懂得走位。
