# 冷到你不信 - 真鳄龟

兄弟们，水里面有只"装甲恐龙"？真鳄龟——咬合力厉害到可以咬断骨头，是龟界的终极杀手！

好了，你可能会说，龟我见得多了，不就是慢吞吞任人摆布的小孩？你如果这样想就错了。真鳄龟可不是你想象中那种普通龟，它是北美洲淡水龟王！整只装甲恐龙一样，大脑壳、3条威风凛凛的大鳞脊，俨然就是已灭绝的装甲恐龙转世——造物主大概是想不出还有什么新花样，就将恐龙的灵魂塞进龟壳里试试。

你知道不知道真鳄龟有多大只？成年龟壳长度可达80厘米——差不多一张A3纸那么大！体重更离谱，可以去到80千克，就是160斤，一袋水泥都没那么重。养它的话，你家那个池子起码要有个浴缸才行。

更厉害的是，据说1937年在美国堪萨斯州发现了一只180多千克的巨型真鳄龟！就是说，它可以是龟界的绿巨人，胖起来真的没边。

但是啊，说到真鳄龟最厉害的东西，当然是它那个像雄鹰一样的大嘴——咬合力厉害到你不信！

它的嘴像鹰嘴，咬下去有力到呢，可以将你手指干脆利落地咬断！就是这样，一，一下子，没了。就是这样说。想象一下，你手指伸进水里，它以为你要偷袭它，这下它就不客气了。

不过呢，它其实轻易不咬人的——除非真的感觉到威胁。就像你家那只大狗，平时笑嘻嘻，不小心踩到它尾巴就知道死了。

其实呢，你知不知道？真鳄龟因为过度捕捞，已经被世界自然保护联盟列为易危物种。

就是因为它的样子够凶、肉又好吃，所以被人狂抓。什么世界？表面威风凛凛，实则被人摆上餐桌——这个就是所谓的"龟间悲剧"了。

顺便提一提，说到真鳄龟最厉害的外表，当然是它那个装甲恐龙风——3条大鳞脊就是这么威！

这3条大鳞脊不是只是好看的，是真的可以防御的。像搭棚一样，凸出来的鳞片可以挡住一些攻击。不信？你试下咬一口看看——不要啦，真的会咬你的。

所以呢，如果你在河边见到它，千万不要好奇心爆棚伸手去摸——这个不是普通龟，是可以还手的。

各位，接下来讲的，就是真鳄龟最鲜为人知的生存之道。

虽然它外表够凶，咬合力厉害到你不信，但是呢，它其实是一个很有趣的伏击型猎手。它们喜欢潜伏在水草里，等小鱼游过来——然后一下子嘴张开，水流夹在一起冲进去，连东西带水一起咬——就像自然界的真空吸尘器。

这种捕猎方式省水省力，不像其他龟那样追来追去那么辛苦。就是说，它外表是装甲战士，内心其实是一个喜欢静静设伏骗你的骗子。

这个就是大自然最有趣的设计：不靠拳头大，靠骗你不到。
