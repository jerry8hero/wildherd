# 冷到你不信 - 饼干龟

兄弟们，背脊像块饼干，扁平到可以滑下楼梯——饼干龟，龟界最有趣的"压缩包"！

好了，我们从头讲起。今天聊聊，讲只名字很有趣的陆龟——饼干龟！

你可能会说，饼干龟？是不是味道的饼干啊？难道只龟里面是空心的？如果你这样想，就错了。饼干龟不是用来吃的，而是因为它个壳厉害到像一块薄饼干！

你知不知道，饼干龟个壳可以有多夸张？扁平平的，简直像你吃的消化饼！成年的可以超过17厘米——你就是当真是一块17厘米大的饼干。不过这块"饼干"就不太好吃了，味道应该一般。

但是啊，说到个壳，就不能不提它最厉害的地方——厉害到呢，厉害到个壳充满孔洞！

它的壳不像其他龟那样实心，是由脊椎、肋骨、腹肋、胸骨一起愈合形成的外骨骼，但因为有很多孔洞，所以很轻盈。普通陆龟背住个壳就像背住块石头，饼干龟呢？就像背住块威化饼，轻飘飘，走起来都比其他陆龟敏捷很多。就像你背个书包和人家背个铁箱，怎么追啊！

不过呢，很有趣的外形反而害了它。

因为样子太有趣，饼干龟被人看中，大量捕捉去做宠物。想象一下，你天生很样子骗到很多粉丝，本来生活得好好的，结果被人说"你这么有趣，我要带你走"——饼干龟表示：我只是想安静做块饼干而已！

其实呢，说到吃方面，饼干龟就不是素食者了。

它们在野外什么都吃——草、树叶、花、水果，甚至动物尸体都行。就像个素食者突然说"我今天想试下川菜"，完全不像你想象中那种只坐不动的乖龟。

顺便提一提，各位，接下来讲的，就是饼干龟最有趣的生存绝技。

除了很轻盈，饼干龟还有一个很厉害的东西——它们可以爬得很高！虽然不是很大只，但是四肢有力，攀石爬树都OK。就像一个灵活的小胖子，不要小看它！

不过这个技能都有代价——因为太容易被人捉走，加上栖息地破坏，现在野生饼干龟数量已经开始减少。下次见到这么有趣的"饼干"，记得远观不要亵玩啦！
