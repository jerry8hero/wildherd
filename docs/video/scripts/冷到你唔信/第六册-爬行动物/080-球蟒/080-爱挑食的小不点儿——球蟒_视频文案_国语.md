# 冷到你不信 - 球蟒

球蟒——为了吃不愿动，一星期只吃一餐，养它真是要耐心！

你可能会说，球蟒？是不是可以当球玩？不好意思，你猜错了！球蟒之所以叫球蟒，就是因为遇到危险的时候会将身体蜷缩成一个球——然后将头、脖子这些容易受攻击的部位藏在球中心——这个就是"球"的由来！

兄弟们你知道不知道球蟒有多大只？

它是蟒蛇中的"小不点儿"，最大身长都只有1米多——完全不像你想象中那些几米长的巨蟒！但是小不代表你好惹，它们依然是蟒蛇！

你知道不知道球蟒有多懒？

这个家伙很懒的！不喜欢自己挖洞，总是找些其他动物挖好的洞来住。夏天会呼呼大睡——就是这样享受世界！

但是！你知道不知道球蟒有个很大问题——挑食！

它喜欢吃大只一点的猎物，如果猎物不满意，宁愿不吃！人工养的有时会"绝食"，甚至饿死——这个就是"有性格"！

你知道不知道尼日利亚人对球蟒有多尊敬？

在尼日利亚东南部，球蟒被视为地球的象征。遇到球蟒会将它送回远离人群的安全地带；遇到死了的球蟒，还会为它举行葬礼——这个就是"文化信仰"！

各位兄弟，接下来讲的，就是球蟒最有趣的"球形防御"。

将身体卷成一个球，头藏在中间——这个就是真正的"防御姿态"，而且它们可以做到很圆很圆，像个球一样！

所以下次见到可以卷成球的蟒蛇，记得——这是挑食、喜欢享受世界、而且被尼日利亚人尊重的"球蟒"！
