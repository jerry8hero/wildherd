# 冷到你不信 - 白唇树蜥

白色嘴唇、绿色身体——白唇树蜥，明明可以靠样子，现在要用实力！

你可能会说，树蜥我见得多了，不就是绿色那些？你如果这样想，就错了。白唇树蜥可不是你想象中那种普通绿色蜥蜴，它的嘴唇有一条白色花纹，一路延伸到身体侧面——就像画了条白色眼影线那样，非常有辨识度。但是等等，这不是重点，重点是它们会"换衣服"！

兄弟们你知不知道白唇树蜥平时穿什么衣服？棕色、橄榄色，单调到像你件旧卫衣。但是！一到交配季节，它就会华丽转身，换上一身炫亮的蓝色"战袍"——主要是身体前部变蓝，蓝到那样！

这个时候它们还会做一件事——疯狂地上下摇晃个细头仔，像跳着迷你舞那样，就是为了吸引异性。蜥蜴版的广场舞就是这个意思！

你知不知道？白唇树蜥的蓝色战袍不是整天都有的！

平时它就是一只低调的棕色蜥蜴，一点都不起眼。但繁殖季节一到，它就会在自己的地盘内疯狂展示——身体前部变蓝，头仔又摇下摇下，快过你去健身房的时候show腹肌！

而且这种蓝色多厉害？厉害到呢——科学家都专门研究过它们的体色变化。蓝色的鲜艳程度直接和它的健康状况挂钩，越蓝就代表越健康。就像你见不到哪个大陆说自己环保，但是蓝到这只蜥蜴就是自然界的健康码——绿码代表不代表健康我不知道，但蓝码就肯定健康！

说到吸引异性，白唇树蜥就是最佳示范。

它们会用一种很搞笑的方式——不停地上下点头，就像小学生举手回答问题那样。但这个动作是有东西的！科学家发现，这种头部摇摆不仅是为了吸引异性，还可以威慑竞争对手——这么大只蜥蜴，不用武力，靠跳舞就可以搞定！

这种行为在爬行动物里面挺少见的，大多数爬虫都是靠打架解决问题，但白唇树蜥就选择用最优雅的方式：跳舞不打架！

各位兄弟，接下来讲的，就是白唇树蜥最厉害的生存技能。

白唇树蜥主要栖息在树林边缘和灌木丛，它们的攀爬能力厉害到呢——可以在很滑的树干上随意行走。因为它们的脚趾有特殊的鳞片结构，可以增加摩擦力，就像穿着对爬树专用的那样！

这种设计就厉害了，好过你买那对天价跑步鞋，它是免费的而且还防滑！进化论真是什么都想得出。

所以下次你见到一只棕色蜥蜴在树上爬来爬去，不要立即走开——等它show下蓝色先，因为它可能是伪装了的白唇树蜥！
