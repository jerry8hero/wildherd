# 冷到你不信 - 圆鼻巨蜥

中国有龙？圆鼻巨蜥——身形像龙、骚味像龙，这只就是现实版中国龙！

你可能会说，巨蜥？不就是放大版的四脚蛇，有多厉害？你如果这样想，就错了。圆鼻巨蜥在中国华南、西南部分地区，当地人叫它"五爪金龙"——注意是金龙哦！是我们中国版的"龙"！

兄弟们你知不知道，圆鼻巨蜥是中国唯一的野生巨蜥？是我们国家土生土长的"龙"来的！不过这条龙不会飞，也不会喷火，它是潜水的——整天浸在水里，就像你家楼下浸温泉那样的大佬，多享受。

说到体型，圆鼻巨蜥厉害不厉害？厉害的！最大的个体超过3米——三米啊！普通成年人张开手臂都没这么长。它们有长长的尾巴，锋利的牙齿和爪子，最厉害的是，每个爪子上有5个脚趾！五爪金龙就是这么来的嘛。

你知不知道？圆鼻巨蜥看上去就像真的龙那样——强劲的嘴巴，配上威风凛凛的气势，个样就像准备好要来一场世纪大战。它们是大型水栖蜥蜴，喜欢住在河边、湖边或者沼泽地带，一言不合就说要下水——这个大概就是它们对"龙"这个名字的理解：潜龙在渊。

你知不知道？关于圆鼻巨蜥的唾液，2023年有单大新闻——说五爪金龙唾液有毒！不知是不是说被咬一口就会原地升天呢？

但是后来专家就出来解画了：作为巨蜥家族的成员，唾液是否有毒尚无定论。就像你说某个人是好人还是坏人，不是非黑即白的——巨蜥家族成员那么多，不可以一概而论。

不过讲开又讲，圆鼻巨蜥的咬合力的确挺厉害，就算没毒，被咬一口都不好，所以见到它们，真是走远点好。

各位兄弟，接下来讲的，就是圆鼻巨蜥最厉害的生存本领。

圆鼻巨蜥是游泳高手，它们可以在水底闭气几分钟——就像你打游戏打到废寝忘餐那样，完全不记得上水面透气。它们的长尾巴就是最佳的游泳工具，划下划下，游得厉害过好多鱼。

它们又会吃各种东西——鱼、蛙、蛇、蟹、虾，有时连腐肉都不放过。就是这样才可以在大自然生存到——有东西吃就吃，不挑剔，这个就是现实版的"务实龙"。

所以下次你听到"龙的传人"，可以幽默下——可能你家边远地区，真是有些亲戚是五爪金龙来的。
