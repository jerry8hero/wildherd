# 冷到你不信 - 内陆太攀蛇

一口毒可以杀100人——内陆太攀蛇，毒蛇界的终极Boss，不要乱动！

你可能会说，内陆太攀蛇？名字这么长！是不是很毒？你这样问就对了！这只蛇被誉为"陆地毒蛇冠军"，毒素厉害到呢——厉害到你不信！

兄弟们你知不知道内陆太攀蛇有多毒？

一次过放的毒，足够取走成100条人命！万一被咬又不立即去看医生，半个钟头到几个钟就会归西——这个就叫做"毒到你不信"！

你知不知道内陆太攀蛇攻击有多快？

快到呢，子弹都追不上！而且极精准——这个就叫做"快准狠"！猎物还没动都已经中招！

但是！你知不知道内陆太攀蛇其实挺害羞？

话说在19世纪末，科学家首次发现这只蛇，但之后成十年都见不到它——一度被认为只是传说中的毒蛇！直到90几年后人类才再次发现——这个就叫做"隐世高人"！

你知不知道内陆太攀蛇为什么叫"太攀"？

因为它们生活在澳洲中部和东部的沙漠地带——"太攀"可能是指这些荒地方？但无论为什么，这个名字已经够厉害！

各位兄弟，接下来讲的，就是内陆太攀蛇最令人惊讶的事实。

明明是地球最毒的蛇之一，但性格好害羞，只是喜欢藏在洞里——当然不会主动撩人！这个就叫做"武力高强但是低调"！

所以下次见到内陆太攀蛇，记得——这是可以取走100条人命的"毒王"，但性格怕怕的，你不要激它就没事！
