# 冷到你不信 - 巴拉圭凯门鳄

小孩那样大但是食人鱼——巴拉圭凯门鳄，迷你杀手，水底狼！

你可能会说，巴拉圭凯门鳄？是不是很吓人？你如果这样想，就答对一半了。这家伙确实有几厉害，但最令人惊讶的不是它有多恶，而是它们的生长速度厉害到你不信！

兄弟们你知不知道巴拉圭凯门鳄有多小？

幼体不计尾巴只有12厘米左右——就像漂浮在湖边灯芯草丛中被风吹动的种子！《美国国家地理》评价说："它们看上去就好像漂浮着的种子"——这个形容多有趣！

但是！你知不知道它大个了有多夸张？

5岁就可以长到50厘米左右，15岁生长完成时可以长到80厘米到1米几！想象一下，你由5岁到15岁，身高增长一倍——普通人做得到吗？这只鳄鱼就做得到！

你知不知道巴拉圭凯门鳄有个很厉害的名——"食人鱼凯门鳄"？

这个不是乱叫的！它下颚那些牙齿可以穿过上颚上面的洞，令到牙齿非常突出——被誉为鳄鱼中的"食人鱼"！这个就叫做"牙尖嘴利"，咬下去很厉害！

说到最夸张，就是这只小孩5岁到15岁可以长几倍——

但如果你5岁到15岁是可以由50厘米变到1米，你妈一定会说："多吃点，行不行呀！"可惜你不是鳄鱼，你不行。

各位兄弟，接下来讲的，就是巴拉圭凯门鳄最厉害的"食人鱼"装备。

牙齿穿过上颚，咬东西下去就像剪刀夹——不是吃你肉，而是直接剪开！这个就是进化的神奇，小小只但是有食人鱼那样的咬合力！

所以下次见到巴拉圭凯门鳄，记得——这是"食人鱼凯门鳄"，小时候像种子，大个时像"剪子"，不要被它骗到！
