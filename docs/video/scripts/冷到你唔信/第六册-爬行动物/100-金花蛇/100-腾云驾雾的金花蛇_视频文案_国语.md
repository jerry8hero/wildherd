# 冷到你不信 - 金花蛇

会滑翔——金花蛇，条条像带东西，树与树之间的直升机！

你可能会说，金花蛇？腾云驾雾？蛇会飞？你没有听错！金花蛇生活在我国南方地区，以及东南亚等热带亚热带地区——森林危机四伏，为了更安全，它演化出在树木间滑翔的惊世绝技！

兄弟们你知不知道金花蛇怎样"飞"？

用强劲肌肉将两侧肋骨外张——管道状身体变扁，空气阻力大增！然后在降落时进行独特扭动——不会翻跟头！这个就叫做"滑翔技术"！

你知不知道金花蛇有多厉害？

可以在树与树之间滑翔——就像无成本飞行那样！而且身形灵活，扭动精准——这个就叫做"空中杂技"！

你知不知道金花蛇生活在哪里？

我国南方——广东、广西、海南、云南都有！以及印度、东南亚等地区——所以我们都有可能见到！但好在它们不是毒蛇——虽然叫"金花"，但对人类友好！

你知不知道金花蛇为什么叫"金花"？

可能因为身上有金色花纹？但实际上这只蛇颜色挺有趣——可能有金黄色图案，攀着树看上去就像金花那样！

各位兄弟，接下来讲的，就是金花蛇最厉害之处。

可以在树木间滑翔，不仅会游泳，还懂得"飞"——这个就叫做"三栖选手"！而且对人类友好，不会主动攻击——所以见到记得不要乱捉！

所以下次见到会滑翔的蛇，记得——这是可以在树间"腾云驾雾"的金花蛇，不是毒蛇，但对人类友好！
