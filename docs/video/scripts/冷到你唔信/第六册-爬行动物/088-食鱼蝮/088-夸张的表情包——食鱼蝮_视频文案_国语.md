# 冷到你不信 - 食鱼蝮

样子丑丑但是说清楚——食鱼蝮，吃鱼就是我的专职，不要叫外卖！

你可能会说，食鱼蝮？吃鱼的？嗯，就是吃鱼！但你知不知道，它遇到危险的时候样子很夸张！

兄弟们你知不知道食鱼蝮有多夸张？

将身体盘绕起来，大脑袋往后一仰，张大嘴巴，露出可怕毒牙！有时还会发出嘶嘶声，脖子和身体前部扭成一个大大的"S"形——就像预示着死亡之神的降临！这个就叫做"表情包本包"！

但是！你知不知道食鱼蝮最搞笑的防御？

它竟然会"放屁"！从肛门附近的腺体喷出有强烈刺激性的分泌物——这个就叫做"生化武器"！

你知不知道食鱼蝮咬人概率有多低？

科学家测试过，45条食鱼蝮中，有接近一半遇到危险会选择跑路——只有被你用手捡起来时，才会咬人！这个叫做"找吃艰难"！

你知不知道食鱼蝮多喜欢吃吃鱼？

就像名字，就是喜欢吃鱼！但有时会被鱼鳍棘卡到嗓子——这个就叫做"吃鱼都会噎"！

各位兄弟，接下来讲的，就是食鱼蝮最有趣的表情包技能。

遇到危险可以扭成S形、可以张嘴露出毒牙、可以实现放屁攻击——这个就叫做"三连击防御"！而且它是世界上少有的半水生毒蛇——会游泳又会放屁！

所以下次见到食鱼蝮，记得——这是可以扭成S形、可以放屁、但是偏向跑路的"表情包蛇"！
