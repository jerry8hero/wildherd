# 冷到你不信 - 塞舌尔巨龟

兄弟们，一只龟可以活到200岁，还要等你去打卡！塞舌尔巨龟——动物界的老寿星，看着文明起起落落。

好了，你可能会说，陆龟我见得多了，不就是慢慢爬的吗？你如果这样想就错了。塞舌尔巨龟可不是你想象中那种普通陆龟，它竟然可以活到150多岁！当你爷爷的爷爷的爷爷……它还是个宝宝！这是最离谱的老寿星，它见证的历史比你家族谱还长。

但是啊，更离谱的是，塞舌尔巨龟是世界上最大的陆龟之一，壳可以长到一米多，整只狗那么大！有只叫亚达伯拉象龟，就是塞舌尔巨龟的代表品种，重量可以去到两三百斤——这个就是爬行动物里面的大象，龟中巨无霸。

其实呢，你知不知道？它可以活到150多岁！

普通人活到一百岁都已经很厉害了，它呢？轻轻松松超过150！科学家研究说它们细胞修复能力强、代谢慢，所以才可以这么长寿。就像你养着只铁甲长寿龟，每天就是慢慢吃、慢慢走、慢慢看世界——将养生这件事做到极致，想不长寿都难。

不过呢，说到慢，当然要提提它们的生活节奏——一天睡足18个小时！

你没有听错，18个小时！不要以为它是懒，它这是节能模式。野外食物不多，要保存体力嘛，难道天天浑身是刀吗。睡醒就吃，吃完又睡，日子就是这么简单纯粹——这个大概就是它长寿的秘诀：不卷、不焦虑、不内耗。

顺便提一提，说到吃，就不得不提它们的素食主义。

亚达伯拉象龟是很纯粹的草食动物，最喜欢就是各种树叶、草、花和水果。野外环境下一只龟一天能消灭很多公斤植物，环保小助手！不过它们对食物有很高的追求——一定要新鲜、一定要绿色、一定不要太硬。人工养的话，可以喂狗尾巴草、红薯叶、油麦菜，加点龟粮调味都行。

但是，千万不要喂葱姜蒜、辣椒、韭菜、鸡蛋壳——这些对龟来说就是毒药！

各位，接下来讲的，就是塞舌尔巨龟最厉害的身份证明。

这是地球上最长寿的陆地脊椎动物之一，150多岁高龄，经历过一战、二战、人类登月、互联网兴起——它都见证过！多厉害？就像你养了只传家宝，比你爷爷留下的，然后一代传一代，家族聚会的时候当然是焦点！
