# 冷到你不信 - 玳瑁

兄弟们，被人类整了千年艺术品，玳瑁——背甲可以做梳子、眼镜框，但是自己就快消失了？

好了，你可能会说，玳瑁？不就是古装片里面那些妃嫔头上戴的梳子吗？如果你这样想，恭喜你答中了一半。玳瑁的确是古代宫女的最爱，但是你知不知道，这种东西竟然是用它们的壳做的？没错，玳瑁只是一只龟，它们就为了这个壳，被人类追了几千年——就像你在街上走着走着，突然有人追着你说要你的壳，这只龟多惨。

你知道不知道玳瑁的壳有多厉害？它是爬行动物里面最漂亮的！

玳瑁壳上面有淡淡的金黄色底色，点缀着放射状的黑色和褐色花纹，就像天然生成的艺术品。古代人就把这些壳切片打磨，做成梳子、戒指、眼镜盒，甚至是酒杯——这个才是真正的"奢侈品"，因为每件都是独一无二的。古代妃嫔戴着它，不仅因为漂亮，还因为觉得可以辟邪。但是问题来了，这样搞法，玳瑁就倒大霉了。

但是啊，说到玳瑁，就不能不提它们的"艺术生涯"。

自古以来，玳瑁壳就被当作高级装饰品材料。你看古装剧里面那些宫女头上戴的梳子，不少都是用玳瑁壳做的。战国时期就已经有这种做法，之后历朝历代都继续。有一段时间，玳瑁甚至成为了身份的象征——你戴得越多名贵，你就越厉害。但是你知不知道，制作一件普通的玳瑁饰品，可能要杀死好几只玳瑁？这个就是人类多厉害了，为了漂亮，可以做到多绝。

其实呢，你知不知道玳瑁现在有多稀有？

因为过度捕捞，玳瑁已经成为濒危物种。它们的壳依然有人想要，但是野生的已经越来越少。泰国、越南、菲律宾等地都曾经是主要捕捞地，后来才慢慢开始保护。但是问题是，玳瑁成长很慢，要十几年才可以繁殖，所以恢复起来都很慢。这个就是"艺术"的代价——人类的爱美之心，令到整个物种都岌岌可危。

顺便提一提，说到玳瑁的饮食习惯，又有东西可以讲。

玳瑁是少数完全不是素食主义的海龟，它们主要吃海绵，偶尔也会吃水母和其他海洋无脊椎动物。就像你以为龟都是素食的，但是玳瑁就告诉你：不要把所有龟都看成吃素的，它们都有自己的口味。科学家还发现，玳瑁吃海绵的时候，会选择某几种特定的品种——不是所有海绵都适合吃的，它们都很会挑东西吃。

你知道不知道玳瑁有多厉害？它们可以潜入几十米深的海底找东西吃。

虽然不及绿海龟潜得那么深，但是玳瑁都可以去到几十米。而且它们游得很快，海里较少对手敢惹它——毕竟壳那么硬，谁想啃这份东西？

各位，接下来讲的，就是玳瑁最惨的故事。

几千年来，玳瑁就因为壳漂亮，被人类追着不放。不仅壳被做成梳子和装饰品，卵也被认为有药用价值而被捕食。科学家估计，全球野生玳瑁数量已经跌到很低很低，大部分地区都开始立法保护。但是走私依然存在，毕竟壳太漂亮了，天然的花纹谁能复制？

这个就是最漂亮的代价：因为你太漂亮，所以你要绝种。
