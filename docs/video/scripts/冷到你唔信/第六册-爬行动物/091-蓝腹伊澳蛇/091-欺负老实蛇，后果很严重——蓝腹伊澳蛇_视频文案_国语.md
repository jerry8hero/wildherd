# 冷到你不信 - 蓝腹伊澳蛇

专整老实蛇——蓝腹伊澳蛇，不要欺负老实人，不要欺负老实蛇！

你可能会说，蓝腹伊澳蛇？和红腹伊澳蛇有什么不同？最大分别就是——红腹伊澳蛇个肚是红色，蓝腹伊澳蛇个肚是灰色或蓝灰色！就是这么简单！

兄弟们你知不知道蓝腹伊澳蛇有多喜欢草地？

喜欢在开阔的草地、草原生活——就是喜欢宽敞的地方！但性格有些害羞，你踩到它或者用棍子戳它，它就不会再等你欺负——会咬你，而且咬上不会松口！

你知不知道蓝腹伊澳蛇有多毒？

比红腹伊澳蛇厉害很多！被咬伤要立刻去看医生——不是后果很严重！这个就叫做"笑里藏刀"——外表安静，内心好狠！

你知不知道蓝腹伊澳蛇为什么叫"欺负老实蛇后果很严重"？

因为红腹伊澳蛇性格比较温顺，不会乱咬。但你踩到蓝腹伊澳蛇？不好意思，它会立刻报复！而且咬上之后还会在伤口反复嚼——这个就叫做"一咬再咬"！

各位兄弟，接下来讲的，就是蓝腹伊澳蛇最厉害之处。

灰色蓝灰色肚皮，就像另一个版本的红腹伊澳蛇。但不要搞它——它会咬，而且不会松口！这个就叫做"喜欢和平，但和尚都怕"！

所以下次见到蓝肚皮的伊澳蛇，记得——这是会咬不放、反复咀嚼的"狠角色"！
