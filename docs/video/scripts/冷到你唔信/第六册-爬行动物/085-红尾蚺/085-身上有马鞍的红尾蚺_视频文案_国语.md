# 冷到你不信 - 红尾蚺

条尾红当当做得很SAD——红尾蚺，马鞍花纹就是它的名牌！

你可能会说，红尾蚺？身上有马鞍？意思是坐上去？不不！红尾蚺身上有红棕色的"马鞍"图案——这个图案在尾端更加明显，所以叫"红尾蚺"！

兄弟们你知不知道红尾蚺有多大只？

有多大？有个故事——有两条生活在南美洲苏里南的红尾蚺，身长都超过4米！相当于2到3头成年猪连起来那么长！4米啊——你试下想象一下！

你知不知道红尾蚺条尾有多厉害？

条尾像一只灵活有力的"大手"，可以帮助它们抓紧东西——攀爬、缠绕都靠这条尾！这个就叫做"尾有独用"！

你知不知道红尾蚺有多喜欢吃老鼠？

主要食物就是老鼠，但偶尔会换下口味——抓大蜥蜴，甚至猫科动物！这个叫做"不挑食"！

但是！你知不知道红尾蚺性格多不稳定？

有些地方的红尾蚺脾气特别差，一言不合就生气，发出嘶嘶声然后猛咬；但有些地方的就性格温柔——这个就叫做"看地方"！

各位兄弟，接下来讲的，就是红尾蚺最有趣的"马鞍图案"。

红棕色马鞍图案，尾端特别明显——这个就是它的身份证。而且4米长，条尾可以当手用——这个叫做"大只但灵活"！

所以下次见到有马鞍图案的蛇，记得——这是可以超过4米长、条尾可以当手用的红尾蚺！
