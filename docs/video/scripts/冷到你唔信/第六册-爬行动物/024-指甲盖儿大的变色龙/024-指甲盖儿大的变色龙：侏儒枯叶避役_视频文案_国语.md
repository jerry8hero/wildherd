# 冷到你不信 - 侏儒枯叶避役

兄弟们，世界上最小的变色龙，小过指甲盖——侏儒枯叶避役，想捉都捉不到！

好了，你可能会说，蜥蜴我见得多了，不就是变色龙吗？它们会变色的嘛，有什么出奇？你如果这样想，就错了。这个家伙呢，成年后只有——你猜下有多小？成年人的指甲盖那么大！不是开玩笑，真是只有这么大只，科学家发现的时候都忍不住说："这家伙是不是真的蜥蜴来的？"

2012年，德国和美国科学家在马达加斯加一下子就发现了4种新的变色龙——全部都是这种迷你size。你知不知道发现地点在哪里？哈拉岛的热带雨林。就是这么小的地方，居然住着几只这么有趣的小精灵，科学家真是捡到宝。

但是啊，说到它有多小，就厉害了。你可以将它放在你手指公上，从鼻尖到尾巴量完，才不够30毫米！整只东西就这么大只，还小过一粒花生。你知不知道普通蜥蜴有多长？就算是壁虎仔，都起码有人家几只那么大。但是这种东西——不好意思，基因决定了它只能长到这么大。

但是它这么小，到底是优点还是缺点？就像你看古装片见到那些武林高手，小小粒但是厉害到不行。这个家伙可能就是世界上最细的蜥蜴之一，到底是不是"最"就见仁见智，但说到小，它肯定是头几名。

更神奇的是，它们身体是棕色的，不会变色——对，你没有听错，它是变色龙但是不会变色！为什么？因为它根本不需要。它们演化到可以模拟枯叶的样子，静静地躲在枯叶堆里面，你走过都不知道有只东西在那里。就是这样，隐身技能就这么厉害！

其实呢，你知不知道为什么科学家要花那么多心思才确认它们是4种不同的个体？因为它们看上去真的差不多样子，完全分不开！最后要靠分子遗传学分析，才认定它们是不同的品种。这个大概就是生物界最厉害的"找人游戏"：我看你们样子都差不多，但是DNA告诉你——不是的，你们不同的！

顺便提一提，说到生存能力，这个小家伙就厉害了。在马达加斯加的热带雨林里面，它们就是最厉害的伪装大师。棕色的身体，扁的样子，放在枯叶上一趴，捕食者根本看不到。这个就是花最小的力气，下最大的雨——不对，是最稳的防护。

想象一下，你是只小鸟，飞来飞去找吃的，突然见到一片枯叶——不好意思，这片不是叶，这是变色龙。你想吃它？sorry，已经走了。这种反应速度就是它们的保命绝招。

各位，接下来讲的，就是侏儒枯叶避役最厉害的生存之道。

小小一只，不仅会隐身，还要懂得分辨哪些枯叶是安全哪些不是。它不靠颜色骗人，靠的是——静静地，等你走过。所以呢，大自然教我们的道理就是：有时候不用太张扬，低调才是王道。

但是这些小家伙也有它们的难处——因为太小，所以好多时候被忽略。科学家也是等到2012年才正式发现它们，它们其实已经在马达加斯加静静地生活了几百万年。这些才是真正的隐世高人——不是你找不到它，而是它根本不想你找到。
