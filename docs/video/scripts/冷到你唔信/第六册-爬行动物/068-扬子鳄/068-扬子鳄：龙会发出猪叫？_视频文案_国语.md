# 冷到你不信 - 扬子鳄

中国独有鳄鱼，叫声像猪——扬子鳄，龙族耻笑，但是国家一级！

你可能会说，扬子鳄？哦，就那种很稀有的鳄鱼吧？你如果这样想，就错了。扬子鳄竟然有个很厉害的名——鼍龙、猪婆龙！而且它会发出像猪叫的声音——龙叫猪叫傻傻分不清！

兄弟们你知不知道扬子鳄为什么被古人称为"龙"？

先秦古籍《山海经》记载，有一种长着龙头的"雷神"，当鼓起肚仔时能够发出雷鸣般的吼叫——这个雷神的原型可能就是扬子鳄！古人见到它发声，以为是神兽降世——多厉害，我们中国本土都有"龙"！

但你知不知道？扬子鳄其实没有声带！

没错，它根本没声带——但它可以利用腭帆、喉褶、和鼻瓣等器官发出两种不同的叫声。听起来像敲鼓、像雷鸣、更有点像猪叫——这个就叫做"口技"！

你知不知道古人为什么叫它"猪婆龙"？

因为有人觉得它的叫声像猪叫，所以又叫它"猪婆龙"。但你不要以为它是猪啊，它是正牌恐龙的亲戚——鼍类的代表！多有趣，历史记载和现实混合，名字就变成了这样。

说到扬子鳄最厉害之处，就是它是我们中国特有的极危物种！

数量少到呢，野生扬子鳄大概只有几百只。但国家很重视，已经列为一级保护动物——你敢搞它？不好彩啊！

想象一下，你在安徽、浙江一带见到它——这个"龙"慢慢游过去，但叫声像猪——多有趣！

各位兄弟，接下来讲的，就是扬子鳄最有趣的身份。

它是"鼍龙"，是"猪婆龙"，是中国特有的极危物种。叫它"龙"也好，叫它"猪"也好，它依然是我们国家的宝贝——而且是活化石，几千万年前就已经存在！

所以下次见到扬子鳄，记得——这是可以发出猪叫的"中国龙"，而且是国家一级保护动物，不要随便伸手去摸！
