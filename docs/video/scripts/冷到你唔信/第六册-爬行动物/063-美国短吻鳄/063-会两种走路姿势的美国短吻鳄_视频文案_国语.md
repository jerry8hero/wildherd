# 冷到你不信 - 美国短吻鳄

急事慢做事，两种走路姿势——美国短吻鳄，慢都要惊人的方法！

你可能会说，鳄鱼我见得多了，不就是条大蜥蜴？你如果这样想，就错了。美国短吻鳄可不是普通鳄鱼，它是西半球最大的鳄鱼品种，身长可以超过4米——这么多位，多夸张？就是差不多等同一架小汽车那样！想象一下，你在停车场突然有条4米长的大鳄鱼在你前面走过，这个画面多恐怖？

但它最厉害的不是体型，而是——走路姿势！

兄弟们你知不知道鳄鱼可以两种方式走路？低走和高走！

低走就是肚皮整块那样粘在地下爬，走得好像蛇那样，全身一弹一弹那样匍匐前进。但高走就厉害了——它会撑起四条腿，将个肚整块抬离地面！就像你做掌上压那样，将整只鳄鱼撑起身来走。包你猜不到，爬行动物也可以这么帅这么有型！

说到体型，美国短吻鳄就是美国东南部淡水湿地的绝对王者。西半球鳄鱼家族里面，它最大只。雄性可以长到4米以上，雌性就小点，但都不可以说少。

兄弟们你知不知道美国短吻鳄有多好牙？成口有七八十只牙！每只都尖尖那样生在那里，而且旧牙掉了，新牙又会生出来添。由不得你不信，它们一辈子可以换过千几只牙！这个就是名副其实的"铁齿铜牙"。

但最夸张的是，它真是一个超级大吃货——

美国短吻鳄是名副其实的食货，它几乎什么都吃！鱼类、鸟类、蛇类、龟类，统统都是它的菜单。但你以为它只是吃小东西？错了！它有时甚至会吃鹿和野猪！想象一下，一条4米长的大鳄鱼突然从水里冲出来，将一头鹿拖落水——这个才叫做真正的淡水霸主。

所以下次你们去美国东南部旅行，见到淡水湖或者沼泽地，千万不要离得太近——因为你不知道你脚下面几时会有一条4米长、肚皮离地、高叉走路、牙尖尖的大家伙在那里等你。

各位兄弟，接下来讲的，就是美国短吻鳄最奇葩的冷知识。

虽然它这么大只、这么能打，但它们其实很喜欢晒太阳。整天看到它们嘴巴大打开那样趴在那里——你以为它在那里凶人？不是的，它只是在那里利用下巴的血管吸收热量，让自己早点暖一暖。所以呢，不要误会，它不是想吃你，只是想做个日光浴。
