# 冷到你不信 - 北草蜥

叫草蜥但不是草——北草蜥，四脚蛇成员，走给你看！

你可能会说，蜥蜴我见得多了，不就是四脚爬爬虫？你如果这样想就错了。北草蜥可不是你想象中那种普通蜥蜴，它竟然可以在中国北到吉林、西到甘肃、华南地区都找到它！而且是中国特有品种——就是只有中国才有，外国想养都养不到。

兄弟们你知不知道北草蜥最大的特点是什么？就是条尾很长！多长？可以达到头体长度的2到3倍！就是说如果头加身子是10厘米，条尾可以去到20甚至30厘米——比例夸张过好多减肥人士的梦想。

但是，如果说到尾长，南草蜥就更离谱——它条尾可以去到头体长度的3倍以上！南草蜥表示：比不过你，我就超你。

说到北草蜥，就不得不提它的花名——四脚蛇。你望真点，样子真是像蛇多点啦，长长扁扁的身躯，但又生了四条腿——就像蛇仔穿了四条裤那样，好搞笑。

也因为这个样子，好多人见到它都说"哇，四脚蛇！"但这个不是蛇来的，虽然像，但四肢健全，是正正经经的蜥蜴。

你知不知道北草蜥有多快？厉害！它们有"风一般的速度"，抓猎物或者跑路都好敏捷。就像你楼下那只蟑螂，一见到就飙走——但北草蜥快得过蟑螂添！

这种速度不仅用来捕食，还用来求生。因为条尾实在太长，很容易被人捉住——所以它们懂得自己断尾！一被咬住，条尾就自动断开，它就趁机跑路。这个就是大自然的"金蝉脱壳"——丢车保帅，生存智慧。

说到保护级别，北草蜥2000年就被列入《国家保护的有益的或者有重要经济、科学研究价值的陆生野生动物名录》——就是三有保护动物。

但问题来了，在部分地区，有人认为"四脚蛇"可以制成药酒——这个就是它们生存最大的威胁。不幸的是，虽然有保护名录，但误解仍然存在。

各位兄弟，接下来讲的，就是北草蜥最厉害的生存技能。

北草蜥最厉害的不仅是速度，还有它们的适应能力——从吉林到甘肃到华南，祖国大江南北都有它们的足迹。这种"全国都去得"的分布，证明了它们是多么百搭。就像你的朋友，永远都说"我哪里都去得"，但永远都不会主动约你。

但正因为分布广，见到的人多，关于它的误解都特别多。哪里最多四脚蛇的传说，就哪里最多奇怪用法——这个就是"名气大的代价"。
