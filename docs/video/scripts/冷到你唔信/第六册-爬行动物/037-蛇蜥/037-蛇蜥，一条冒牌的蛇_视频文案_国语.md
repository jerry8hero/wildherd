# 冷到你不信 - 蛇蜥

有脚蜥蜴学蛇爬，蛇蜥——终极卧底，明明是蜥蜴就不知做什么学人家！

我们从头讲起。今天聊聊，兄弟们，讲只超级奇葩的爬行动物——蛇蜥！

你可能会说，蛇蜥？不就是种蜥蜴吗？但当你见到它真人——身体细长条，滑溜溜，没脚那样爬行——你一定会想：难道是蛇跑去了，整不同了？蛇蜥表示：我真是蜥蜴来的，你知不知道！

这个世界真是有什么都有，猜不到蜥蜴都可以进化到像蛇那样。但是它们又不是完全骗你——遇到危险的时候，它会自断尾巴逃走，这个技能蜥蜴才有的啦，蛇是学不到的！这就是"舍卒保车"，断尾求生，够醒目。

不过这招都有后遗症的——断了的尾巴不会完全长回以前那样，长度、粗细都差点，不是说换条新那样就搞定。所以蛇蜥每次用这招，都是要付代价的。

兄弟们你知不知道？蛇蜥虽然像蛇，但完全不像蛇那么厉害——蛇有超快的移动速度，蛇蜥不够它；蛇有厉害的战斗力，蛇蜥都不行。简单来说，蛇蜥就是蜥蜴里面的"冒牌货"，什么都学蛇，但学到都是九不搭八。

欧洲有研究说，家猫是蛇蜥的克星——在欧洲部分地区，家猫是出名的"蛇蜥杀手"。猫猫表示：我又不知道你这么寸，小心我一下就搞定你！蛇蜥：我走啦！

不过蛇蜥都有厉害的一面——是出名的长寿蜥蜴！

你知不知道？蛇蜥可以活到30年！如果是人工饲养的，靓仔靓女那样照顾，活过50岁都不出奇。这个真是厉害了，人生龟赢——不少人类都未够它命长。

说到蛇蜥最奇葩的地方，当然是它们的身份——明明是蜥蜴，却长成这样。

科学家研究发现，蛇蜥在进化过程中慢慢失去了四肢，适应了钻洞、钻草丛的生活方式。但这个进化不是完全的，它们保留了蜥蜴的很多特征，例如可以自断尾巴、会眨眼皮、保留住小脚的痕迹骨骼。就像一个扮嘢大师，虽然样子整到像蛇，但是DNA骗不到的，骨子里都是蜥蜴来的。

各位兄弟，接下来讲的，就是蛇蜥最厉害的生存智慧。

蛇蜥不靠速度、不靠战斗力，靠的是——保育自己。昼伏夜出，见到危险就装死，或者立即钻泥土、钻草丛。它们知道，自己不够打，就不要硬碰，保存实力才是王道。就像你打游戏那样，打不赢就不要送头，先蹲草隐身，等对面走错路再出击。

这个就是大自然最真实的生存法则：不怕你厉害，最怕你不懂得保育自己。
