# 冷到你不信 - 黑鳄

黑漆漆、丑丑的——黑鳄，样子丑但是恶，不要靠样子就以为可以骗它！

你可能会说，黑鳄？是不是黑色那只？你如果这样想，就答对了！但你知不知道，这家伙竟然是鼍类中最大只的——平均体长3到4米，最大个体纪录超过5米！多巨型！

兄弟们你知不知道黑鳄有多厉害？

它可以将亚马逊雨林中令人闻风丧胆的绿水蚺撕成碎片！绿水蚺是世界上最厉害的蛇之一，但黑鳄就可以制服它——这个就叫做"以大欺小"！

你知不知道？黑鳄虽然名字里面有"凯门"，但其实不属于凯门鳄，而是独立的"黑凯门鳄"！

这个就像你姓李但不是李家村那支，不同分支而已。但这个不影响它的江湖地位——在鳄类家族中，黑鳄实力排在湾鳄、尼罗鳄、美洲鳄之后，和奥利诺科鳄并列第四——这个就叫做"鳄界四哥"！

说到最厉害，就是黑鳄可以捉绿水蚺——

想象一下，6米长的绿水蚺对上5米长的黑鳄，谁赢？科学家观察到，黑鳄可以撕裂绿水蚺——这个就是自然界最疯狂的"鱿鱼游戏"！

各位兄弟，接下来讲的，就是黑鳄最厉害的外号。

"黑凯门鳄"——黑当然啦，但为什么叫"凯门"？因为它曾经被归类为凯门鳄，但后来发现基因不同，就分开了。这个就叫做"分家"事件，黑鳄表示：我不想再做"凯门"啦！

所以下次见到黑漆漆的大鳄鱼，记得——这是可以撕裂绿水蚺的"黑凯门鳄"，鼍类里面的"一哥"！
