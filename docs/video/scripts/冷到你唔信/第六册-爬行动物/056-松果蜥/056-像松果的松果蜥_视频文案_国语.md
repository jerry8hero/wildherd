# 冷到你不信 - 松果蜥

像松果多过像蜥蜴——松果蜥，如果树会走，就像这家伙了！

你可能会说，松果？是不是指它吃得撑撑撑撑，软软的那样？你如果这样想就错了。松果蜥可不是你想象中那种整天趴在那里吃松子的享受材，它全身披着一层砾石那样坚硬的鳞片，像隔壁老板夹给你看都不信！

这层鳞片坚硬到怎样呢？像你踩在碎石路上面走路那样——硬核是几坚硬的。不过呢，正因为像层那样，它才改名叫"松果"蜥，远远看过去，真是像一粒松鼠最爱吃的大松果那样！

兄弟们你知不知道松果蜥有多厉害？

它竟然是蓝舌蜥家族的成员！蓝舌蜥你听过没？就是那条整天伸条蓝色舌出来扮嘢、虚张声势的那种！现在松果蜥都有样学样，遇到敌人就伸出条蓝舌头扮厉害——但其实呢，它就是一只只打分的斋饭输出，一动真格就软掉。

说到最奇葩的，当然是松果蜥的头尾迷惑法！

你没有看错！它条尾短粗短粗，形状像头像极了！遇到敌人时分分钟搞到你头尾都分不清——究竟哪个是头，哪条是尾？敌人愣下愣下，这边咬下去不是头哦，嗯，原来咬中条尾而已！这招叫"双头石龙子"，就像你打游戏打Boss的时候有个分身术那样，令对手完全猜不到！

所以下次见到松果蜥，千万不要冲动上前摸头——你摸的可能是它条尾哦！

说到防御能力，松果蜥就靠这层"砾石装甲"。

坚硬的鳞片除了像松果，还是天然护甲！敌人想咬？像你咬一粒碎石那样，硬到你崩牙。有研究显示，这层鳞片由特化的角质化皮肤形成，层层叠叠就像盔甲那样。不过呢，移动起来就慢点啰——毕竟背着全身碎石周身动，哪有得灵活。

这个就是大自然最奇妙的迷惑大法：靠样子骗人，一骗就骗几十年。
