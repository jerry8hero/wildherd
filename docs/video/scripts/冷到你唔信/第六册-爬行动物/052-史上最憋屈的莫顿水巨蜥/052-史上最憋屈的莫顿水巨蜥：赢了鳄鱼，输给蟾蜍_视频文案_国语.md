# 冷到你不信 - 莫顿水巨蜥

打赢鳄鱼输给蟾蜍——莫顿水巨蜥，鳄鱼都不够打，但蟾蜍就搞定它！

你可能会说，巨蜥哦，不就是放大版的四脚蛇？你如果这样想，就错了。这家伙你可以得罪讲，是澳洲北部最恶死的水中霸主——鳄鱼见到它都要忌三分。但是，它竟然输给了一只癞蛤蟆？你没听错，就是蔗蟾蜍。这个就是莫顿水巨蜥最离谱的生存故事。

兄弟们你知不知道莫顿水巨蜥多傍派对？它们住在澳洲北部，喜欢游泳多过在陆地荡。普通巨蜥晒太阳找块石头就行，这家伙连做日光浴都要找块浮木或者石头浸在水里——十足十温泉爱好者。体长不超过1米，不算巨蜥里面最大只，但游泳身手就厉害到呢，一转眼就不见了它。

说到打架，莫顿水巨蜥就是典型的闲死人。

它是超级凶悍的捕食者，鱼、两栖、鸟、哺乳动物，统统都是它的菜。不要以为它小只就没什么威胁性，它咬下去力大无穷，一下就搞定。有片拍到它们杀掉年幼的淡水鳄鱼——注意哦，是鳄鱼！这么大只东西都搞定，厉害到呢。

但是，火车不是推的，它就是输得这么冤。

1935年，蔗蟾蜍引入澳洲，本来是想对付蔗园里面的害虫。谁知？蟾蜍吃多了不仅大只了，还分泌毒素。莫顿水巨蜥不知死穴在哪里，照吃可也——吃完就中毒身亡。被蟾蜍毒死成为近百几年最常见的死因之一，就这样慢慢被毒到绝种边缘。你说惨不惨？

这个就是大自然教我们的一课：不是大只就恶晒，有时最危险的敌人不是你面前那个大东西，而是你身后那只衰东西。

各位兄弟，接下来讲的，就是莫顿水巨蜥最讽刺的生存之道。

莫顿水巨蜥游泳厉害过鳄鱼，咬东西厉害过蛇，但偏偏就不知蔗蟾蜍有毒。这个大概就是进化的代价——它祖先那时候没这种蛤蟆，仔仔不知道什么叫套路。

所以下次见到它，记得提醒下它：只蛤蟆不是这么容易东西！
