# 冷到你不信 - 喙头蜥

存在2.5亿年，恐龙都灭绝但它还在——喙头蜥，活化石界的老老前辈！

你可能会说，蜥蜴我见得多了，只是改个名字来骗鬼吗？你如果这样想，就错了。喙头蜥根本不是蜥蜴，它属于"喙头类"家族，在爬行界自立门户，独立成科！这个家族有多矜贵？全世界只有它一科一味，是现生爬行动物中最孤单的一支——就像你家整条村只有你一个姓，不说还以为你是石头爆出来的。

兄弟们你知不知道喙头蜥有多老？2.4亿年前三叠纪已经在地球行走了，恐龙都未出世它已经在那里！侏罗纪时家族最旺，白垩纪大灭绝捱得过，恐龙就这样走了，它还在那里享受世界。这个才是真正的老古董，活的化石——你知不知道你在看的时候，喙头蜥已经看着地球转了两亿几圈。

说到稀罕程度，喙头蜥就是爬行界的大熊猫。

只是分布在新西兰柯克海峡那几个小到地图都看不清的小岛上面，全世界野生个体只有几千只。新西兰人将它捧到上天，奉为"国之骄傲"，有专门保护区，有科学家24小时看着，还要和海鸟争地盘——因为它们喜欢在海鸟的洞穴里面住，就是这么串，不给钱就想有瓦遮头？

兄弟们你知不知道喙头蜥的牙齿有多奇葩？

现生爬行动物里面独一无二——下颌一排牙齿紧紧咬在上颌两排牙齿中间！就像个夹子一样，上下夹住，咬东西的时候完全没有空隙。普通蜥蜴牙齿生在牙骨上面，它就是生在上颚骨骼上，这种结构在爬行动物里面找不到第二家。简单来说，它开口就是一个三文治夹心——上颚两排，下颚一排，紧紧夹住。想吃东西？先过牙齿这关！

说到长寿，喙头蜥就是爬行界的百岁人瑞。

人可以活到一百岁已经厉害，喙头蜥轻松笑着——研究显示它们可以活到一百岁甚至更老。它们要吃东西就慢慢找，喜欢就找个安全的洞穴享受世界，不用追不用找，慢慢吃慢慢享受，养生之道就是这么简单。就是这样，才可以在这个地球生存两亿几年——你说多舒服。

各位兄弟，接下来讲的，就是喙头蜥最神奇的生存技能。

它们虽然行动慢悠悠，东西又吃得不多，但就是可以活那么久——其中一个原因就是它们的新陈代谢超慢，就算一年不吃东西都死不去。但最正的是，喙头蜥到了二十几岁才开始发春——性成熟年纪大过人类，科学家都觉得它就是在等运气，等地球环境变合适才考虑传宗接代。这种生存策略，难怪可以捱过大灭绝了。
