# 冷到你不信 - 枯叶龟

兄弟们，有只龟用"吸管"喘气，还要扮树叶！枯叶龟——伪装界的影帝，会呼吸管还会变身！

好了，你可能会说，枯叶龟？是不是像枯叶的龟？说中了！枯叶龟的脑袋就像一片枯黄的落叶一样，所以就取名"枯叶龟"。这个不是比喻，而是真的像——就像你在路边捡了片落叶，但是这片"叶"竟然有对小眼睛在那里动来动去，多吓人！

更有趣的是，它们不是哪个地方都有，只在南美洲的河流、湖泊、沼泽才找得到。流动缓慢的水、安静的环境——这些才是枯叶龟的安乐窝。

你知不知道枯叶龟有多喜欢吃鱼？

科学家解剖了20只野生枯叶龟，想研究下它们吃什么，结果——全部胃里面都是鱼！没错，100%都是鱼！这些家伙简直就是"鱼见鱼怕"的代表，全身技能都是为了吃鱼而生。不知道它们是不是吃鱼吃到腻，整天都在想：今天吃什么鱼好呢？

但是啊，说到厉害的东西，当然是枯叶龟那对眼——街坊称之为"火眼金睛"！

它的眼睛可以说是龟界里面最厉害的，夜猫子级别的视力！就算水里暗到伸手不见五指，枯叶龟依然可以精准地捕捉到猎物。这个就像你戴着夜视仪去打游戏，敌人还没到你已经知道它在哪里，厉害不厉害？

其实呢，你知不知道枯叶龟为什么夜视这么厉害？

原来它眼球里面有一层特殊的晶体，可以将微弱的光线反射多次，让视网膜吸收更多光线。简单来说，就是它眼睛内置了一个"信号放大器"，晚上看东西就像白天那么清楚！不过这个都是为了找吃的——鱼仔一动，枯叶龟已经看准了。

顺便提一提，说到枯叶龟最有趣的技能，当然是它那个"吸管鼻"！

枯叶龟不像其他龟那样，要整个头伸出水面才能换气。它们的鼻孔就像一支喷射口一样，只需要鼻尖一端伸出水面，就可以直接呼吸——完全不用整天水面上浮上浮下！

这个就厉害了！你想象一下，假设你游泳的时候只露出鼻子就可以喘气，不用整天整个头出来，多舒服！我就说，这个就是真正的"水面下呼吸大法"，包你在水底可以舒服地找吃的。

各位，接下来讲的，就是枯叶龟最有趣的伪装术。

枯叶龟除了头像枯叶，它的外壳也可以长到像水草和泥沙一样。它们经常会静静地趴在水底，动都不动，等猎物自己送上门——这个就是真正的"守株待兔"式捕猎，等你走过路过都不知道我在这里！

这招以静制动，多有智慧！我们整天说"静是金"，枯叶龟就是最好的示范——静静地等你上钩，这个就是顶级猎手的风范！
