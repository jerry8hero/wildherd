# 冷到你不信 - 双冠蜥

水面是可以跑的！双冠蜥——轻功水上飘，鸭子都羡慕的绝技！

你可能会说，蜥蜴我见得多了，不就是变色龙吗？如果你这样想，就错了。双冠蜥可不是你想象中那种普通蜥蜴，它竟然可以在水面上狂奔！没错，你没有听错，是水面——上——跑！这个技能厉害到连它的名字都搬进了欧洲传说里面。

兄弟们你知不知道双冠蜥的名字有多牛？1768年林奈——就是帮所有生物改拉丁学名那个猛人——用欧洲神话里面的蛇怪"巴西利斯克"来叫它。巴西利斯克是什么？就是那种可以单凭目光就搞定你的石化蛇怪！林奈心想：不如叫它"BASILICUS"吧，反正都这么厉害——结果双冠蜥就这样背负着一个传奇蛇怪的名号。

说到厉害，就不能不提它们头上的冠。有空在这里想：为什么要搞两下在头顶呢？原来，只有雄性双冠蜥才有两只冠，雌性只有一只——这个就是动物界的性别歧视的极致体现。雄性表示：两只冠才够帅啊，是不是？

但真正厉害的不是名字，而是它们的水面轻功。

双冠蜥逃跑的时候，可以在水面上狂奔！多厉害？每秒1.6米——你没有看错，是每秒1.6米！如果你试过在泳池里面走路，你就知道在水上走有多难。但是双冠蜥就可以做到，它们快速踢水，形成气泡，然后借力弹走——就像踩着水泡在那里冲刺。

你知不知道为什么它们不会沉落水？原来它们脚底有几大块鳞片，踢水的时候可以留住空气，形成气泡垫。就像你穿着波鞋踩在气垫上面——虽然气垫会漏气，但只要踩得快，就可以一直弹弹不沉。

这种技能，主要是用来对付追它们的捕食者——蛇、鸟类、还有其他蜥蜴。一旦发现危险，双冠蜥就二话不说冲到水那里，用水面狂奔来甩身。好像你见到个催命债主，当然要先跑了再说！

说到生活环境，双冠蜥就很挑剔——只喜欢墨西哥南部和哥伦比亚北部的雨林。这些地方天气热辣辣，湿度爆灯，整天都下雨。它们大部分时间都在河边的树枝上休息，一旦发现有人在附近偷看——不好意思，我走先！

各位兄弟，接下来讲的，就是双冠蜥最令人惊叹的生存技能。

原来它们不仅可以水面狂奔，还可以在水里闭气一段时间！当它真的跑不掉的时候，会静静地潜入水底，等捕食者走了才去找吃的。这种"你追不到我就滚"的心态，真是够可以。

所以下次见到双冠蜥，记得留意它头上有多少个冠——两只就是型英帅靓正的雄性，一只就是低调务实的雌性。但最厉害的技能当然是水面狂奔——每秒1.6米，踩着气泡就走，捕食者望着个背脊都不知道发生什么事！
