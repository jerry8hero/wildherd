# 冷到你不信 - 棱皮龟

兄弟们，龟中海王！不说不知道，棱皮龟是地球上最大型的海龟，皮滑溜溜像橡胶——不是普通龟壳的！

好了，你可能会说，海龟我见得多了，不就是普通东西？你如果这样想就错了。棱皮龟可不是你想象中那种普通海龟，它是世界上最大的龟！壳可以长到1.8米——整个人那么高！体重可以超过900公斤——等于一辆小型货车！龟中海王当之无愧。

但是，体型大只是基本操作，棱皮龟最厉害的——潜深海！

其实呢，你知不知道棱皮龟可以潜多深？1000米！普通潜水员下去三四十米就厉害了，它呢？可以去到1000米深！多厉害？就像你用电梯下车库，它就用电梯去月球——这个就是层次的不同。

科学家为什么要让一只龟潜到这么深？原来棱皮龟壳上面有一道道放射状的骨脊，其实是由很多很多小的鳞片拼成，这个结构令到它的壳非常有韧性，可以承受巨大水压。就像你见到的防弹衣原理——不是硬邦邦，而是有弹性，才可以卸力。

不过呢，说到棱皮龟吃什么，就真的猜不到——它竟然喜欢吃水母！

不要以为水母没什么吃的，棱皮龟就是靠水母为主食，而且食量很大，一天可以吃到自己体重七成的水母！就像你一天吃成50碗饭——的确是大胃王。不过研究发现，好多塑料垃圾在海里漂浮，形状像水母，棱皮分辨不到，一不小心就吃进肚子——这个就真是大悲剧了。

顺便提一提，你知不知道？棱皮龟的样子其实非常诡异——壳看上去像一块坑坑洼洼的岩石，头又没有其他海龟那样的尖嘴，而是有个像钩又像锯的开口。

不要以为这个是随便做的，这个开口其实非常适合在深海捕食水母——可以像吸尘器那样将水母吸进口腔里面。而且棱皮龟在地球上已经存活超过1亿年——对，你没有听错，1亿年！它们见过恐龙出生，见过恐龙消失，经历过大灭绝仍然生存到现在——这个才是真正的老前辈。

各位，接下来讲的，就是棱皮龟最催泪的生存故事。

棱皮龟虽然厉害，但它们的数量已经非常少——被列为易危物种。原因包括：海洋污染令水母变少、塑料垃圾令它们吃错东西、气候变化影响繁殖。

但是这个世界里面，仍然有一群棱皮龟在深海里面默默生活，延续着1亿年的生命奇迹。

所以下次见到棱皮龟的纪录片，记得留意这位低调的深海王者——它们不声不响，其实厉害到呢。
