# 冷到你不信 - 恒河鳄

嘴巴幼长像夹子——恒河鳄，古代就被玩坏，当乐器又当神器！

你可能会说，恒河鳄？印度那边的？不就是普通鳄鱼吗？如果你这样想就错了。恒河鳄可不是你想象中那种普通鳄鱼，它竟然有只像油条夹东西那样的超长嘴巴——细到那样，但很厉害！

兄弟们你知不知道恒河鳄的样子有多奇葩？

它们身体又细又长，嘴巴又细又长，就像早点摊卖油条那个叔叔夹油条用的夹子！就是这样，不要以为它是衰东西，这个就是造物主的创意——细不代表不好看！

兄弟们你知不知道？恒河鳄早在4000几年前就已经被人认识！

考古学家发现了好多印章、石碑，上面刻着恒河鳄周围都是鱼，它嘴里还叼着鱼——这个就告诉我们，几千年前人类已经知道恒河鳄是最爱吃鱼的家伙。多厉害，它是印度的"鱼王"！

说到恒河鳄最惨的，就是被古人玩坏了！

古时的人将恒河鳄看成河神、风神的化身。有人认为雄性恒河鳄拥有神秘力量，整天杀它取个鼻子——这个真是挺惨了。而且塔鲁人认为将恒河鳄尸体放在田野里燃烧，可以驱除害虫——你就知道古人有多喜欢搞这些东西。

但兄弟们你知不知道？恒河鳄其实完全不是杀人狂！

恒河鳄完全没有可证实攻击人致死的记录，它也缺乏捕食大型动物的能力。就像个温柔巨人，明明大只过分，但就是不会乱来——这个就叫做"大只但是温驯"！

兄弟们你知不知道？恒河鳄和我们中国的扬子鳄一样，都是极危物种！

一度险些在野外绝种——这个就是最惨的事实。因为人类捕捉、栖息地破坏，它们数量越来越少。所以呢，下次见到恒河鳄，记得——这个不是普通鳄鱼，而是差点被人类玩坏的"印度河神"！

各位兄弟，接下来讲的，就是恒河鳄最奇葩的长相。

你仔细看下，它个嘴像油条夹——细长细长。但这个不是缺陷，而是为食鱼而生！它可以快速地将鱼夹住，然后吞落肚——这个才是真正的"印度鱼王"本事。

所以下次见到恒河鳄，不要以为它是普通鳄鱼——这个是4000年历史的"河神"，差点被古人玩坏，但依然坚持在印度河里默默生存！
