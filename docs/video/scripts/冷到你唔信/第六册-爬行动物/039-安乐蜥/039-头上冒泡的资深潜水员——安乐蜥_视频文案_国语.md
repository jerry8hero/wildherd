# 冷到你不信 - 安乐蜥

头顶冒泡？但这不是卖萌，是潜水憋气——安乐蜥，水下活动厉害过好多鱼！

这次讲只厉害东西——安乐蜥！听到名字你可能会说，安乐蜥？就是闲闲地挂在树叶那里享受世界那只？

你错得好离谱。

有一批安乐蜥，不知发了什么神经，跑去学潜水！而且不是普通的蜻蜓点水式潜水——是正经的水肺潜水！它们懂用气泡当氧气瓶，潜水时间可以超过15分钟！

兄弟们你知不知道？原来安乐蜥界都有潜水教练！

2021年有个研究，发现了它们的超狂技能——每次下水之前，它会深深吸一口气，然后将个鼻头变成一个大大气泡——似足个潜水头盔！

这个气泡不是随便整来的，是它的"备用氧气罐"！在水底用氧的时候，就从这个气泡里面慢慢吸。你猜下，它们鼻子上面的气泡多厉害？

更加离谱的是，科学家可以通过这个气泡来判断它们在水底留了多久——气泡里面氧气越少，就代表潜得越久。这个就是动物界最强的"水下计时器"了！

说到这里，我突然想——如果安乐蜥懂用气泡潜水，那它们是不是也会想：今天下雨，不想做事，不如钻入水底享受世界？

下次你见到安乐蜥，记得看清楚——可能它正是一个资深潜水员，鼻子上挂着个气泡，想着等下去哪里捞东西吃。

各位兄弟，接下来讲的，就是安乐蜥最离谱的生存技能。

安乐蜥主要分布在美洲哥斯达黎加西海岸，那里环境其实挺恶劣——有季节性洪水，还有各种天敌。但它们发展出一套独特的生存策略：遇险就跳水，一跳就是几分钟到十几分钟！

有研究记录到，水生安乐蜥可以潜水超过15分钟不换气——你试下浸着不换气看看，分分钟红尸走不切。

这种技能不是天生的——年轻的安乐蜥要学的！它们慢慢摸索怎样吸气、怎样控制气泡、怎样省着用氧。就像你去考潜水牌，要慢慢累计经验才行。

所以下次见到安乐蜥，不要以为它只是挂在那里吹空调——可能它是刚完成了一场深度潜水之旅，歇下而已！
