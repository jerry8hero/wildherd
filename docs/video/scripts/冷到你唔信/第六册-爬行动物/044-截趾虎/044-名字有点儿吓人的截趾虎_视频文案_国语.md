# 冷到你不信 - 截趾虎

名字叫"截趾"，但是不关脚趾事——截趾虎，听名字吓人看完东西，原来是益虫！

我们聊聊，讲只名字超级恐怖的壁虎——截趾虎！

你听到这个名字，是不是以为它被人截断了脚趾？由不得你不信，截趾虎从来没有被人截过脚趾，它天生就是那样！名字来自它前后脚内侧脚趾几乎没有爪，不是疤痕，而是天生的。这个大概就是造物主的恶作剧——明明健康活泼，偏偏改个名搞得人心寒。

兄弟们你知不知道截趾虎有多厉害？分布范围横跨半个地球！

从东南亚出发，一路飘洋过海，去到夏威夷、墨西哥，整个太平洋都被它们走遍了。这种东西不仅走得远，还要适应能力爆灯，森林住得，城市一样活得。森林？行！城市？一样行！简直就是爬行动物里面的"全能选手"。

说到夏威夷，截趾虎就厉害了——当地沙滩上面到处都是，但被归类为入侵物种。

不过！当地人完全不介意。为什么？因为截趾虎虽然是入侵者，但非常受欢迎——它们会帮人类吃蚊、捉蟑螂，简直就是免费的除虫大师。就像你请了个不用使钱的灭虫公司，天天帮你看门口，你说多爽？

兄弟们你知不知道截趾虎有多鬼马？它们只在人类家里出没——而且只是晚间活动！

白天你见不到它，它们找了个最漂亮的位置高高挂着，墙壁、天花板，统统都是它们的主场。一到晚上就出来捉虫，包你家少很多蚊虫。这个就是最佳室友：不用你照顾、不用你使钱、只是帮你做事。

各位兄弟，接下来讲的，就是截趾虎最厉害的生存哲学。

少了些爪，不代表弱。截趾虎用自己的方式证明：不用卷的，找到自己的位置就够。森林、城市、沙滩、家里，样样都行。这个就是它们的生存之道——不需要完美，只需要适应。
