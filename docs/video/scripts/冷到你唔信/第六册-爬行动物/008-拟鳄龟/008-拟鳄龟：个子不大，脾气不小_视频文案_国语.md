# 冷到你不信 - 拟鳄龟

兄弟们，个头比大佬小，但是脾气就大把！拟鳄龟——龟中战斗机，一言不合就追击，不好惹！

好了，你可能会说，哇，小鳄？听起来像是真鳄龟的小弟？不好意思，你这样想就出事了。拟鳄龟虽然大个那时候个头、咬合力确实比真鳄龟小，但是脾气？包你猜不到——它比真鳄龟厉害多了！真鳄龟是防守型，等你搞它才还手；拟鳄龟呢？主动追击型，一言不合就上嘴，是进攻进攻再进攻！

你知道不知道拟鳄龟可以有多激进？

这个家伙会主动追逐猎物！不像其他龟那样等东西吃上门，拟鳄龟会两边看："喂，你为什么走过这里？"然后——追！追到你要叫救命！对待入侵者更加是零容忍，是龟里面的激进派代表。

更厉害的是它们的脖子——又长又灵活，可以向后伸到身体后部！这个意味着什么？意味着它可以侧面、后面、你以为安全的角度突然发难。攻击速度厉害到呢，理论上可以轻松咬断手指——这个不是开玩笑的，是真的可以的！

但是啊，说到咬合力，就由不得你不信。

虽然它成年体型比真鳄龟小，但是咬下去的时候，牙还是厉害的。科学家做过研究，拟鳄龟的咬力可以说是龟界里面数一数二。有多厉害？假设你被它咬到手指，可能真的要和手指说拜拜。所以呢，如果见到野生拟鳄龟，千万不要手多多走去搞它——被它咬一口，你就知道什么叫后悔。

其实呢，你知不知道？拟鳄龟在日本曾经掀起过一阵"宠物热"。

话说20世纪60年代，日本有人将拟鳄龟当作外来宠物引进。谁知引进之后才发现——这家伙是坏东西！咬伤个案不断，被记录为严重咬伤来源之一。本来以为养只龟多安静，谁知养了只"水底比特犬"，每天都要提防被它咬一口。这个就是外来物种入侵的教训了。

不过呢，顺便提一提，凶猛的拟鳄龟，小时候其实有点可爱。

拟鳄龟宝宝在离开巢穴之前，可以发出"咔嗒""咯吱"的声音！有的还可以发出像手指在梳子上摩擦那样的奇异声音。想象一下，一只长相凶残的龟，小时候在那里发出"咯吱咯吱"声……是不是有点反差萌？
