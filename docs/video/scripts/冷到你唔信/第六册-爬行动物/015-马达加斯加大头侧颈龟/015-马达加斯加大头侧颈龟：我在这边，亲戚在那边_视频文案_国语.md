# 冷到你不信 - 马达加斯加大头侧颈龟

兄弟们，我在马达加斯加，亲戚在非洲大陆——这只龟竟然有"跨国恋"？地理课都教没过！

好了，你可能会说，龟就龟啦，大脑袋有什么特别？你如果这样想，就错了！这只龟不止头大，还要在2018年被评为"世界上最濒危的龟类"——注意是"最濒危"，不是几濒危，是最！就像你去参加选秀，不是拿冠军，而是直接拿了"全球最后这个"——呃，听起来是挺感动，但又好sad。

但是啊，说到侧颈龟，你可能觉得陌生。但它属于南美侧颈龟科——对，你没有听错，南美。问题来了：马达加斯加明明在非洲，它们的亲戚为什么在南美？这里就厉害了。

约7800万年前，白垩纪晚期，连接南美洲与南极洲和马达加斯加的大陆桥沉没——就是说远古时期，这些地方是连在一起的！后来大陆桥一沉，马达加斯加就开始了"漂移"人生，慢慢飘到现在的位置。而这只龟的祖先，就被困在马达加斯加，跟整个家族失去联系。

所以这只龟现在成为南美洲以外唯一发现的南美侧颈龟科家族成员——就像你去了外国读书，才发现家里有个小孩，你忘记了他存在多久，但他真的在这里！是多浪漫又好sad的故事。

其实呢，你知不知道？这只龟大头大在哪里？

它头占身体比例来讲，算是龟界里面比较大的，所以叫"大头"。但是这个头大得有道理——它们要用这个大脑来感知环境、找吃的、生存。毕竟住在马达加斯加，生存压力大，不大头大个脑，怎么顶得住！

顺便提一提，说到外表，它外壳是黑褐色为主，加上头大，看起来的确有几分工装feel。但是不要小看这个"丑小龟"，它是地球上最濒危的龟类之一，野生数量少到让人心疼。

各位，接下来讲的，就是马达加斯加大头侧颈龟最厉害的身份证明。

这只龟是"活化石"——7800万年前的血脉，延续到今天，还是地球上独一份。就是这个原因，科学家对它研究很认真，希望找到方法保护这个珍稀物种。

但是，濒危当然有原因的——栖息地破坏、非法捕捉、气候变化，每一样都夹击着这个脆弱的族群。

所以下次见到侧颈龟，记得打个招呼——你打招呼的，是一个7800万岁的老街坊！
