# 冷到你不信 - 中华鳖

兄弟们，鳖用嘴尿尿？这个真不是废话——中华鳖的独特生理结构，科学家研究完都说白费力气！

好了，你可能会说，鳖？甲鱼？那些莲藕塘里面养的？我可以告诉你，如果你这样想，就完全低估了它。中华鳖是中国特有的淡水鳖之王，不仅外形独特，还有一些厉害到离谱的生理技能——包括一样令人匪夷所思的事：它竟然可以用嘴来"尿尿"？

其实呢，你知不知道？中华鳖会用嘴排尿！

不好意思，我知道你一定是这样想——尿尿？用嘴？难道它屙完再喝？想想都觉得恶心！但先不要急，中华鳖其实不是真正用嘴去屙尿，而是它们的口腔黏膜可以辅助排泄废物。它们有特别的血管结构，可以在口腔里面进行气体交换，和排出尿素。就是说，如果你想帮它检查身体，兽医可能要检查它的嘴——这件事，多考验技术。

但是啊，但是等等，不要以为它们只有这一样厉害东西。

说到中华鳖的绝活，当然是潜水——它们可以潜入水底长达数小时！

中华鳖不仅可以水里面长时间活动，它们还可以在水底"冬眠"。冬天的时候，水面冻冰冰，但是水底就暖了，它会将自己半埋入泥巴里面，心跳可以慢到每分钟几次，不仅不需要出水面换气，还可以利用皮肤和口腔进行气体交换。就是这种技能，令到它可以安安稳稳地度过整个冬天——你这个时候在被窝里面睡，它在泥里面享受世界。

顺便提一提，你知不知道？中华鳖可以活到五六十年！

中华鳖是长寿动物的代表，不仅寿命长，它们的生长速度其实很慢——要长到足够大可以繁殖，可能要等十来年。但是一旦大个了，它就是淡水生态里面的顶级存在。虽然性格温顺，但是一旦受到威胁，它会猛烈反击——咬你一口不在话下，而且速度很快，想捉它？小心你的手！

各位，接下来讲的，就是中华鳖最神奇的生存技能。

中华鳖在繁殖季节的时候，会爬上岸边找合适的沙地产卵。刚刚生完蛋，它会很仔细地用沙覆盖，然后离开——不会回头看。但这个不代表它不关心下一代，它将大部分精力放在找吃的和储存能量，让受精卵可以在沙里面自然孵化。大概两个月后，小鳖就会破壳而出，循着本能往水里冲——这个时候，它们要靠自己，不会有爸爸妈妈教。

生存的第一课，就是自己爬出去，自己游。
