## 评论区置顶

🐢 侧颈龟冷知识要点回顾：

🔹 第一站：缩壳方式
→ 特点：歪向一侧、L 型折叠
→ 为什么：适应沼泽环境的保命绝活
→ 日常：检查壳缝、侧面逗龟

🔹 第二站：亚目不同
→ 侧颈龟亚目：脖子侧向折叠
→ 曲颈龟亚目：脖子 S 型垂直向下
→ 区别：相当于猫和狗那么大

🔹 第三站：冈瓦纳三兄弟
→ 非洲派：西非泥龟、巨头、沼泽
→ 南美派：蛇颈龟
→ 澳洲派：澳洲短颈龟

🔹 第四站：蛇颈龟
→ 脖子几乎等于体长
→ 南美沼泽捕食绝活
→ 成体水位：背甲高度的 2–3 倍 + 晒台

🔹 第五站：腹甲可闭合
→ 非洲侧颈龟科（西非泥龟、沼泽侧颈龟等）
→ 腹甲铰链、自带"门锁"
→ 南美蛇颈龟和澳洲短颈龟没有

🔹 第六站：加温过冬
→ 热带品种无冬眠本能
→ 必须配加热棒 + 温控 + 缸盖
→ 水温维持在 25–28 度
→ 18 度以下易感染：不吃东西、眼睛睁不开、四肢无力

🔹 第七站：不尿尿的龟
→ 龟无膀胱储尿机制，水分被大肠和泄殖腔重吸收
→ 氮废物以白色糊状尿酸排出
→ 缸底白色沉淀 = 尿酸盐，不是脏
