## 【简介】

龟粮颗粒到底该买多大？小颗粒高蛋白、大颗粒低蛋白，这个说法是真的吗？

结论先给你：颗粒大小本身是中性的，它管"吃得进"；营养高不高，得单独翻配方——两件事分开评估。

这期把颗粒大小当成一张参数表来拆：

◆ 规格是套"方言"——寸金 0 号 1.5mm 到 4 号 7mm 各有对应，但跨品牌编号对不上；同一品牌标的数字有的指长度有的指直径，别混着看
◆ 四层逻辑——口腔咽喉决定吞多大；水龟食道能当蓄水池、陆龟靠咬合撕扯，才有圆粒和长条；生长阶段；最容易被漏的水质
◆ 黄金法则——看体型不看年龄；量化标准一口吞 1-3 粒；拿不准宁小勿大（但别小到漂散被过滤吸走）
◆ 营养争议的答案——多数品牌只换模具，但寸金是反例：0 号苗料粗蛋白≥42%、3 号≥38%、陆龟粮 15% 起步，先改配方再换模具
◆ 水质三笔账——碎屑、残饵、溶出，合适的颗粒是水质管理第一道防线
◆ 四个坑全避开——按年龄选 / 小粒=高营养 / 大粒练咬合 / 只看直径不看形状

小不一定营养高，大也不一定练咬合，合适的口径是一口吞得下、少出碎屑、全吃完。

## 【置顶评论】

🐢 龟粮颗粒规格，一条评论总结

📌 规格是"方言"，别背编号：
寸金：0 号 1.5mm / 1 号 2.3mm / 2 号 3.5mm / 3 号 5mm / 4 号 7mm——跨品牌对不上（寸金 2 号 3.5mm，别家 6 号可能是 1cm）；同一品牌标的数字有的指长度有的指直径，别混看；海外品牌看各家对照表

📌 背甲区间参考：
- 背甲 4cm 以下、50g 以下：0.8-1.5mm 微粒（芝麻大）
- 背甲 5-10cm：3-5mm 中小粒
- 背甲 10cm 以上：6-8mm 甚至更大
混养大小龟统一选小粒（最大公约数）——但混养本身不推荐，颗粒只是补救

📌 黄金法则：
看体型，不看年龄（同龄龟能差两三厘米）；量化标准：一口能吞 1-3 粒
宁小勿大，但有边界：别小到会漂散、被过滤器吸走；成龟长期吃太小的粒会没兴趣、摄入不足

📌 为什么按体型（四层逻辑）：
①口腔咽喉决定吞多大——龟没牙齿，角质喙+前肢切断撕裂，不做咀嚼研磨
②水龟食道高度可伸缩"当蓄水池"吸吞→圆粒；陆龟食道伸缩性差靠咬合撕扯→长条；半水龟居中
③生长阶段需求不同
④水质：碎屑（大粒咬碎出粉）+残饵（分解出氨氮亚硝）+溶出（水溶性营养流失）

📌 大小颗粒营养一样吗：
主流：多数品牌只换模具、配方不动。反例：寸金 0 号苗料粗蛋白≥42%、3 号料≥38%、陆龟粮粗蛋白 15% 起步+粗纤维≤25%——先改配方再换模具
结论：规格管吃得进，配方管吃得好，两件事分开评估。定完大小照样翻粗蛋白、粗脂肪、钙磷比、维生素 D3 和配料表

📌 四个坑：
①按年龄选不看体型 ②以为小粒=高营养 ③大粒练咬合（正确做法：带壳螺、墨鱼骨）④只看直径不看形状（圆粒适合吸吞，长条适合撕扯）

📌 操作四步：
测体型→定规格（宁小勿大、一口1-3粒）→核对配方对不对阶段→观察进食速度、碎屑、粪便、水质，不对就调

一句话：小不一定营养高，大也不一定练咬合，合适的口径是一口吞得下、少出碎屑、全吃完。
