1️⃣ 纯种辨识速查：
- 洪都拉斯：细红线条 / 脸纹多而艳 / 喙偏白 / 腹甲黑线窄 / 虹膜蓝
- 油彩：粗红圆环带黑边 / 圈内包黄 / 更华丽
- 索诺拉：背甲黯淡 / 脸纹寡淡 / 喙偏灰黑 / 腹甲黑线粗
- ⚠️ 国内杂交个体泛滥，单个特征不可靠，至少交叉验证2-3项

2️⃣ 饲养四要素：
温度25-30℃（20℃红线）｜湿度≥70%｜水陆比6:4｜UVB必配
水位≤背甲长度 ｜ 垫材≥5cm
❌ 不可冬眠 ｜ ❌ 雄龟勿多养

3️⃣ 物种档案：
Rhinoclemmys pulcherrima incisa ｜ 成体背甲约20cm
寿命约30-50年（口径不一）｜ 性成熟10年+
木纹龟属是地龟科唯一分布于中南美洲的属，近亲多在亚洲

## 物种准确性提示（生成后必查）

木纹龟三大识别特征，缺一样就重生成：

1. 每块盾片上一圈圈同心生长环纹，像树木年轮（"木纹"名字的来源）
2. 头顶后部一大块奶油黄圆斑
3. 四肢、颈部、脸颊鲜明的橙红斑点和细纹

本集特有要求：如果封面出多只龟，花纹差异必须明显——洪都拉斯是细红线条、油彩是粗大红圆环，三只画成同一个花纹等于封面失效。

常见翻车：画成红耳龟（头侧红纹+扁壳）、黄缘类箱龟（高拱+黄边）、三只花纹无差异。

更稳的方案：用自家木纹龟实拍+油彩/杂交对比图（注明来源或"图片来源网络"）拼三联图，剪映叠字。
