# 来源：03-B站发布内容.md 置顶评论（中秋特辑）

📌 补充一些视频里没展开的：

1️⃣ 合规提醒（本期最重要）：
- 黄缘、锯缘都是国家二级保护动物（2021年名录）
- 只能养带专用标识的人工繁育个体
- 野外捕捉、买卖野生个体都违法，别碰

2️⃣ 水果红绿灯：
- 可以当零食：无花果、桑葚、蓝莓（一周最多1-2次）
- 别喂：葡萄、柚子、石榴（高糖，代谢扛不住）
- 月饼等一切人类加工食品：绝对禁止

3️⃣ 温度对照（中秋版）：
- 白天26-30℃：正常投喂
- 昼夜温差拉到8℃以上：宁可少喂、直接停喂
- 夜里降温：关窗避冷风，深色整理箱别晒太阳

4️⃣ 出门安置清单：
- 离家前一天停喂，排空肠胃
- 浅水盆备足干净饮水
- 远离窗户、阳光直射、空调风口
- 超一周找靠谱朋友上门加水查看，别留大量食物

5️⃣ 回家检查顺序：
- 先看温度稳定24℃以上
- 再看精神、腐皮、水盆、垫材过湿发霉
- 一切正常也隔1-2天再少量喂
- 萎靡+长时间侧漂：停食保温静养，别乱下药
