# 内容分析

## 基本信息
- 主题：中秋假期黄缘/锯缘饲养避坑速查
- 来源：B站视频《中秋别把龟喂成"月饼"！黄缘锯缘假期避坑指南》置顶评论
- 用途：评论区配图，替代长文字置顶，观众可直接保存
- 数据类型：清单/规则型（5 个独立模块：合规、红绿灯分类、温度对照、出门清单、回家检查）
- 复杂度：中等偏高——条目多（约 18 条），但每条短、结构平铺
- 语气：玩家向、亲切、防坑警示
- 受众：B站养龟观众（黄缘/锯缘玩家），手机端查看为主

## 语言
- 源语言：中文
- 用户语言：中文 → 图上文字全中文

## 设计指令（来自用户）
- 竖版
- 一张图承载全部置顶评论内容
- 面向"不想读长文字"的用户，要求一眼可扫、可保存

## 结构判断
- 5 个模块互相独立，无先后依赖（除"回家检查顺序"内部有次序）
- 模块 2（水果红绿灯）自带三档分类语义（绿/红/黑），视觉上适合信号灯隐喻
- 模块 1（合规）是最高优先级警示，需视觉权重最高
- 模块 4/5 是清单，适合勾选框式排版
- 布局结论：bento-grid / dense-modules 最匹配；hub-spoke、linear 不适合（无中心概念、无流程主线）
