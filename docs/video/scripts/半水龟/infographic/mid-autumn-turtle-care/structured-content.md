# 结构化内容

## 标题
中秋养龟避坑速查｜黄缘锯缘假期指南

## 学习目标
观众保存这张图后，能快速查到：中秋假期什么能喂、什么不能喂、温度怎么判断、出门怎么安置、回家怎么检查。

## 模块（内容逐字保留，仅做标签化）

### 模块 1｜合规提醒（最高优先级，视觉权重最大）
- 关键概念：合法饲养底线
- 内容（原文）：
  - 黄缘、锯缘都是国家二级保护动物（2021年名录）
  - 只能养带专用标识的人工繁育个体
  - 野外捕捉、买卖野生个体都违法，别碰
- 视觉元素：盾牌/证件图标 + 红色警示边框
- 文字标签：合规底线

### 模块 2｜水果红绿灯（三档分类）
- 关键概念：中秋投喂红绿灯
- 内容（原文）：
  - 绿灯 可以当零食：无花果、桑葚、蓝莓（一周最多1-2次）
  - 红灯 别喂：葡萄、柚子、石榴（高糖，代谢扛不住）
  - 黑灯 月饼等一切人类加工食品：绝对禁止
- 视觉元素：三色信号灯（绿/红/黑），每档一种水果图标
- 文字标签：水果红绿灯

### 模块 3｜温度对照（中秋版）
- 关键概念：看温度决定喂不喂
- 内容（原文）：
  - 白天26-30℃：正常投喂
  - 昼夜温差拉到8℃以上：宁可少喂、直接停喂
  - 夜里降温：关窗避冷风，深色整理箱别晒太阳
- 视觉元素：温度计 + 三档温度色带
- 文字标签：温度对照

### 模块 4｜出门安置清单
- 关键概念：出门前的准备
- 内容（原文）：
  - 离家前一天停喂，排空肠胃
  - 浅水盆备足干净饮水
  - 远离窗户、阳光直射、空调风口
  - 超一周找靠谱朋友上门加水查看，别留大量食物
- 视觉元素：行李箱/水盆/窗户图标 + 勾选框
- 文字标签：出门安置清单

### 模块 5｜回家检查顺序
- 关键概念：回家后的检查次序
- 内容（原文）：
  - 先看温度稳定24℃以上
  - 再看精神、腐皮、水盆、垫材过湿发霉
  - 一切正常也隔1-2天再少量喂
  - 萎靡+长时间侧漂：停食保温静养，别乱下药
- 视觉元素：编号步骤（1→2→3）+ 放大镜图标
- 文字标签：回家检查顺序

### 页脚
- 内容（原文）：中秋你家的龟是留守还是随行？评论区报到～
- 视觉元素：小龟图标 + UP主署名位
- 文字标签：评论区互动

## 设计指令
- 竖版；模块间留白清晰，手机上单屏可读（字号不能小）
- 中秋氛围元素（月亮/灯笼）作点缀，不抢信息密度
