置顶评论：
📌 看前必读：

1️⃣ 合规提示（重要）：
- 本期提到的黄缘、锯缘（闭壳龟属所有种）、枫叶龟（地龟）、草龟、花龟、黄喉拟水龟，均为国家二级保护动物（部分仅限野外种群）
- 个人饲养是否需办理《人工繁育许可证》、如何取得专用标识，各地口径不同，务必先咨询当地农业农村主管部门
- 例：广东口径下家养黄缘也需办证；上海口径为个人少量、不经营不繁育可免办
- 购买请认准人工繁育个体+专用标识，留存交易凭证，别碰"下山货"

2️⃣ 安全提示：
- 陶瓷灯必须配陶瓷灯口（塑料灯座会脆化）
- 灯泡与泡沫板留安全距离或垫隔热层
- 箱体留通风口，防高温高湿闷出病
- 陶瓷灯加防烫网罩，表面温度可达数百度

3️⃣ 温度速查：
- 加温基线：26-28℃，热区≤32℃
- 黄缘冬眠：7-10℃；锯缘浅冬眠：16-18℃、≤2个月
- 水龟浅水冬眠：5-8℃
- 清肠需在15-18℃以上进行

4️⃣ 设备预算参考：
- 整理箱30-60 + 陶瓷灯20-35 + 温控器30-60 + 温湿度计10-20 + 泡沫板若干 ≈ 100-150元
- UVB灯另计（长期室内饲养必备）
- 电费按0.6元/度估算，含温控启停后实际更低
